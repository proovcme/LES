# LES RAG 0.1.0 — руководство пользователя

Первый выпуск LES RAG для Windows. Установщики и результаты проверки доступны в официальном GitHub Releases.

Это тот же текст, который доступен внутри приложения через **Руководство**.

## Начало работы

### Назад, главная и черновики

Вверху рабочих экранов есть **Назад** и **Главная**. Главная — лес знаний. Вкладки сохраняют свои формы при переключении. Черновик запроса сохраняется отдельно для разговора: можно открыть настройки и вернуться. Хранятся последние 16 черновиков до 20 000 символов каждый. Чтобы удалить черновик, очистите поле. Прикреплённый файл после перезагрузки страницы нужно добавить заново. Диалог можно закрыть кнопкой **Отмена / Закрыть** или клавишей **Esc**.

### Лес работает или завис?

При ответе видны текущий этап, прошедшее время и раскрываемый **Ход работы и журнал**. Текст приходит по мере генерации, если движок поддерживает поток. Если общего объёма работы пока нет, полоса движется без процента; при обработке известного числа файлов показываются реальные счётчики. **Остановить** отменяет текущий запрос. Оборванный ответ помечается неполным: полученный фрагмент не является завершённым или проверенным ответом. В данных и почте состояние фоновой обработки проверяйте по их счётчикам и журналам.

### Установить Лес

Маленький **LES-RAG-Web-Setup.exe** скачивает полный пакет с GitHub, проверяет размер и SHA-256 и запускает установку. Python, Qdrant и компоненты приложения входят в пакет; вручную их ставить не нужно. Модели выбираются и подключаются отдельно. Для компьютера без интернета перенесите **LES-RAG-Setup.exe**; WebView2 Evergreen Runtime должен быть уже установлен. Если WebView2 отсутствует, установщик скачает его с Microsoft, проверит цифровую подпись и установит; для этого шага нужен интернет. Если загрузка оборвалась, повторите запуск: повреждённый файл не будет установлен. Онлайн-установка доступна после публикации выпуска в официальном репозитории.

### Установка из командной строки

Скачайте **install-les.ps1** из официального выпуска и выполните `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-les.ps1 -Silent`. Ключ **-Silent** выполняет установку без мастера; **-DownloadOnly** только сохраняет проверенный пакет. Права администратора не требуются. Приложение устанавливается для текущего пользователя; существующие документы и состояние сохраняются.

## Чат

### Файл или папка в разговоре

Перетащите файл в область под сообщением или нажмите её для выбора. Вложение читается для текущего вопроса; через кнопку вложения можно отдельно добавить документ в базу знаний. Кнопка **Папка** предлагает **Прочитать для вопроса** либо **Добавить в базу знаний**. Для одного вопроса допускается до 25 документов, 50 МБ и 48 000 символов текста; при превышении Лес предложит базу знаний и не выдаст обрезанный комплект за полный. В сообщении выбирается одно вложение: файл или снимок папки. Снимок не обновляется сам; для обновления используйте набор документов с наблюдением. Оригиналы остаются нетронутыми.

## Документы

### Сканы и распознавание текста

Для PDF без текстового слоя и изображений используется встроенное распознавание Windows (OCR). Скрытая языковая модель не загружается, интернет для распознавания не нужен. Доступные языки зависят от установленных языков Windows. В смешанном PDF проверяются все страницы: обычный текст извлекается напрямую, сканы распознаются. Если страница не распознана, документ не считается успешно подготовленным. Ошибка не попадает в поиск вместо текста. Для важных фактов сверяйте распознанный фрагмент с оригиналом.

### Пустая или недоступная папка

Лес отличает пустую папку, отсутствие поддерживаемых документов и отказ доступа. Пустую папку можно явно **Подключить под наблюдение**: она станет пригодна для поиска после появления и обработки документов. Если папка временно исчезла, например отключён внешний диск, это не считается удалением всех файлов. Проверки возобновляются, когда папка снова доступна. Источники используются только для чтения; индекс и служебные файлы хранятся в каталоге приложения.

## Интеграции

### Командная строка и локальный API

В папке установленного приложения есть **les.cmd**. Пока Лес запущен: `les.cmd status` — состояние, `les.cmd datasets` — наборы, `les.cmd projects` — проекты, `les.cmd search "вопрос" --dataset ID` — поиск с фрагментами, `les.cmd ask "вопрос"` — ответ модели. Для продолжения чата передайте `--chat ID`. Команда `les.cmd mcp` запускает MCP-сервер для внешнего клиента. Результаты CLI выдаются в JSON UTF-8. API работает на локальном адресе текущего экземпляра; сервер не открывается в сеть автоматически.

## Настройки

### Профили и скиллы

Откройте **Настройки → Профили**. Выберите роль и отредактируйте основной скилл; дополнительные сохранённые скиллы можно выбрать в библиотеке ниже. Общий лимит — 8 000 символов. **Сохранить версию** создаёт отдельную редакцию, а **Сделать активной** назначает её новым чатам. Старые чаты сохраняют свои инструкции. Кнопка **Посмотреть инструкции модели** показывает роль, скиллы и правило ссылок сохранённой версии; история и материалы запроса добавляются отдельно.

### Внешние инструменты MCP

В разделе **Настройки → Профили → Внешние инструменты** укажите название и адрес Streamable HTTP сервера, например `http://localhost:8000/mcp`. Нажмите **Проверить и выбрать**, разрешите нужные инструменты чтения, затем отметьте их в профиле и сохраните версию. Проверка получает только каталог. Подключайте доверенные серверы: отметку чтения сообщает сервер, приложение не изолирует его внутренние действия. Для установленного сервера выберите тип **Локальная программа**, укажите полный путь к его .exe и аргументы по одному в строке. Проверка запускает этот сервер. Сейчас не поддерживаются авторизация, OAuth и инструменты изменения данных. Отключение или удаление подключения прекращает новые вызовы; данные на сервере сохраняются.

Для работы со сметными источниками подключайте отдельный MCP-сервер с инструментами чтения. После проверки каталога выберите только нужные инструменты, затем добавьте их в профиль. LES RAG сам не выполняет сметный расчёт и не разрешает изменяющие инструменты такого сервера.

LES RAG также может отдавать свой поиск внешнему MCP-клиенту, например Codex. Откройте LES RAG, затем настройте в клиенте локальный stdio-сервер: программа — `python/python.exe` из установленной папки LES RAG, единственный аргумент — `runtime/tools/light_mcp_server.py` из той же папки. Укажите оба пути полностью. Сервер предоставляет список наборов и поиск с фрагментами и ссылками на оригиналы. Он работает, пока запущен LES RAG; настройки клиента и запуск сервера выполняются на этом же компьютере.

## Начало работы

### Где взять локальную модель

Откройте **«Модели» → «Найти на компьютере»**. ЛЕС найдёт запущенные локальные сервисы на стандартных адресах и покажет доступные модели. Выберите модель, её задачу и нажмите **«Проверить и подключить»**.

Если Ollama не найдена, установите её по ссылке ниже и запустите из меню «Пуск». Если список пуст, загрузите модель в приложении Ollama и повторите поиск.

Поддерживается обнаружение Ollama, LM Studio и совместимых серверов на стандартных локальных портах. Для другого адреса используйте «Подключить API».

Модель для чата и модель для поиска назначаются отдельно. До подтверждения модель не назначается и документы ей не передаются. Ручные параметры доступны в «Дополнительной настройке».

Официальная загрузка: https://ollama.com/download/windows. Каталоги моделей: https://ollama.com/library/qwen3.5 и https://ollama.com/library/bge-m3. Примеры доступны на экране **Модели → Где взять модель и как подключить**.

### Как подключить облачный API

1. В личном кабинете выбранного сервиса откройте документацию совместимого API, список моделей и раздел ключей доступа.
2. Нажмите «Подключить API». Укажите адрес API из документации провайдера и ключ, нажмите «Получить модели». Если сервис не отдаёт список, введите имя модели вручную. Адрес обычного сайта с чатом не является адресом API.
3. Выберите модель и её задачу, нажмите «Проверить и подключить». ЛЕС проверит подключение и сохранит выбранное назначение.

Схема адреса: `https://api.example.com/v1` — это пример, его нужно заменить адресом своего сервиса. Идентификатор модели тоже берётся у провайдера.

При облачном подключении запросы и переданные модели фрагменты документов уходят выбранному провайдеру. Условия оплаты и обработки данных определяет этот сервис.

## Если что-то не работает

### Подключение модели не работает

**Сервис не отвечает:** убедитесь, что Ollama запущена, а адрес и порт совпадают с её настройками. Для другой машины используйте её адрес, а не 127.0.0.1.

**Модель не найдена:** откройте «Найти на компьютере» и обновите список. Если список пуст — загрузите модель в приложении вашего локального сервиса.

**Неверный ключ / нет доступа:** замените ключ в подключении и проверьте его права у провайдера. Не отправляйте ключ в чат или журнал.

**Медленно или не хватает памяти:** закройте тяжёлые приложения, уменьшите контекст в дополнительных параметрах либо выберите меньшую модель.

**Чат работает, поиск — нет:** проверьте отдельное подключение эмбеддингов, его назначение и состояние индекса документов.

## Документы

### Наблюдение за файлами и автоиндексация

При подключении папки оставьте включёнными **Подготовить документы для поиска** и **Обновлять при изменениях в папке**. ЛЕС сам обновляет поиск. Для уже подключённой папки параметры доступны через **Наблюдение и журнал**. Проверка выполняется каждые 15 секунд, пока работает LES RAG. Обработка начинается после повторной проверки стабильности. Журнал показывает добавленные, изменённые и удалённые файлы, время проверки и отказы. **Обновить журнал** загружает актуальное состояние. При недоступности папки обработка приостанавливается. История хранит последние 1000 событий на датасет; панель показывает последние 100. Проверка изменений использует размер и время изменения файлов; замена с сохранением обоих признаков пока требует ручной переиндексации.

## Начало работы

### Четыре шага — и можно работать

**1. Установите ЛЕС.** Поиск и база уже входят в комплект. **2. Подключите модель** в Настройки → Модели. **3. Добавьте папки** в Документы: ЛЕС подготовит поиск и будет следить за изменениями. Для смыслового поиска выберите также модель поиска. **4. Создайте проект**, выберите его документы и начните чат. Исходные папки доступны Лесу только для чтения. Для обычного разговора документы и проект не обязательны.

## Модели

### Как подключить модель

В **Настройки → Модели** выберите **Найти на компьютере** или **Подключить API**. ЛЕС найдёт запущенные локальные сервисы и предложит их модели. Для API нужны адрес сервиса, ключ при необходимости и модель. Выберите назначение и нажмите **Проверить и подключить**. Технические параметры находятся в подробностях.

### Модель чата и модель поиска

Модель чата пишет ответы. Модель поиска подготавливает документы для поиска по смыслу. Их назначения независимы: отвечающая модель может не поддерживать обработку документов. Выберите обе роли явно. Не меняйте модель поиска у готового индекса без проверки совместимости.

## Документы

### Добавить документы

Откройте **Данные**, выберите набор документов и добавьте файлы. Дождитесь завершения обработки. Метка **готово к поиску** означает, что документ доступен поиску; простая загрузка файла этого ещё не означает. Для документа, требующего внимания, откройте подробности и исправьте указанную причину.

### Как устроен набор документов

Набор объединяет связанные файлы. Внутри документа находятся разделы и фрагменты. Эта структура помогает открыть не только найденную цитату, но и её окружение. Храните документы разных задач в отдельных наборах и выбирайте нужную область поиска для чата.

### Проверить источник ответа

В ответе нажмите ссылку с названием документа и страницей или разделом, если они известны. Откроется панель с цитатой и кнопкой оригинала. Название берётся из найденного источника. Цитата показывается целиком, без обрезки до короткого превью. Сверяйте важные выводы с документом. Если подходящего источника нет, уточните вопрос или добавьте недостающий файл.

## Проекты и память

### Зачем нужны проекты

Объединяйте чаты одной задачи в проект. Перед вопросом проверяйте выбранный проект и набор документов: они определяют контекст работы. Названия проектов и чатов лучше делать короткими и понятными — например, по объекту или теме.

### ЛЕС помнит

В памяти чата видно, что ЛЕС помнит о разговоре. Он автоматически сжимает старую часть беседы, выбирая точные исходные записи; последние реплики остаются целиком. Сводку можно исправить, обновить вручную или отключить. **Забыть контекст** исключает прежние реплики из следующих ответов, сохраняя историю. Отдельные записи памяти проекта сохраняются независимо. Память помогает продолжать работу, но не является доказательством — факты проверяются по документам.

## Профили и скиллы

### Профиль и скилл

Откройте **Настройки → Профили**. Профиль объединяет инструкции, скилл, инструменты и параметры модели. Скилл описывает полезные правила работы с вашей задачей. Изменения сохраняйте новой версией, затем явно назначайте нужную версию активной. Базовая версия не редактируется.

## Интернет

### Поиск в интернете

Разрешайте веб-инструменты только тому профилю, которому нужен интернет. В вопросе можно попросить найти актуальную информацию и привести ссылки. Проверяйте дату публикации и открывайте первоисточники. Без подключения к сети веб-поиск недоступен.

## Почта

### Подключить почту

Откройте **Почта → Подключить почту**. Для почтового сервиса используйте IMAP с защищённым соединением и способом авторизации, который разрешён провайдером. Секрет вводится в поле пароля подключения; не отправляйте его в чат. Каждый почтовый аккаунт получает отдельный набор документов.

### Яндекс Почта

Разрешите IMAP в настройках Яндекс Почты. Используйте пароль приложения, если такой способ разрешён для вашей учётной записи. В настройках Light выберите Яндекс и укажите адрес почты. Для IMAP используется **imap.yandex.ru**, порт **993**, защищённое соединение. При отказе входа проверьте настройки аккаунта у Яндекса.

### Классический Outlook

Откройте классический Outlook с настроенной почтой, затем в Light нажмите **Забрать новые письма**. Сборщик работает от вашего пользователя Windows. Это подключение относится к классическому Outlook; поддержка нового Outlook и Outlook.com через OAuth требует отдельной реализации.

### Что Light делает с письмами

Почтовый модуль читает письма и вложения для поиска. Он не отправляет ответы, не пересылает и не удаляет письма на сервере. Выберите нужный аккаунт перед поиском. Ссылка **Открыть в Outlook** доступна для оригиналов, полученных из классического Outlook.

## Если что-то не работает

### Модель не отвечает

Откройте **Настройки → Модели → Проверить**. Убедитесь, что сервис запущен, адрес указан верно и нужная модель доступна. Для удалённого сервиса проверьте интернет и срок действия ключа. Для локального — достаточно ли свободной памяти. Повторите простой вопрос после исправления причины.

### Документ есть, а ответ не найден

Проверьте, что выбран нужный набор, а документ готов к поиску. Уточните вопрос названием раздела или предмета поиска. Если обработка не завершилась, откройте подробности документа. Не запускайте полную повторную обработку всех данных ради одного файла.

### Установка или обновление не завершились

Закройте окна Light и повторите действие. Если не хватает места, освободите его на системном диске. При сообщении о повреждённом пакете скачайте установщик заново из официального репозитория. Не удаляйте папку с документами. Не отключайте защиту Windows ради запуска неизвестного файла.

### Сообщение о занятом порте

Порт — локальный адрес компонента приложения. Он может быть занят другой программой. Не завершайте чужие процессы и не меняйте их настройки. Light должен выбирать свободные порты своих компонентов; если запуск всё же не удался, сохраните сообщение диагностики и повторите запуск.

## Установка и удаление

### Как удалить LES RAG

Используйте **Параметры Windows → Приложения → LES RAG → Удалить** либо ярлык удаления. По умолчанию документы, почта и настройки сохраняются. Отмечайте пункт удаления всех данных только если они больше не нужны: это действие нельзя отменить.

**0.1.0** — первый выпуск LES RAG для Windows. Проверки компонентов не заменяют проверку приложения целиком. Результаты конкретной сборки указаны в отчёте поставки. Проверка реального почтового аккаунта, чистой Windows и обновления из публичного GitHub-выпуска проводится отдельно. Официальный репозиторий: [proovcme/LES](https://github.com/proovcme/LES).
