# Версии LES RAG

Источник версии — [config/version.json](../config/version.json).

| Поле | Значение |
|---|---|
| Версия продукта | `0.1.3` |
| Номер сборки | `957` |
| Версия пакета Tauri/NSIS | `0.1.3` |

Windows x64, WebView2 Evergreen. Штатный Windows-путь — Rust runtime/API и
Svelte/TypeScript. Отдельная среда Python 3.13.12 загружается при запуске
первого одобренного скрипта внешнего навыка. PDFium входит в основной комплект.
Собственный Qdrant Server 1.19.1 закреплён в `config/light-runtime.json`;
нативный Edge поддерживается отдельной сборкой. Конкретный backend и приёмка
эксперимента не выводятся из наличия библиотеки. Архивы закреплены SHA-256
в config/. Docker не требуется.
Ollama и совместимый OpenAI API подключаются пользователем; веса моделей
в пакет не входят. Роли чата и поиска назначаются явно.

Rust-зависимости закреплены в Cargo.lock соответствующих компонентов:
`core`, `api`, `runtime`, `parsers`, `vector`, `desktop/light/src-tauri`.
PDF читает нативный PDFium; Word — Docling, PDF-таблицы — Xberg в отдельном
процессе парсеров. Сканы используют Windows OCR с установленными языками;
наличие обработчика не подтверждает качество каждого сложного рисунка.
MSG читает нативный Windows-обработчик. Прежние Python-библиотеки чтения
остаются в среде совместимости и проверках, а не в штатном Windows API.

Python-зависимости среды разработки/совместимости и подготовки навыков
закреплены в uv.lock; сборка использует uv export --frozen и проверку хешей.
Фактический состав автономного исполнителя навыков фиксируют его квитанция
и файловый инвентарь. Python в репозитории не равен Python в Windows-приложении;
границы Python-совместимости указаны в [плане переноса](modules/python-exit.md).

Изменение зависимости требует обновления lock, make verify, make test,
make test-mail и повторной приёмки установленного приложения.
Лицензии поставляемых компонентов входят в THIRD_PARTY_NOTICES.
