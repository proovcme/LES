# Выпуск LES RAG для Windows

1. Поднять номер сборки в `config/version.json` и выполнить
   `make version-sync`. Перед пушем должен пройти `make pre-push`.
   Открыть PR и дождаться **LES merge gate** на актуальной ревизии.
2. Запустить **LES RAG candidate package** для исходников кандидата.
   Дождаться сборки установщиков и обеих проверок Windows. Они покрывают
   чистую установку, обновление, сохранение диалога и откат. Сверить
   дерево исходников кандидата с деревом после мержа.
3. По принятому полному EXE пройти затронутый пользовательский путь.
   Для поиска проверить модель, вопрос по папке, фактические фрагменты,
   источники и открытие оригинала. Для изменений других функций проверить
   их рабочие сценарии отдельно. Записать область проверок и ограничения
   в [журнале выпусков](RELEASE_LEDGER.md).
4. Собрать черновик выпуска с проверенными полным и сетевым EXE,
   `install-les.ps1`, `light-update.json` и `SHA256.txt`.
   Сверить версию, номер сборки, размер и хеш полного EXE с манифестом.
   Приложить краткое описание изменений и известные ограничения.
5. Опубликовать по прямой команде владельца. Проверить скачивание по тегу,
   целостность файлов и загрузку через `install-les.ps1 -ReleaseVersion <версия> -DownloadOnly`.
   Сетевой EXE скачивает свой тег. Установленные клиенты проверяют
   последний основной выпуск, поэтому пре-релиз доступен через страницу выпусков.

Установку, обновление и откат проверять на отдельной Windows-среде. Исходные
документы доступны для чтения. Откат сохраняет индекс, память, настройки
и историю. Публичные материалы содержат только проверяемые результаты,
лицензии и ограничения.
