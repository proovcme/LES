# Нативное чтение страницы PDF

В кандидате 821 `core/src/document_source.rs` также разрешает загруженные
оригиналы из собственного `storage/datasets`. Сервер передаёт корень отдельно
от аргументов модели. Селекторы берутся из SQLite; проверяются путь набора,
компоненты имени и выход через junction/symlink. Отсутствующий внешний оригинал
не заменяется одноимённой внутренней копией. Общий сервис оригиналов теперь
тонкий кодек C ABI; PDF reader использует ту же Rust-проверку.

`read_pdf_source` читает физический оригинал через Rust/PDFium. Python остаётся
тонким адаптером текущего чата и реестра инструментов. Рабочая установка этим
изменением не переключается на Edge и не обновляется автоматически.

## Контракт

Обязателен `page` — номер физической страницы начиная с 1. Документ выбирается
по настоящему `doc_id` либо точной паре `dataset_id` + `doc_name` из каталога.
Модель не задаёт путь или базу. Rust разрешает идентификаторы в SQLite только
на чтение и отвергает конфликтующие селекторы/неоднозначные имена.

`source_sha256` закрепляет редакцию. Если он не передан, требуется валидный
SHA-256 каталога. Проверки до и после PDFium выполняются на одном открытом
файле. В Windows дескриптор не допускает запись/удаление во время чтения.
Результат содержит реальные `doc_id`, `dataset_id`, `doc_name`, страницу и хеш.
Изменившийся PDF не подменяется сохранёнными фрагментами индекса.

Есть два режима получения текста:

- Без `q`: порции страницы, по умолчанию 6000 символов. `offset`, `next_offset`,
  `total_chars` и `complete` явно описывают полноту. При запросе целой страницы
  модель должна дочитать все порции. Проверка интервалов в Rust не допускает
  итогового ответа после незавершённого чтения или смешения редакций.
- С `q`: короткая буквальная строка, а не вопрос на естественном языке. Rust
  ищет её в текстовом слое выбранной физической страницы без учёта регистра,
  возвращает ограниченный контекст с точным смещением и `selection=literal_match`.
  Это доказательство конкретного места, не полная проверка страницы. Отсутствие
  строки — ошибка, не повод искать ответ в индексе.

Максимальная порция — 12000 символов, файл — 512 МиБ, документ — 10000 страниц.
Пустая страница, скан без доступного текста, неверная страница, отсутствие файла,
несовпадение редакции и недоступность worker имеют отдельные коды и понятные
сообщения. OCR и визуальная интерпретация чертежа остаются отдельными функциями;
этот инструмент не выдаёт отсутствие текстового слоя за успешное чтение.

## Привязка и ошибки

`core/src/harness_evidence.rs` восстанавливает селектор только по однозначному
provenance: точное имя/базовое имя/основа PDF-имени/известный ID. Конфликтующий
или незнакомый файл не заменяется выбранным. Явный хеш запроса сохраняется.
Для исполнения чат передаёт фактически выбранные dataset IDs вместо `*`.

Нативный outcome guard считает `missing`, `error`, `blocked` и `partial` при
чтении источника неуспехом. Чат прекращает генерацию и отправляет публичную
ошибку. Исключение из чтения не проглатывается общей веткой optional tools.
Текст выбора инструмента буферизуется до решения, чтобы он не остался готовым
ответом после неудачного вызова. Штатная финальная генерация сохраняет streaming.
Проверка полноты страницы выполняется также до принятия terminal answer модели.

Порция физического PDF попадает в evidence с отдельной идентичностью
`doc_id + SHA-256 + page + offset`, не с выдуманным Qdrant point ID. Это исключает
попытку дочитывать физический фрагмент как точку векторной базы. Локаторы и
панель источника получают проверенную страницу и редакцию.

## Файлы

- `core/src/pdf_source.rs`: точный каталог, SHA-256, буквальный поиск внутри страницы.
- `api/src/pdf_text.rs`: PDFium worker, чтение одной страницы и границы текста.
- `core/src/harness_evidence.rs`: привязка источника, outcome, полнота чтения.
- `backend/pdf_reader.py`: тонкий вызов Rust worker, без Python fallback.
- `proxy/services/pdf_source_evidence_service.py`: адаптация evidence и ошибок.
- `proxy/services/tool_harness_service.py`: схема и регистрация инструмента.
- `proxy/services/chat_evidence_application_service.py`: граница ошибок чата.
- `tests/test_light_pdf_source_tool.py`: настоящие PDF, курсоры, хеши, сканы и селекторы.
