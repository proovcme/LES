# Подготовка фрагментов внутри Rust-партии

Кандидат 824 переносит финальную подготовку сырых узлов из штатного Python
адаптера в `core/src/document/nodes.rs` и `node_hierarchy.rs`. Форматный
обработчик возвращает сырые узлы; координатор сам ограничивает текст бюджетом
выбранного локального токенизатора, создаёт прежние ID, наследует заголовки,
строит навигацию и родителей, сохраняет соседний контекст. Классификация
формата/файла и начальное извлечение ещё retained-адаптеры Python.

Ответ моста 0 содержит `node_state=les.nodes.raw.v1`. Узлы передаются приватным
JSONL, а не многомегабайтным аргументом C ABI. Rust читает поток ограниченными
порциями и проверяет объявленное количество, каждую строку и общий объём.
После подготовки пишет отдельный `{spool_id}.prepared.nodes`; только этот
неизменяемый поток поступает в сборку точек и эмбеддинги. Прежний вход с уже
готовыми узлами сохранён для совместимости протокола, штатный адаптер его не
выбирает. Нужна capability `document_nodes`: старый DLL не принимает новый
сырой поток как готовый индекс.

Границы: 50 тысяч итоговых узлов, 8 МиБ на строку, 512 МиБ на поток. Сначала
проверяется конфигурация, затем захватывается партия. Нет скрытой замены
токенизатора на подсчёт символов. Для token-режима необходимы путь и SHA-256
текущего локального tokenizer.json; модель и её назначение не меняются.

Иерархия сохраняет прежнюю семантику: markdown/нумерованные заголовки, стек
предков, отдельные навигационные узлы, порядок групп страниц/таблиц, окна
обычного текста и окружение соседей. SHA-1 используется только для
совместимости прежних идентификаторов; оригиналы и редакции защищены SHA-256.
Новая библиотека `sha1=0.10.6` отдельно согласована владельцем.

Оба JSONL, точки и кеш удаляются по квитанции владельца и после аварии.
Подтверждённый документ не повторяется. Причины новых отказов берутся из
общего `config/extraction-errors.json`: один набор сообщений у Rust и
Python-адаптера. Файл включён в комплект runtime.

Паритет проверяется по полному JSON результата прежних функций, включая
ID, quality, типизацию, заголовки, родителей, навигацию и соседний текст.
Реальная копия индекса и ограничения — в [приёмке](../acceptance/native-node-preparation-824.md).
