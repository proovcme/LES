# Наблюдение за папками в Rust

В «Данные и проекты» при подключении папки доступно «Обновлять автоматически».
Для ранее подключённой папки можно включить режим, добавив её в существующий
набор. «Приостановить» останавливает следующие обходы, а уже взятое задание
завершает работу. «Возобновить» ставит сверку на ближайший цикл. Кнопка
«Подробнее» открывает путь и состояния файлов.

`POST /api/rag/index-external` с `background: true, watch: true` сохраняет
наблюдение. `GET /api/light/folder-watches` показывает папки, а параметр
`id` добавляет страницу файлов. `POST /api/light/folder-watches` с полями
`id` и `enabled` ставит наблюдение на паузу или возобновляет его.
Доступ к путям и управлению ограничен ролью администратора.

Реестр в SQLite использует владельца и очередь нативного импорта. После
запуска проверка становится просроченной. При успешной сверке следующая
проверка запланирована через минуту. После ошибки доступности повтор
запланирован через 20 секунд. Задания и обработка файлов выполняются
в пределах имеющихся ограничений. Плановая индексация использует
явно назначенную локальную модель поиска.

| Состояние | Что означает |
| --- | --- |
| Папка недоступна | Не удалось закончить обход. Прежний снимок и поисковые данные сохраняются. |
| Файл отсутствует | Полный успешный обход не нашёл ранее зарегистрированный файл. Его индекс сохраняется. |
| Новая редакция | Хеш обнаруженного содержимого отличается от хеша проиндексированной версии. |
| В поиске | Обнаруженный хеш совпадает с опубликованным, у документа есть фрагменты. |
| Ошибка индексации | Очередь сохранила ошибку обработки файла. |
| Проверка отложена | Во время обхода изменился состав папки или файл ещё записывался. |

Лес читает байты потоково, чтобы обнаружить подмену с прежними размером и
mtime. Для неизменившихся документов разбор, эмбеддинги и публикация не
повторяются. Windows и SMB учитывают блокировку на запись во время чтения.
После хеширования подтверждается полный состав папки, затем снимок
применяется одной транзакцией. Перед разбором проверяются путь и ожидаемый
хеш, существующий журнал проверяет файл повторно перед публикацией.
При недоступности папки снимок присутствия остаётся прежним.

853 проверяет просроченные наблюдения между партиями других наборов.
Непрерывная большая загрузка не откладывает появление задания сверки до
конца всей очереди. Ручное присоединение к уже созданному автоматическому
заданию сохраняет его публичную квитанцию после завершения.
