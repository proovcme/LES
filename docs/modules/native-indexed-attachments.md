# Индексация вложения и обнаружение моделей · 841

`POST /api/rag/attach?mode=index` сохраняет исходные байты в хранилище Леса и
регистрирует документ, задание и квитанцию в одной транзакции SQLite.
Работает в испытательном Rust-чате с включённым обработчиком индексации.
Совместимые поля ответа `attachment_id`, `doc_id` и `status` сохранены;
`intake_job_id` ведёт к `GET /api/light/intake?id=...`.

- Набор «Вложения чата» локальный (P0). Для этой загрузки нужна локальная
  модель поиска, назначенная явно. До назначения задание остаётся в очереди.
- Вложения одного набора обрабатываются последовательно. Отдельные оригиналы
  сохраняют собственные пути, даже если имена совпадают. SHA-256 исходника
  сверяется перед публикацией; чужая редакция не заменяет его.
- Ключ повтора привязан к клиенту и содержимому. Повтор возвращает ту же
  квитанцию; изменённый файл с прежним ключом отклоняется. Повтор после
  сбоя публикации не требует переустановки или смены модели.
- Только созданный заданием документ попадает в выборку. Статус «готово»
  устанавливается после публикации фрагментов, а не после загрузки байтов.

В 842 [выбор режима](native-settings-attachments.md) доступен в испытательном
Svelte-чате. До штатного переключения legacy-клиент сохраняет своего владельца.

## Обнаружение моделей

`POST /api/model-connections/discover-local` проверяет заданные loopback-порты
Ollama, LM Studio, Lemonade, FreeToken и совместимого API. Поиск не сканирует
LAN и не запускает движки. `POST /api/model-connections/discover-models` читает
каталог по указанному адресу, проверяет область адресов и соединение,
ограничивает время и размер ответа, не следует переадресации. Ключ из формы
используется только для этого запроса. Обнаружение не сохраняет подключение и
не назначает модель.

Оставшиеся операции настроек моделей, почта и часть инструментов/API ещё
используют прежний сервер. Штатный запуск и NiceGUI не переключены.
