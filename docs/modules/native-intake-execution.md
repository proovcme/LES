# Фоновое подключение папки без Python API

Кандидат 830. Целый путь фонового подключения `/api/rag/index-external` с
`background=true` принадлежит Rust: правила источников → обход → регистрация →
выбор партии → модель и параметры индекса → обработка → checkpoint → повтор.
Оба прежних внутренних FastAPI-обработчика политики/старта удалены вместе с
регистрацией router. Запуск партии больше не делает HTTP-запрос в Python.

| Владелец | Ответственность |
| --- | --- |
| `api/src/intake.rs` | OS lease очереди, правила папок, обход, запуск и понятные причины остановки |
| `api/src/index_batch/configuration.rs` | Снимок настроек, сохранённый контракт, локальный токенизатор и явная роль embeddings |
| `core/src/index_configuration.rs` | Совместимость модели, fingerprint, границ фрагментов и векторного пространства |
| `core/src/catalog/intake.rs` | SQLite manifest, прогресс, восстановление и ограниченный повтор ошибок |
| `api/src/index_batch.rs` | Полная партия без Python callbacks, общий исполнитель с ручным запуском |

Настройки читаются из окружения и принадлежащего экземпляру файла настроек;
в процесс партии передаётся только разрешённый список параметров. Ключи моделей
не входят в frozen request или результат. Модель берётся из сохранённой роли,
её ревизия закрепляется на партию. Нет роли — файлы остаются зарегистрированными
с причиной `EMBEDDING_MODEL_NOT_ASSIGNED`, без скрытой локальной замены.

Проверяются fingerprint существующего index-contract v3, модель, размерность,
коллекция, векторные имена, нарезка и SHA токенизатора, если он записан в контракт.
SHA считается независимо от порядка полей JSON, в том числе при включённом
Edge/`serde_json preserve_order`. Автозагрузки токенизатора нет. Сохранённый
символьный контракт остаётся символьным; непреднамеренная смена настроек
останавливает партию до изменения статусов документов.

Повтор возвращает в PENDING только ERROR с `retryable=1` и наступившим
`retry_after`, принадлежащие manifest задания и прежней привязке source_path.
Чужие документы, постоянные ошибки и ещё не наступившие повторы не затрагиваются.
Счётчик попыток и последняя причина сохраняются до следующего attempt-ticket.
Пустая выборка с ещё ожидающими документами ждёт, а не крутит очередь без паузы.

## Граница применения

Этот путь использует **уже настроенный индекс** и его сохранённый контракт.
Первичное создание/явное принятие коллекции пока остаётся частью прежнего
bootstrap. Без контракта возвращается `INDEX_NOT_CONFIGURED`, без автоматического
принятия чужого векторного пространства. Стандартный запуск приложения и загрузка
нестандартных auth-политик ещё имеют Python-зависимости; холодная проверка узла
использует поддерживаемый явный native auth-policy file.

Синхронное подключение с полным preview, слежение/синхронизация изменений,
специальные форматы, оставшиеся чат/API/classic и общий bootstrap ещё требуют
переноса. Новый узел не запускает прежний обработчик при неподдерживаемом формате:
он сохраняет явную причину `DOCUMENT_NATIVE_DISPATCH_REQUIRED`.
Опциональная модельная сводка `LES_DATASET_READER_AFTER_PARSE` — отдельная
незакрытая ветка: прежний автоматический reader после native intake пока
не запускается. Ручной reader/чтение при study остаются в совместимом слое.
До нативного переноса этой ветки кандидат не считается заменой всех режимов
импорта и не устанавливается вместо рабочего приложения.
Изолированный CPython внешних навыков сохраняется; его поставка не менялась.
