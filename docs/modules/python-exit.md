# Перенос основы Леса в Rust с сохранением автономных Python-навыков

840: [публичные вложения и внешний чат](native-public-attachments.md): Rust
принимает файлы и папки для чтения, сохраняет оригиналы с квитанциями и проверяет
происхождение данных перед внешним вызовом. Штатные Python-маршруты пока сохраняются
для индексации, расширенных форматов и оставшихся инструментов/API.

839: [публичный вход Rust-чата](native-public-chat.md) объединяет обычный HTTP
и SSE с нативной авторизацией, квитанциями и ссылками в истории. В испытательном
запуске не требуется Python API или NiceGUI. Штатное переключение и физическое
удаление прежнего приложения ждут паритета остальных функций.

838: [проверка документов](native-document-review.md) связана с общим Rust-чатом:
список, источники, передача текста, цитаты, зависимости и журнал выполняются
нативно. Заменённые Python-решения и общий SQLite-класс удалены; остаются кодеки.
Подтверждённые результаты инструментов переживают ошибку и восстановление чата.
Общий публичный чат/API и classic до полного паритета ещё не переключены.

837: [хранилище вложений и табличный журнал](native-chat-attachments.md) принадлежат
Rust. Из Python удалены самостоятельное управление оригиналами, Pillow-декодер
вложений, SQL/пакеты/решения по строкам, чтение окон и переходы состояния table_document.
Остаются IO-кодеки для текущих потребителей. Нативный кандидат чата принимает
multipart, проверяет реальный файл, передаёт изображения и ведёт таблицу без
приложения Python. Публичная загрузка, её квитанции и редкие форматы ещё требуют
переноса; публичный чат не переключён. Общий Python-exit не объявляется завершённым.

836: [автосуммаризация и команды](native-conversation-memory.md) выполняются Rust.
Перенесены весь модельный исполнитель сводки, последовательное чтение истории,
общие слоты, приоритет нового сообщения, durable outbox и восстановление.
Прежние Python-генератор/планировщик и недоступные ветви команд удалены;
остаются IO-кодеки для действующих потребителей. Общий публичный чат и прочие
API/bootstrap/classic ещё Python; перенос целого приложения не объявляется завершённым.

835: [общий испытательный чат](native-chat-turn.md) соединяет HTTP/SSE, подготовку,
модель, инструменты и историю без приложения Python. На копии проверена настоящая
Qwen с поиском и физической страницей PDF; автономный внешний навык также проверен
через нативный чат. Оригиналы GET/HEAD выдаёт Rust. До публичного переключения
остаются специальные инструменты/политики/вложения/автосуммаризация и паритет режимов.
Действующий общий чат, остальные API/bootstrap/classic пока сохраняют Python;
их нельзя удалять до переноса потребителей. Полный Python-exit ещё не достигнут.

834: [подготовка контекста чата](native-chat-context.md) перенесена в Rust:
профиль/память, целые объекты, обязательные результаты, покрытие разделов,
сообщения и отчёт о реально видимых источниках. Python-решения из двух модулей
удалены, остаются кодеки. Общий HTTP/application путь чата, специальные
обработчики, реестр промптов, bootstrap и classic ещё требуют переноса.

833: [основной первый индекс](native-index-setup.md), его контракт и создание/
миграция FTS выполняются Rust. Новый Edge не требует предварительного импорта.
Python layout, его вспомогательные решения и DDL миграции удалены. Общий bootstrap,
оставшийся чат, дополнительные RAG-построители, специальные форматы и classic открыты.

832: [холодный допуск к API](native-access-bootstrap.md), proxy/CORS и preflight
выполняются Rust. Три Python callback endpoints и HTTP fallback удалены. Обычному
старту нативных маршрутов больше не нужен вручную подготовленный auth-policy файл.
Runtime ещё запускает старый backend/NiceGUI для остальных сценариев; создание
первого индекса и полный bootstrap приложения остаются открытыми.

831: [навигационный model reader](native-dataset-reader.md) перенесён целиком:
каталог/контекст, модель, проверка, очередь, CAS и восстановление. Python-цикл,
подготовка и запись результата удалены; остаются только совместимые IO-функции.
Нативный batch публикует durable outbox в своей транзакции, поэтому автозапуск
не зависит от сохранившегося Python/HTTP-клиента. Typed/topic map и остальная
notebook-обвязка ещё имеют прежний код; это не весь API.

830: [полный фоновый intake для настроенного индекса](native-intake-execution.md)
проверен без приложения Python: правила папок, регистрация, замороженная
конфигурация/роль модели, запуск партии, повторы и аварийное восстановление.
Удалены два прежних внутренних HTTP-обработчика и их регистрация. Синхронный
preview/синхронизация папок и первичная настройка индекса ещё остаются;
остальной API/bootstrap/classic и специальные форматы не объявляются закрытыми.

829: [нативный HTTP-исполнитель целой партии](native-table-dispatch.md) соединяет
конвертацию, эмбеддинги и публикацию без Python callbacks. Нормализация/Parquet
и активные ссылки редакций перенесены. Граница приёмки — изолированный сквозной
запуск без Python приложения. Общий intake, специальные форматы и штатная обвязка
ещё не закрыты; это не завершение миграции всего API.

828: [Excel/CSV/PPTX](native-format-conversion.md) читаются отдельным Rust worker.
Структурный XLS-путь больше не требует Pandas → временный XLSX. Классификация,
нормализатор/Parquet, специальные узлы и общий форматный диспетчер ещё Python;
чат/API/bootstrap/classic остаются следующими владельцами переноса.

827: [встроенный Excel-расчёт](native-builtin-calculations.md) перенесён в Rust;
[автономная поставка внешних скриптов](skill-runtime-package.md) имеет отдельный
комплект и единый Rust-selector launcher/API. Реальный одобренный скрипт
проверен на копии, его содержимое в публичную часть не переносится.
Общий app runtime ещё нужен форматам и оставшимся HTTP/UI/чат-обработчикам.

826 переносит [исходные узлы PDF и Markdown](native-source-nodes.md): страницы,
части, ID, начальные бюджеты и provenance. Форматный процесс/классификация,
сложные извлекатели и специальные узлы ещё требуют переноса; это не конечный
Python-exit. Короткие физические страницы теперь сохраняются и после finalizer.

825 переносит [JSON/JSONL](native-json-sources.md) в Rust. UTF-декодирование нативное; legacy-детектор кодировок ещё Python. Нужна миграция старых JSON-индексов.

824 переносит [финальную подготовку узлов](native-node-preparation.md) внутрь Rust-партии. Начальное извлечение и классификация формата остаются отдельной границей.

823 переносит [управляющие циклы основного чата](native-chat-loop.md): модель/инструменты, бюджеты, дочитывание PDF и финальные попытки. Промпт/evidence, специальные обработчики и HTTP-обвязка ещё Python; это не окончательный Python-exit.

822 переносит [штатный координатор партии](native-index-batch.md): выбор,
попытки, состояния, проверку регистрации/оригинала и решение публикации.
[Реальная копия и границы](../acceptance/native-index-batch-822.md).
Форматная подготовка, привязки и прежний путь без native publisher ещё остаются.

821 переносит библиотеку/исполнение/восстановление старых навыков и исходящий
MCP HTTP/stdio в Rust. Нативные настройки MCP работают без Python backend;
скрипт исполняется отдельным CPython без импортов приложения.
[Контракт и границы](native-skills-mcp.md).
Допуск инструментов, схемы, подтверждения, идемпотентность, SQLite и полные
результаты также перенесены в [Rust](native-tool-execution.md). Асинхронный
диспетчер старых обработчиков остаётся адаптером; это не удаление общего runtime.

В том же кандидате 820 удалены прежние реализации хранения/проверки профилей
и файлового обхода. Вместо них — Rust core и нативные HTTP-пути профилей и
реестра. [Контракт](native-profiles-files.md). Холодное восстановление Edge
тоже больше не вызывает прежний Python-обработчик.

820 убирает Python из нормализации/лексической подготовки, локального
BGE-M3 и канонического исполнения эмбеддингов. Продуктовый `vector/`
выполняет Edge + точный BM25 + иерархию; API дочитывает родителей с проверкой
поколения. На копии 43 219 точек этот путь работает без Python backend.
[Контракт и оставшиеся границы](native-edge-embeddings.md),
[проверенные сценарии](../acceptance/native-edge-embeddings-820.md).
Перенос всего приложения этим не объявляется завершённым.

Кандидат 819 переносит модельные пресеты, формирование запросов, чтение ключей,
проверку возможностей, внешний модельный HTTP и разбор потоков в Rust.
Поиск в интернете и обычное чтение страницы также нативные.
[Контракт и незакрытые границы](native-web-inference.md).

Кандидат 818 переносит целиком SQLite-реестр моделей (создание, импорт,
ревизии, роли, снимки возможностей и аудит), SQL списков истории и общие
проверки доверенных сетей. Пять дополнительных HTTP-пар обслуживает Rust;
отдельно проверен холодный запуск без Python backend с явным файлом политики.
Штатный runtime ещё не формирует эту политику и продолжает запускать Python.
[Контракт](native-model-registry.md), [приёмка](../acceptance/native-registry-history-818.md).

Текущий критерий завершения остаётся открытым. Для удаления общего runtime
необходимо последовательно закрыть все границы:

- модельный цикл, поток, отмена, исполнители встроенных и MCP-инструментов;
- HTTP-настройка подключений с проверками адреса, peer, возможностей и секретов;
- полная партия документов: оставшиеся форматы/OCR, иерархия и локальные модели
  эмбеддингов без запуска общего Python-обработчика;
- оставшиеся API и classic/NiceGUI-экраны с сохранением пользовательских путей;
- отказ от оставшегося Python bootstrap; реальная политика доступа уже читается
  самим Rust API в 832, без Python callback;
- автономный совместимый CPython только для одобренных старых навыков;
- удаление общего окружения и серверных зависимостей из пакета после проверки
  чистой установки, CLI/MCP, обновления и восстановления на копии корпуса.

Генерируемая [карта Python](../CODE_RUNTIME_MAP.md) показывает достижимость
модулей, включая совместимые фасады, тесты и инструменты; она не доказывает
процент готовности. Файл удаляется после переноса всех его потребителей,
а вызов общего кода через процесс навыков не считается переносом.

Вычисления BGE-M3 и нормализацию в 820 повторно переносить не нужно.
Другие локальные модели/OCR требуют собственной проверки поддерживаемых
ресурсов. Пока эти строки не закрыты пользовательским путём на чистой машине,
общий Python нельзя удалять из установки или объявлять перенос завершённым.

Кандидат 817 переносит SQL-чтение и сборку истории сообщений в
`core/src/catalog/history_view.rs`, сохраняет причину ошибки в Rust SQLite и
продолжает выбранные физические страницы через нативный курсор. В Python
остаются тонкие вызовы этих операций и остальная оркестрация чата.
[Контракт](pdf-cursors-history.md), [приёмка](../acceptance/pdf-cursors-history-817.md).


В 814 Rust очищает фрагменты и проверяет бюджет эмбеддера после разбора
документа. Сохраняются границы, метки качества и SHA-1 ключи прежних
фрагментов. Rust собирает нормализованные события обоих потоков чата в
ответ, включая аргументы инструментов, статистику и признак завершения.
Транспорт и исполнители инструментов продолжают вызываться из Python.
Контроль на 227 сохранённых фрагментах дал равные результаты в символьном
и токенном режимах. В локальном release-замере медиана токенной подготовки
составила 153 мс против 278 мс, символьной — 23 мс против 14 мс. На копии
прежнего Qdrant оба вектора контрольного документа взяты из кеша.
Изолированный чат подтвердил доставку дельт, сборку аргументов и ошибку
при закрытии потока без события завершения.

В 813 Rust читает очередь ручного запуска из SQLite, разрешает внутренние
и внешние пути и считает оставшиеся документы. Состояние файла до разбора
и его SHA-256 берутся с проверенного дескриптора Rust. Штатная запись
не создаёт синхронный Python-клиент Qdrant. Python ещё вызывает парсер,
строит иерархию и связывает этапы партии. Совместимый режим для других
хранилищ сохраняет прежний исполнитель. [Контракт](auto-parse-resume.md).

В 812 Rust читает кеш плотных векторов из собственного Qdrant с фильтром
по файлу, набору и отпечатку эмбеддера. Между Rust API и ядром данные
проходят через ограниченный двоичный файл. Python связывает вызовы и
выбирает подключение для новых векторов. При недоступности или повреждении
кеша Rust заново запрашивает необходимые эмбеддинги.
[Контракт партии](auto-parse-resume.md).

В 811 Rust рассчитывает исторический TF-вектор Qdrant при сборке точек
и для запросов к совместимым коллекциям. Сохраняются частоты, идентификаторы
терминов CRC32, различие кириллицы и латиницы и запасной разбор коротких
обозначений. Фрагмент без поисковых терминов пропускается до эмбеддинга.
Полноценный BM25 по-прежнему считает отдельный индекс SQLite.
[Публикация и восстановление](auto-parse-resume.md).

В 810 Rust принимает подготовленные фрагменты порциями, выбирает промахи
кеша, заказывает для них векторы, проверяет их размерность и собирает
точки с исходными ссылками. Полный файл точек передаётся существующему
Rust-владельцу публикации только после успешной подготовки. Ручные
запуски любого разрешённого размера используют нативные попытки.
Python пока читает кеш Qdrant, готовит иерархию и совместимый sparse-вектор,
выбирает подключение эмбеддингов и обслуживает оставшиеся парсеры.
[Контракт партии](auto-parse-resume.md).

В 809 Rust сохраняет исключение реплики по чату, номеру хода и роли.
Фильтр работает до выборки контекста, сводки, поиска старых ответов и
воспроизведения результатов инструментов. Изменение закрывает ревизию
уже запущенной сводки. Если сводка охватывала эту реплику, она собирается
заново от существующей границы истории. Переписка хранит обе реплики.
Rust API также выдаёт безопасное представление сохранённых пакетов контекста.
Отправку модели и её статистику пока фиксирует Python-координатор чата.
[Интерфейс](svelte-desktop.md) и [контракт API](native-api.md).

В 808 Rust выдаёт разрешения на попытки обработки документов фоновой партии
и ограниченного ручного запуска в штатном профиле.
Токенизатор Hugging Face читает локальный `tokenizer.json` и считает токены
внутри Rust, в том числе во время нарезки. Существующие символьные индексы
сохраняют режим. Rust также читает прямоугольные таблицы Word, запускает
подключённый Tesseract и выполняет прямые запросы эмбеддингов с помощью
системного TLS-клиента по проверенным адресам.

В Python остаются подготовка и сборка точек одного файла, ручной обход папок,
сложные структуры Word и другие форматы, часть OCR-движков,
разрешение секретов и совместимость прокси и пользовательских сертификатов.
[Восстановление партии](auto-parse-resume.md).

Кандидат 807 переносит нарезку Markdown, текстовых пунктов и страниц PDF в Rust.
Если доступен токенизатор назначенной модели, адаптер отдаёт Rust только длину
в токенах. Rust извлекает обычные абзацы и заголовки DOCX. В Windows он читает

Уточнение владельца 01.11.2026: требуется автономная работа всех прежних
Python-навыков. Поэтому буквальное отсутствие любого Python-движка в поставке
больше не является достижимым критерием при сохранении совместимости. Цель:
Rust/Tauri, TypeScript, нативный Qdrant и обработчики; отдельный совместимый
локальный Python-исполнитель только для одобренных навыков. Нельзя называть такую
поставку полностью свободной от Python. Внешний обработчик вместо автономности
владельцем отклонён. Это целевая граница, а не описание готового build 775.

Python не должен оставаться владельцем API, поиска, индекса, папок, очередей,
восстановления или UI. Нельзя переносить эти функции в исполнитель навыков и
называть это миграцией. Прежний контракт навыков: одобренный hash/entrypoint,
изолированный процесс, JSON-входы, Decimal и доступные прежним скриптам библиотеки,
построчное сохранение и лимиты. Набор библиотек исполнителя определяется по
совместимости одобренных скриптов; нельзя обещать stdlib-only и молча лишить
существующий навык pandas или другого ранее доступного модуля.
Самовольная подмена совместимости RustPython/упрощёнными формулами не допускается.

Порядок: стабилизировать границы обработки и измерения → закончить frontend →
переносить API и хранилища небольшими совместимыми вертикальными сценариями →
заменять форматные адаптеры → удалить общий Python runtime и его серверные зависимости,
оставив выделенную совместимость навыков. Не держать две
активные записи одного индекса или две очереди. Существующие журналы, модельные роли,
локальные данные и доказательства сохраняют свои контракты.

[Windows OCR](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine.trycreatefromuserprofilelanguages)
для установленного системного OCR. Наличие библиотеки не доказывает паритет:
нужно проверять объединённые ячейки/формулы, таблицы PDF, страницы/координаты,
кодировки, старые Office/MSG/PST и вложения. Замену Docling и сложной структуры
документа нельзя объявлять эквивалентной по одному успешному извлечению текста.

Критерии готовности: чистая Windows без системного Python, с поставленным
изолированным исполнителем навыков; исходные папки
доступны только для чтения; успешные импорт/переиндексация/поиск/цитата/оригинал;

не теряет прежний индекс; обновление и откат сохраняют пользовательские данные.

одном корпусе. Один язык сам по себе эти результаты не гарантирует.
