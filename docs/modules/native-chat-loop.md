# Нативный владелец цикла поиска, инструментов и ответа

Кандидат 823 подключает основной чат к `core/src/agent_loop/`: решения о
следующей итерации, бюджете, повторном вызове, дочитывании PDF и финальной
попытке принадлежат Rust. Это ещё не удаление всего Python из чата.

`les_core_research_run` принимает `les.chat-research.v1`. Мост 0 выполняет один
модельный запрос, мост 1 — один допущенный инструмент. Мост не выбирает следующий
шаг. Перед вызовом инструмента Rust связывает параметры с явно выбранными
наборами/документами и provenance. Имена файлов не заменяют ID каталога;
пользовательский вопрос не становится буквальным поиском по странице PDF.

Частично прочитанная физическая страница дочитывается курсором без лишнего
модельного запроса. Перед финальным ответом проверяется полнота чтения. Ошибка
источника, смена редакции или неизвестный нативный инструмент останавливают цикл.
Повторные действия отсекаются по аргументам и ревизии рабочего состояния.
Изменение документа/рабочих файлов допускает новое чтение; прежняя неудача не
разрешает бесконечно повторять тот же вызов.

Тот же ABI с `les.chat-answer.v1` управляет финальной генерацией: максимум две
попытки, вторая только после пустого текста и со строгим контекстом. Ошибка
транспорта не вызывает повтор. Вызов инструмента после закрытия бюджета не
публикуется как обычный ответ. Готовый ответ из исследовательского шага
сохраняется и повторно не запрашивается.

`proxy/services/native_research_loop_service.py` связывает синхронный ABI с
асинхронным IO текущего запроса. Сохраняет исходное исключение и его detail;
отмена запроса отменяет ожидающий IO и прекращает новые шаги. Это не откат уже
подтверждённого файлового действия. Состояние управляющего цикла принадлежит
одному запросу и не переживает его завершение.

Отмена ожидания не гарантирует принудительную остановку уже исполняющегося
синхронного обработчика. Он может завершить действие после отмены клиента;
подтверждённый эффект определяется квитанцией и ревизией, а не исчезновением
индикатора. Полная отмена каждого специального обработчика ещё требует приёмки.

Остаются Python-адаптеры подготовки промпта и evidence packet, специальные
обработчики таблиц/проверки документов, подготовка ответа и HTTP-обвязка.
Перенесённый модельный транспорт, инструменты и память вызываются через эти
адаптеры. API/bootstrap/classic и конечная упаковка требуют отдельной приёмки.
Автономные старые навыки сохраняются отдельным CPython под нативным host.

Проверки: Rust unit, `tests/test_light_native_research.py`, регрессии физического
PDF/контекста/старых навыков и [приёмка кандидата](../acceptance/native-chat-loop-823.md).
