# Нативный поиск и локальные эмбеддинги

Кандидат 820. Рабочее хранилище не переключено. Изолированный путь
`текст → tokenizers/ORT → Edge + BM25 → RRF → родительские разделы`
работает без общего Python-сервера и без процесса Qdrant Server.
Это не означает окончания переноса остальных функций приложения.

## Хранилище и публикация

`vector/` — продуктовый Rust-модуль с Qdrant Edge 0.9.0. Один процесс
владеет каталогом через файловую блокировку. Миграция читает отдельный
экспорт JSONL, сверяет SHA-256, сохраняет курсор только после flush,
затем проверяет каждый идентификатор, payload и вектор. Прерванная партия
повторяется по тем же ID. Незавершённое хранилище не открывается для поиска.

BM25 сохраняется в SQLite postings; терминология и оценки совместимы.
Начальный перенос строит postings целиком. Дальнейшая публикация использует
существующий журнал поколений и пересчитывает только изменённые области.
Число записей BM25 проверяется по точному count Edge. Падение между записью
векторов и публикацией postings оставляет восстановимый журнал, а не готовый
поисковый индекс. Повреждённые postings не заменяются молча пустой базой.

При холодном запуске Edge Rust API сам восстанавливает журнал публикации.
Во время восстановления индексные запросы получают `INDEX_RECOVERING`,
остальные нативные разделы API доступны. Фоновая очередь ждёт восстановления.
Авария самого восстановителя сохраняет `INDEX_RECOVERY_OWNER_FAILED`, не вечное
ожидание. Staging откатывается, committing завершается,
прерванный BM25 перепубликуется. Регистрация документа проверяется до изменения
индекса и повторно в транзакции каталога. При конфликте или отсутствии новых
точек журнал сохраняется, индекс остаётся закрытым, причина пишется в лог.
Старый журнал без идентификатора документа требует явного восстановления;
он не объявляется исправленным автоматически.

Поиск использует прежний коэффициент RRF: 2 для dense/BM25. Мягкая иерархия
сохраняет глобальную ветвь, использует навигационные узлы только для маршрута
к потомкам и объединяет доказательства с прежним коэффициентом 60.
Старые точки без `node_role` сохраняются в глобальном поиске доказательств;
точки с явным `evidence_admissible=false` не допускаются в эту ветвь.
Родительское чтение проверяет поколение до и после операции, идентичность
найденного фрагмента и SHA-256 соседних фрагментов. Чужая редакция не становится
контекстом найденной страницы.

`les-api --edge-storage ABS_ROOT` требует сборку с `--features edge`.
`les-runtime --native-api --edge-storage ABS_ROOT` не запускает Qdrant Server.
Остальные службы штатного запускателя пока сохраняются. Совместимый HTTP-мост
не поддерживает создание/удаление коллекций, изменение alias и снимки;
это ограничения кандидата, а не завершённая замена серверной установки.

## Исполнение моделей

`core/src/embedding_native.rs` использует утверждённые `tokenizers` и `ort`.
Манифест `les.embedding-worker.v1` явно задаёт модель, tokenizer, DLL/библиотеку
ONNX Runtime, ONNX и external data с SHA-256, выход модели, pooling,
нормализацию, размерность и предел входа. Загрузок из сети нет.
Слишком длинный вход отклоняется без скрытого усечения.

Исполнитель — отдельный `les-api --serve-embeddings ABS_SPEC`, которым
управляет Rust worker host: ограничение памяти, очередь, срок, остановка,
повторное использование и освобождение после простоя. Допуск нового
ML-процесса сохраняет порог 4 ГиБ свободной RAM; ограничение процесса 8 ГиБ.

Для штатного назначения манифест закрепляет `connection_revision_id`.
Другая модель, размерность или ревизия не допускает перехода к HTTP.
Канонический приватный `/api/light/internal-inference/embeddings` сам читает
закреплённую ревизию/возможности и разрешённый секрет из Rust. Внешние
Ollama/OpenAI-запросы тоже выполняются Rust с закреплёнными адресами,
проверкой локальности и ограничением ответа. Явно подключённый локальный
манифест не заменяется сетевым провайдером после ошибки.

## Unicode

Нормализация NFKC, полный casefold и подготовка лексических терминов теперь
имеют одного владельца в Rust. Замороженные таблицы Unicode 15.1 сохраняют
поведение прежнего индекса. `tools/generate_native_unicode.py --check` —
только инструмент разработки, установленное приложение его не запускает.
Лицензия таблиц включена в `licenses/Unicode-LICENSE.txt`.
