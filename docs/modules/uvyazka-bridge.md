# Увязка: инженерные источники и вьювер

Кандидат 880, продолжение 879. Отдельный адаптер к установленной Увязке, без CAD-декодеров в LES.
Рабочая установка и её индекс не переключены.

`Увязка → проверенный снимок → штатная очередь LES → BM25 + dense → общий контекст → источник → вьювер`.

## Владельцы

Увязка читает зарегистрированные DWG/RVT/IFC/DXF и другие поддерживаемые её
читателем форматы. Наличие расширения не доказывает полного чтения.
LES импортирует сохранённые `UvyazkaModelData`, не меняет оригиналы и не включает
сторонний GPL-декодер в свой пакет. Чтение выполняется в Увязке, включая явный
запуск из LES через «Прочитать и добавить в поиск».

`api/src/engineering.rs`: явные `POST /api/integrations/uvyazka` с действиями
`projects`, `datasets`, `sources`, `read_import`, `import`, `viewer`. MCP `uvyazka_integration` вызывает
тот же API. Дальнейший поиск — обычный `search_sources`, без второго конвейера.
Только явно указанный loopback HTTP-порт, без учётных данных, proxy и redirects.
Адрес запоминается в браузере; данные документов туда не копируются.

## Целостность

`engineering/registered.rs` получает зарегистрированные файлы и возможности
читателей, показывает недоступные форматы и продолжения каталога. `read_import`
принимает проект, doc_id и request_id; для известной редакции —
expected_source_sha256. Только явное действие пользователя инициирует чтение.
Увязка проверяет регистрацию, исходник и читатель; LES после ответа снова
проверяет полный снимок, затем использует прежнюю очередь. Нельзя передать
произвольный путь или загрузить модель/декодер скрыто.

Авторизация использует существующее локальное рукопожатие Увязки. Временный
токен не возвращается браузеру/MCP, не сохраняется и не журналируется. Чтение
может создать кеш Увязки; это не изменение оригинала и не инженерное утверждение.
Повтор в открытой форме использует тот же request_id; после перезапуска формы
продолжение этого запроса не обещается. Тайм-аут не означает успешную индексацию.

- Увязка проверяет SHA-256 оригинала до и после выгрузки. Изменение или
  недоступность оригинала, несовпадение редакции блокируют импорт.
- Все разделы и продолжения, включая пустые страницы с курсором; счётчики
  и уникальность проверяются до постановки задания.
- `les.uvyazka-snapshot.v1` — производный JSON в каталоге LES. Его хеш отличается
  от SHA оригинального RVT/DWG; JSON не выдаётся за исходник.
- `core/src/engineering.rs` создаёт отдельные карточки объектов: проект, снимок,
  native ID/object ID, исходник, читатель и покрытие. Родители не смешивают
  свойства разных объектов. Нули, null и исходные единицы сохраняются.
- Первая версия: 5 000 объектов, 128 КиБ на объект, 24 МиБ на снимок,
  три минуты на импорт. Превышение — отказ целиком, без тихого обрезания.
  Большие модели требуют следующего этапа потокового экспорта Увязки.
- Обновления пока явные, старые снимки не удаляются автоматически. Данные
  источника не являются инженерным утверждением; непрочитанное не равно нулю.

## Интерфейс

«Чертежи и модели»: подключение, проекты, файлы / ранее прочитанное, вьювер. Добавление в очередь
не означает готовность поиска. Источник несёт `model_locator`, действие проверяет
редакцию ещё раз и открывает отдельное окно Увязки, без iframe или ослабления CSP.

Вьювер публикует `/simulation/les-capabilities.json`, контракт
`uvyazka.les-viewer.v1`. Параметры `project`, `les_dataset`, `les_object`,
`les_sha256` открывают свойства точного объекта. Подсветка — только при
однозначной геометрии той же редакции. Иначе показываются свойства и ограничение.
Приёмник подготовлен в Увязке: `web/src/les-source.ts`; старые выпуски могут его
не иметь. Без совместимого приёмника LES показывает необходимость обновления.

Если сервис не отвечает, LES отличает это от несовместимого вьювера и предлагает
запустить приложение, проверить адрес либо «Установить с GitHub». Открывается
официальная страница выпусков, включая предварительные, и инструкция. Нет
автоматического скачивания/исполнения установщика или заявления, что приложение
точно отсутствует только потому, что порт не отвечает. Обычный RAG не блокируется.

## Приёмка

[Фактическая проверка и незакрытые границы](../acceptance/uvyazka-bridge-879.md).

Проверки курсоров/редакций, настоящего форматного обработчика, приёмника ссылок
и компонентов не подтверждают все варианты DWG/RVT, качество генерации или
установленное приложение. Сквозная установленная приёмка, большие модели,
автосинхронизация и визуальная проверка остаются отдельными пунктами.
