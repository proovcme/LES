# Память разговора и команды в Rust

Кандидат 836. Обновление сводки имеет одного владельца: `api/src/conversation/`
и `core/src/conversation_summary/`. Прежние Python-генератор, блокировки,
очередь задач и таймер удалены. Совместимые вызовы classic только передают запросы.
Это не завершение переноса всего публичного чата или остальных API.

## Полный путь памяти

Сохранение успешного ответа в SQLite и постановка задания памяти выполняются
в одной транзакции. Ошибка outbox откатывает успешное завершение; полученный
текст остаётся частичным, а причина сохраняется в истории. Это относится и к
совместимому сохранению истории через Rust core.

Один процесс держит lease владельца чата. При разрешённых фоновых изменениях
он проверяет существующую очередь без создания пустой базы и восстанавливает
незавершённые задания после запуска. Неаутентифицированный HTTP-запрос не может
запустить восстановление или создать базу.

Очередь читает историю с самого старого ещё не обработанного сообщения.
Последние два сообщения остаются для прямого контекста; граница `through_id`
продвигается только по целиком прочитанным сообщениям. Порция ограничена бюджетом
явно назначенной модели. Продолжение очереди и новая сводка фиксируются вместе.

Модель выбирает индексы исходных реплик, а не переписывает их. Неверный JSON,
несуществующий индекс, булев индекс, слишком длинная или незавершённая генерация
не заменяют память. Это извлекательная сводка, а не проверка истинности реплик.
Она передаётся следующему запросу как вспомогательная память, без статуса источника.

Новый запрос прерывает только фоновую сводку, возвращает её в очередь и получает
приоритет на модель. Ручная сводка использует те же ограничения ресурсов и слоты.
Совместимый чат сообщает начало/окончание работы через локальный защищённый API.
Запись сводки проверяет ревизию: изменение, отключение, изоляцию или забывание
памяти нельзя затереть результатом старой генерации. Ошибка сохраняет прежнюю
сводку и границу, понятное сообщение и отдельный диагностический код задания.

## HTTP и совместимость

- `POST /api/workspace/memory/context/{session_id}/summarize` — Rust, обычный
  пользовательский допуск, обязательная `expected_revision`.
- `/api/light/internal-context` — локальный токен модели, без браузерного Origin;
  действия summarize/enqueue/status и lease совместимого foreground-запроса.
- Чтение, редактирование, забывание и изоляция памяти сохраняют прежние нативные
  маршруты и CAS-контракт. Исходная история не удаляется при суммаризации.

`proxy/services/conversation_context_service.py`, `background_summary_service.py`
и `local_model_http.py` остаются кодеками для ещё не перенесённых потребителей.
В них нет запасного модельного генератора или Python-планировщика сводок.
Без нативного сервиса ручная суммаризация явно недоступна.

## Команды

`core/src/chat_commands.rs` и встроенный `config/chat-commands.json` содержат
четыре публичные команды и их алиасы. `GET /api/commands`, разбор, справка и
переформулировки работают в Rust. JSON и SSE вызывают один обработчик;
справке не нужна генерация модели. Обычная речь не превращается в команду.
Прежние недоступные предметные ветви физически удалены из Python-обработчика.
