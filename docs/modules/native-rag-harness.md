# Нативная основа RAG и harness — 780

`core/src/bm25.rs` и `bm25_schema.sql` — единственный владелец SQLite postings:
схема, замена/удаление области, df, длины, точная оценка, фильтры до top-k и
транзакция чтения. Формат базы совместим; пересоздание корпуса или эмбеддингов
не требуется. `bm25_hybrid.fuse` передаёт ранги в Rust: стабильные ничьи,
типизированные ID, прежний коэффициент RRF и первый payload сохраняются.

`backend/bm25_store.py` — адаптер без SQL и Python-отката. Порция до 256 записей;
ABI ограничивает вход 8 МиБ. Rust держит до восьми писателей в процессе.
Каждый владеет BEGIN IMMEDIATE до commit/rollback; ошибка порции или неверное
число точек уничтожает handle с откатом всей транзакции. Выход из контекста
закрывает handle; смерть процесса оставляет штатное восстановление SQLite.
Читатели открывают независимые снимки WAL. Подготовленные SQL переиспользуются.

Публикация журнала Qdrant/SQLite, lease и проверка поколения пока Python:
сначала commit postings, затем контракт/публикация ревизии; незаконченный журнал
блокирует поиск до восстановления. Старый SQL только в test oracle, исключённом
из поставки. `LES_CORE_MODE=python` не возвращает старого владельца postings;
он влияет только на прежние необязательные ускорители. NFKC/casefold и словарь
токенизации пока связывает Python; контракт v2 сохранён.

`core/src/context.rs` владеет порядком, резервами, выбором целых объектов,
ошибкой переполнения обязательных блоков, курсорами пропусков и порядком
модельных сообщений. Python-фасад сохраняет публичные dataclass, сериализацию
объекта и token estimator. Оценка по умолчанию остаётся приближённой.
USER/MEMORY — advisory, не доказательства. Запрос после истории/контекста и
пары assistant/tool сохраняются. Обязательные блоки не обрезаются скрыто.

Ещё Python: модельный цикл/сеть/streaming, executor/MCP, генерация сводок,
Qdrant dense-запросы, реранкер, раскрытие родителей, доказательства, очереди
и публикация индекса. Весь перенос этим этапом не завершён. API и дизайн UI
не меняются. Реранкер остаётся явным и отключаемым.

`tests/test_light_native_rag_harness.py`: сравнение с замороженным 779 таблиц,
оценок/порядка, фильтров и замены областей; смерть процесса с открытой транзакцией;
250 наборов контекста/курсоров/overflow/сообщений и 100 RRF-наборов.
`tools/benchmark_native_core.py` — стенд исходников с test oracle, без моделей.
