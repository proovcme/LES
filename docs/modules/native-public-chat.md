# Публичный вход Rust-чата · 839

В испытательном запуске `les-api --chat-owner rust` обычные `POST /api/chat` и
`POST /api/chat/stream` обслуживает один [Rust-цикл](native-chat-turn.md).
Оба адреса переключаются вместе, без отката отдельного запроса на Python.
Адрес `--upstream` можно опустить: неперенесённые маршруты тогда явно возвращают
`501 NATIVE_ROUTE_NOT_AVAILABLE`. Сборка веб-чата обслуживается нативно
через `--frontend-assets`; обычные действия чата не требуют внутреннего токена.
Без явного выбора штатный владелец публичных адресов остаётся прежним.

## Границы запроса и ответа

- Применяется обычная нативная авторизация. POST принимает JSON, проверяет
  браузерный Origin и поддерживает прежний CORS preflight. Внутренние адреса
  сохраняют отдельный токен и запрет браузерного Origin.
- Повтор с тем же Idempotency-Key возвращает завершённый ответ через любой из
  двух публичных адресов. Квитанция принадлежит проверенному клиенту; ключ
  и удостоверение клиента сохраняются в виде хешей. Чужой, внутренний и
  прежний Python-журнал не используются для переигрывания ответа.
- История и квитанция создаются одной транзакцией. Карта уже опубликованных
  источников сохраняется до передачи клиенту; ссылки, частичный текст и причина
  сбоя остаются после перезагрузки. Сводка действий видна и в потоке, и в истории.
- В режиме поиска с явным ограничением на выбранные источники текст без
  переданного доказательства не стримится и не становится готовым ответом.
  Наличие ссылки не считается независимой проверкой смысла ответа.
- Список наборов, карточка источника и PNG предпросмотра PDF для панели
  доказательств работают без старого сервера. Rust-worker проверяет SHA на
  открытом оригинале до и после рендера, поддерживает ограничение размера
  и область страницы. Изображение не пишется во временный файл.

## До штатного переключения

С 840 [read/quick/folder и ограниченный допуск внешнего чата](native-public-attachments.md)
работают через этот же вход. Ещё требуются полный паритет поиска и специальных
инструментов, расширенные форматы, проверка
ответа, семантический кеш, отключаемый реранкер, оставшийся API и экраны
NiceGUI. Внешняя модель получает только допущенный контекст; неизвестные
источники и локальные вложения запрещены до сетевого вызова.
Неподдерживаемые параметры запроса явно отклоняются.
Рабочая установка не изменялась.
В 841 [совместимый индексирующий API вложения](native-indexed-attachments.md)
подключён к нативной очереди.
В 842 [выбор режима скрепки](native-settings-attachments.md) добавлен в новый чат.
