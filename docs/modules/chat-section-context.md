# Поиск → чтение разделов → контекст чата

Начиная с build 754, основной чат связан с чтением индексированных родителей.
Это самостоятельная реализация, без переноса Legion. В build 755 основной
поиск дополнен полноценным BM25: [контракт индекса](bm25-index.md).

## Граница чтения

ChatSectionReader в chat_section_context_service.py принадлежит одному
запросу. После поиска и необязательного реранкера сохраняет первые 10 попаданий
в исходном порядке, проверяет их по текущим payload Qdrant и дочитывает до
8 уникальных родителей. Фильтр — dataset_id + file_name + parent_id;
navigation и evidence_admissible=false исключены. Первая проверка также
сверяет текст, страницу, порядковый номер и source_ref исходного попадания.

Чтение идёт страницами по 128 точек. Защитные пределы: 2048 фрагментов или
2 млн символов на родителя, 15 секунд на этап; превышение возвращает понятную
ошибку. В упаковку добавляются до 512 соседей по очереди из каждого родителя.
Первоначальные попадания имеют приоритет. Остаток найденной выдачи и фактическое
число включённых фрагментов отражаются в диагностике.

Журнал индекса проверяется до/после чтения и перед вызовом модели. Ревизия поиска
передаётся вместе с попаданиями; смена поколения останавливает запрос.
Кэш родителя работает только внутри одного запроса и одного поколения.
Ошибка чтения не подменяется успешным ответом по старой склейке.

## Модель и доказательства

Каждый прочитанный фрагмент становится отдельным Chunk, сохраняя собственные
point ID, текст, страницу и source_ref. Для atomic_evidence старый renderer
не склеивает соседей, не очищает исходный текст и не обрезает его по символам.
Чрезмерно большой фрагмент пропускается целиком; более короткий следующий
может войти. Заголовок честно называет материал фрагментом раздела.

Общий ContextGovernor учитывает профиль, запрос, историю и резервы ответа.
Источник попадает в модель целым объектом. Второй проход упаковки исключает
из SOURCE_MAP ссылки на не вошедшие доказательства. Источники итогового ответа
ограничены фактически отправленным пакетом; quote совпадает с текстом индекса.
section_coverage показывает индексированные, переданные и пропущенные фрагменты.
Полнота относится к индексированному родителю, не к качеству OCR оригинала.

Один механизм применяется к первоначальному поиску, дополнительному
search_sources модели и повтору после пустого ответа. Прогресс сообщает
дочитывание и подготовку контекста. Память остаётся советом, не доказательством.

Подробная приёмка: [build 754](../acceptance/chat-section-context-754.md).

Кандидат 760: заводские профили публикуются как отдельные ревизии по хешу
содержимого. Сохранённые снимки чатов и активный выбор не обновляются скрыто;
новая заводская версия в существующей установке применяется явно. Письменность
цитат сохраняется, ranking score исключён из модельных заголовков доказательств.
