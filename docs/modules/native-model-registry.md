# Нативный реестр моделей и чтение истории

Кандидат 818 переносит весь SQLite-владелец реестра подключений из
`proxy/services/model_connection_registry_service.py` в
`core/src/catalog/model_registry.rs`. Прежний класс остаётся только типизированным
адаптером для ещё действующих потребителей Python. Второй реализации SQL нет.

## Сохранённый договор

- Идентификаторы подключений, номера неизменяемых ревизий и старые назначения
  читаются из тех же таблиц; пользовательские назначения не меняются.
- Создание, импорт `legacy:…`, изменение, отключение, назначения ролей, снимки
  возможностей и аудит записываются одной транзакцией `BEGIN IMMEDIATE`.
- Ожидаемая ревизия обязательна для изменения существующей записи. У двух
  одновременных изменений один победитель; проигравший не оставляет ревизию,
  назначение или запись аудита.
- Имена активных подключений уникальны по прежнему SQLite `NOCASE`-правилу.
  Это не обещание полноценного Unicode case folding.
- Отключение не уничтожает прежние ревизии и привязки. Выполнение по отключённой
  голове по-прежнему блокируется разрешителем.
- Снимки возможностей неизменяемы. Повтор идентификатора отклоняется;
  неизвестная ревизия, неправильные интервалы дат и поля не записываются.
- Ошибка записи аудита откатывает всю мутацию. Внешние ключи включены до начала
  транзакции; SQL-ошибка не маскируется как пустой реестр.

## HTTP без передачи запроса Python

Rust обслуживает пять дополнительных пар:

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/api/model-connections` | Административные карточки и назначения |
| GET | `/api/model-connections/templates` | Общие шаблоны из поставляемого JSON |
| GET | `/api/chat/history` | Сообщения, источники и сохранённые причины ошибок |
| GET | `/api/chat/sessions` | Список сохранённых разговоров |
| GET | `/api/chat/learning` | Подтверждения/исправления по прежним правилам |

Обработчики применяют прежние роли и CORS; успешные ответы имеют `no-store`.
Карточка содержит только статус ключа, без значения и `secret_ref`. Проверка
статуса использует разрешённые имена переменных и тот же порядок: окружение,
затем первая запись ключа в файле настроек. Файл ограничен 8 МиБ; содержимое
не попадает в журнал. Общий файл шаблонов включён в allowlist упаковщика.

Ошибки чтения истории дают 503 с пояснением о сохранённой переписке, а не
пустой успешный ответ. Старые таблицы истории мигрирует тот же Rust-владелец;
ошибка инструмента не становится успешным примером обучения.

## Самостоятельная загрузка политики

`les-api --auth-policy-file <абсолютный путь>` читает ограниченный файл
`les.native-auth-policy.v1` до приёма запросов. Несовместимая, повреждённая,
отсутствующая или слишком большая политика останавливает запуск. Разрешающего
отката нет. Ключи проверяются по действующему SQLite-реестру, включая отзыв.
Этот путь позволяет проверять холодный старт нативных сценариев без Python.

С 832 [обычная политика](native-access-bootstrap.md) читается самим Rust API
из настроек экземпляра, без этого аргумента и без внутреннего backend.
Forwarding и CORS/preflight тоже нативные; несовместимая настройка не включает
старую проверку. Полный bootstrap и оставшиеся маршруты API ещё требуют переноса.

Общие вычисления CIDR, роли сети, адреса клиента и доверенного прокси теперь
принадлежат `core/src/trust.rs`. Python `backend/trust_core.py` — только
совместимый вызов. Проверены IPv4/IPv6, маски/hostmask, scope ID, повреждённые
адреса и отказ принимать XFF от чужого peer.

## Граница этапа 818

HTTP-запись подключений, управление секретами, проверка возможностей, DNS и
подключение внешних провайдеров в 818 ещё обслуживались прежними маршрутами.
Их нельзя заменить прямым вызовом записи реестра: это потеряет проверки
адреса, подключённого peer, возможностей и явного выбора пользователя.
Модельный цикл, часть исполнителей инструментов/парсеров и classic UI также
остаются Python. Единственное целевое исключение после завершения переноса —
автономный исполнитель одобренных старых Python-навыков.

Проверки и границы: [приёмка 818](../acceptance/native-registry-history-818.md).
