# Холодный допуск к API в Rust

Кандидат 832 убирает последний Python callback из авторизации нативных маршрутов.
`core/src/access_policy.rs` читает настройки; `api/src/auth.rs` проверяет доступ,
ключи, прокси и CORS. Ручной `--auth-policy-file` больше не нужен для обычного
холодного старта. Существующий явный v1-файл остаётся совместимым входом.

Настройки берутся из принадлежащего экземпляру `.env`/`LES_ENV_PATH`; переменные
процесса имеют приоритет, включая пустые значения. Читаются только шесть полей:
`TRUSTED_NETWORKS`, `TRUSTED_NETWORK_ROLE`, `TRUSTED_PROXY_NETWORKS`,
`TRUSTED_PROXY_HEADER`, `CORS_ALLOWED_ORIGINS`, `CORS_ALLOWED_ORIGIN_REGEX`.
BOM, CRLF, export, кавычки в ключах/значениях, комментарии и повторные ключи поддерживаются.
Успешный снимок фиксируется до рестарта, как прежняя конфигурация backend.
Неудачная загрузка может повториться после исправления файла.

Сохраняется явное доверие loopback по умолчанию. Режим только по ключу требует
пустых **обоих** списков доверенных сетей и прокси. Переданный клиентом адрес
используется только от настроенного доверенного прокси; невалидный адрес не
становится локальным. Ограниченный пользователь не получает права администратора.
Отзыв, роль и срок ключа проверяются в SQLite на каждом запросе.

Нативный API принимает только IPv4 loopback, поэтому транспортный peer фиксирован
запускателем, а не заголовком Host. Расширение сетевого bind потребует передавать
фактический peer в эту политику. V1-файл описывает прямой loopback и не даёт сетевых
привилегий запросу с forwarding-заголовками; действительный ключ остаётся доступен.

CORS preflight выполняется без Python и без создания пользовательских данных.
Проверяются origin, метод и заголовки. Приватные endpoints по-прежнему не
публикуются браузеру. Неподдерживаемое Rust-regex правило, нераскрытая `${...}`,
неверные кавычки, имя proxy-заголовка или ошибка чтения дают 503 с понятным
сообщением и `AUTH_*` кодом; содержимое настроек/секреты не выводятся.
Автоматической замены ошибочной политики правами по умолчанию нет. Для сложного
Python-regex следует задать явные `CORS_ALLOWED_ORIGINS` либо совместимое правило.

Удалены Python endpoints `native-auth-policy`, `native-authorization` и
`native-admin-authorization`, а также нативный HTTP fallback к ним. Их адреса
на публичном front door возвращают 404.

Это перенос **допуска к API**, не всего launcher/API. Runtime ещё запускает
старый backend и NiceGUI для оставшихся обработчиков и classic. Первичное
создание индекса, адаптеры чата, специальные форматы и UI требуют переноса.
Модели, рабочий индекс, установленное окно и комплект внешних навыков не менялись.
