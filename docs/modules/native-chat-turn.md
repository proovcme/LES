# Общий обработчик чата в Rust — кандидат 835

Обычный JSON-ответ и SSE используют один request-owned путь: проверка запроса,
область документов, сохранённая ревизия модели, профиль, память, контекст,
модельный поток, AgentLoop, доверенный исполнитель и атомарная история.
Нет Python callbacks, HTTP fallback или запуска приложения в комплекте навыков.

Это **испытательный контур**, а не завершённая замена публичного чата.
POST `/api/light/internal-chat` и `/api/light/internal-chat/stream` доступны
только локальному владельцу с внутренним токеном модели, без браузерного Origin.
Обычные `/api/chat` и `/api/chat/stream` пока сохраняют прежнего владельца.
Рабочая установка, индекс и назначения моделей не переключены.

| Узел | Владелец |
| --- | --- |
| Запрос, область, точные номера заголовков | `core/src/chat_request/` |
| Квитанция, повторы, восстановление, история | `core/src/chat_request/journal.rs` |
| HTTP/SSE и отмена соединения | `api/src/chat/http.rs` |
| Реестр модели, контекст и цикл | `api/src/chat/{prepare,runner,model}.rs` |
| Допуск инструментов и ограниченная выдача схем | `api/src/chat/tools/` |
| Dense + BM25 + RRF, чтение родителей | `api/src/index_store/{search,sections}.rs` |
| Оригинал, хеш и браузерное чтение диапазонов | `api/src/documents.rs` |

## Гарантии

- `Idempotency-Key` привязан к нормализованному запросу и диалогу. Завершённый
  запрос возвращает сохранённый результат; выполняющийся/прерванный не запускается
  повторно. Другое содержимое с тем же ключом отклоняется.
- Квитанция и начальная строка истории создаются вместе. Финальный ответ и квитанция
  завершаются одной транзакцией. Каждый переданный текстовый блок сначала записывается
  в историю; после терминального состояния запись/очистка текста запрещена.
- После аварии восстанавливаются только строки этого нативного координатора.
  Частичный текст и причина остановки сохраняются. Активные legacy-запросы не трогаются.
- Закрытие SSE отменяет модельное чтение; отсутствующий конец потока не считается
  ответом. Ошибка чтения источника останавливает цикл до финальной генерации, включая
  вызов через общий инструмент расширений. Сырые исключения/секреты не публикуются.
- Физический PDF читается отдельным Rust-процессом по зарегистрированному ID,
  SHA-256 и однобазной странице. Все промежутки курсора должны быть дочитаны.
  Идентификатор фрагмента не подменяет идентификатор документа.
- Выбранный файл с подпапкой может быть привязан по короткому имени только при
  единственном совпадении среди явно выбранных файлов. Чужой набор и выход за
  `selected_sources_only` запрещены, в том числе во вложенном инструменте.
- Поиск проверяет контракт эмбеддингов, поколение индекса и канонические точки,
  затем дочитывает сохранённые родительские разделы. Переполнение и неполное
  покрытие не превращаются в обещание полноты оригинала или правильности ответа.
- Схемы учитываются в бюджете отдельно от сообщений. Текст источника передаётся
  одним блоком доказательства, а инструмент ссылается на этот блок. Обязательные
  доказательства не обрезаются для вмещения. Trace скрывает вопрос, профиль и память.
- Избранные инструменты можно раскрывать порциями без расширения прав профиля.
  Внешний навык использует явно заданный автономный CPython и одобренный хеш скрипта;
  `backend`/`proxy` приложения ему недоступны. Встроенные вычисления остаются Rust.

GET/HEAD `/api/documents/by-id/{id}/raw` уже принадлежат Rust. Оригиналы открываются
по серверному каталогу, проверяются на том же файловом дескрипторе и выдаются
ограниченными порциями. Поддержаны одиночные byte-range/206 и ссылки старого вида
с точными dataset/name; неизвестный ID сам по себе не угадывается. Непроиндексированный
оригинал тоже можно открыть. Classic ещё нуждается в своём совместимом маршруте.

## Незакрытый паритет

В 837 [вложения и table_document](native-chat-attachments.md) соединены с общим
кандидатом: авторитетный preview, изображения и устойчивые табличные задания.
Старые пакеты таблицы не накапливаются в модельном контексте; незавершённые
решения обозначаются квитанцией, а не обещанием модели. Редкие форматы,
document_review и публичный upload ещё не перенесены целиком.

В 836 [обновление сводки и команды](native-conversation-memory.md) получили
нативного владельца. Сохранение истории атомарно ставит задание памяти;
JSON/SSE учитывают ошибки финальной записи, сохраняя их точную причину.

До переключения публичного чата нужны: полноценная notebook/typed map и виртуальные
тома, специальные таблицы и vision, вложения,
политики чувствительных материалов, дополнительные режимы, проверка ответа,
семантический кеш и отключаемый реранкер. Явные неподдерживаемые флаги/вызовы
отклоняются; их работа не имитируется. `dataset_map` пока показывает инвентарь,
а `read_excel_source` читает проверенные индексированные разделы, как прежний инструмент.
Оставшиеся API/bootstrap/classic и специальные форматы также не объявлены перенесёнными.

Нужна отдельная приёмка отмены длительных вычислительных инструментов, полного
Server-конвейера и конкурентного обновления/падения Edge именно в новом обработчике.
Завершение модельного потока не является независимой проверкой фактов.
