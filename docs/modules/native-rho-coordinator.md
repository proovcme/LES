# Координатор Rho — кандидат 870

Rho SDK 5.15.2 владеет последовательностью модель → инструменты → модель.
Основной Rust API и совместимый синхронный ABI используют один модуль
core/src/coordinator. Старые agent_loop, его runner/answer, отдельный
счётчик harness и Python-класс HarnessLoop удалены.

## Ответственность

- runtime.rs — адаптер поставщика и callback-инструменты SDK.
- policy.rs — допуск, общий срок, бюджет действий, идемпотентность,
  ревизии изменяемых ресурсов, исходные ошибки и покрытие PDF.
- mod.rs — асинхронный/синхронный порты I/O, отмена и владение ресурсами.
- compatibility.rs — сохранённый wire-договор research/answer. Цикл
  этого адаптера обслуживает события SDK, не выбирает следующие действия.

api/chat/runner.rs готовит контекст, вызывает назначенную модель/инструмент
и проверяет завершение. Он больше не хранит отдельную историю вызовов:
для каждого запроса строится проекция канонической истории Rho. Схемы
инструментов и сами модели по-прежнему определяет профиль LES.

Внутренняя capability завершения вызывает host-проверку ответа. Она не
передаётся модели, не публикуется в MCP и не попадает в модельный контекст.
Отклонённый ответ допускает прежние ограниченные исправления без открытия
инструментов заново и без восполнения срока/бюджета. Успех возвращается
только после подтверждения окончательного завершения Rho.

## Сохранённые договоры

Бюджет контекста и резерв ответа, память, таблицы/числа и адреса абзацев,
проверка видимых доказательств, цитаты и проверка оригиналов остаются в
существующих Rust-владельцах. Неполная физическая страница дочитывается
точным курсором до нового запроса модели. Ошибка чтения остаётся ошибкой:
после неё нельзя запросить уверенный финальный ответ.

Исходные native call_id сохраняются. Идентификатор с похожим префиксом
не считается доказательством серверного происхождения: внутренние курсоры
зарегистрированы отдельно. Legacy JSON-выбор не превращается в фиктивный
native tool_call для внешнего сервера модели.

Изменение памяти/таблицы делает устаревшее чтение снова допустимым.
Запись же содержит ожидаемую ревизию и желаемое изменение в аргументах:
новая эпоха чтения не разрешает повторить эту же запись. Это исправляет
лишние повторные попытки, которые обнаружила приёмка реального эффекта.

Владелец запроса отменяет Rho и ожидает завершения своего потока. Его
callback, исходный deadline и семафоры моделей не становятся глобальными.
Python для внешних навыков и существующие MCP/файловые инструменты остаются
за прежними Rust-host адаптерами.

## Граница приёмки

Кандидат исходников; рабочая установка и индекс не переключаются.
Нативные тесты и повтор Qwen выполняются на отдельной копии. Интеграция
Rho не объявляет исправленными известные проблемы смыслового отбора RAG.
Результаты 39 основных запросов Qwen, трёх SSE и полного gate — в
[приёмке 870](../acceptance/native-rho-coordinator-870.md). Реальный Qwen
не выполнил просьбу физически прочитать PDF; успешные интеграции читателя
с управляемой моделью не подменяют эту незакрытую проверку.
