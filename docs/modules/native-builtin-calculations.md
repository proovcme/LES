# Встроенные вычисления в Rust

Кандидат 827. Встроенный инструмент `sum_excel_ranges` больше не использует
Python Decimal/OpenPyXL для адресов, пересечений и сумм. Его владелец —
`core/src/workbook_calculation/`: координаты/диапазоны, точная десятичная
арифметика, проверки значений и описание листов. Сервис чата сохраняет
авторитетный список книг запроса, проверяет редакцию/оригинал и передаёт снимок
через `backend/workbook_calculation.py`; он не выбирает диапазоны за модель.

Десятичные числа представлены знаковым коэффициентом и степенью десяти.
Сложение не использует f64, округление или `eval`. Предел точности — 1024
значащие цифры, как в прежнем Decimal-контексте. Непредставимая точная сумма,
NaN/Infinity, текст вместо числа, отсутствующий/устаревший результат формулы,
пересечение диапазонов или объединённые ячейки дают отказ без частичного итога.
Пустые отсутствующие координаты считаются пустыми; нули остаются числами.
Дополнительно отвергаются повторные координаты и несовпадение номера строки
с адресом ячейки. Формулы не вычисляются: используется подтверждённый кеш файла.

Сохранены восемь диапазонов, пределы 20 000 строк, 512 столбцов и 300 000
выбранных ячеек. Результат содержит подытоги, числовые/пустые ячейки, число
кешированных формул, координаты и SHA-256 источника. Цитаты диапазонов остаются
на прежнем пути evidence; отказ расчёта не создаёт доказательство суммы.

Протокол `les.workbook-calculation.v1`: действия `sum` и `describe`.
`les_core_workbook_run` получает неизменяемый JSON-снимок порциями по 262 144
Unicode-символа, проверяет курсор и предел 256 МиБ. Это сохраняет работу
снимков больше общего лимита 8 МиБ C ABI. Кодек не содержит резервного
Python-калькулятора. Для нативного инструмента нужен capability
`workbook_calculation`. Borrowed JSON-мосты партии/чата/источников/JSON/расчёта
используют одну реализацию проверки размеров и времени жизни буфера.

Нативная административная команда `les-api --builtin-workbook` принимает
один JSON-запрос в stdin: протокол, действие, абсолютный `path` и явные
`ranges`. Она читает XLSX/XLSM через существующий нативный снимок и работает
без Python. Общий чат сохраняет прежний совместимый читатель сложных книг:
эти форматные остатки не объявлены перенесёнными. CLI не обходит ограничения
чата/MCP: это локальная команда оператора с указанным им файлом.

Встроенные профили/инструкции — данные, а общие инструменты переносятся под
своими контрактами. Пользовательский код из `storage/skills` остаётся внешним,
исполняется только с прежним разрешённым хешем. Его не подменяют Rust-функцией
по имени файла и не копируют в публичные встроенные алгоритмы.
