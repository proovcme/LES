# Первый индекс: нативный владелец

Кандидат 833 переносит основной путь создания индекса в Rust:
явная роль embeddings → проверка возможностей/адреса → контрольный вектор →
сохранённый план → создание Server/Edge → лексическая проекция → атомарный контракт.
Новый индекс создаётся также перед первой явно запрошенной индексацией папки.
Python API и Python-парсер не участвуют в этом исполнении.

| Владелец | Операция |
| --- | --- |
| `api/src/index_bootstrap.rs` | HTTP, роль/модель, измерение размерности, допуск и продолжение |
| `core/src/index_bootstrap.rs` | Контракт, общий writer lease, каталог плана и атомарная публикация |
| `api/src/index_store/bootstrap.rs` | Только принадлежащие экземпляру Server/Edge |
| `vector/src/initialize.rs` | Новый пустой Edge и восстановление его незавершённой инициализации |
| `core/src/lexical_schema.rs` | Создание/миграция лексических таблиц, FTS и триггеров |
| `backend/native_index_store.py` | Совместимый клиент, без выбора модели и создания хранилища |

## Договор

Нет роли — нет другого эмбеддера. Один фиксированный несекретный текст проверяет
фактическую размерность и пригодность вектора; неверный model ID/неконечные числа/
нулевой вектор не принимаются. Локальный вызов сохраняет порог свободной RAM 4 GiB.
Внешний вызов требует явного разрешения; запрос индексации папки уже является
действием пользователя для назначенной роли. Никаких загрузок моделей/токенизаторов.
Недоступный локальный токенизатор даёт ошибку с действием; явный режим chars сохраняется.

План сохраняется в SQLite до создания или явной замены пустой коллекции.
Общий с публикацией/восстановлением writer исключает конкурирующую индексацию.
Контракт включает SHA токенизатора и исходную ревизию назначения модели;
настройки и роль перепроверяются перед мутацией и перед завершением. После
падения незавершённый план не заменяется догадкой по новой роли.

Существующая коллекция без контракта требует явного `adopt_existing=true`.
Для непустой коллекции дополнительно проверяется fingerprint всех точек.
Несовместимую пустую Server-коллекцию можно заменить только с явным
`replace_empty=true`; advisory points_count не даёт разрешения удалять данные.
Точный count сравнивается с INDEXED-каталогом. Повреждённый контракт не считается
отсутствующим и не перезаписывается. Индекс Edge с чужими/незавершёнными import-
метаданными не превращается в новый пустой индекс.

Опубликованный файл контракта не заменяет чужой файл при гонке. Незавершённое
задание, стадия проверки/создания, ревизия модели и причина ошибки доступны
после рестарта. Копия не требует готовой лексической базы: миграция принадлежит
Rust; прежние тексты/FTS восстанавливаются без потери строк. Миграция старых
колонок выполняется до индексов по этим колонкам.

Локальный эмбеддер, прогретый для непрерывной партии, используется далее этой
партией. После её завершения/ошибки действуют прежние правила освобождения
собственных workers. Отдельная ручная проверка не удерживает ONNX-worker.
Keyword-индексы создаются идемпотентно в фоне с прежним opt-out, не блокируя старт.

## API

- `POST /api/rag/index/setup`: `allow_remote`, `adopt_existing`, `replace_empty`
  (bool), необязательная ожидаемая `collection`.
- `GET /api/rag/index/setup`: стадия задания, код ошибки и наличие контракта;
  это состояние подготовки, не оценка качества поиска.
- Внутренний `/api/light/internal-index-setup`: ingestion-токен и отсутствие Origin;
  клиент не выбирает базу, путь хранения, executable или роль модели.

Удалены `backend/collection_layout.py`, прежние Python layout/adoption/count-
решения, payload-index task и Python-миграция FTS. Чтение совместимых настроек
учитывает нативный контракт; секреты сохраняют отдельную прежнюю семантику.
Непрерывная партия повторно использует прогретую при проверке модель; отдельно
вызванная подготовка освобождает её. Лимит памяти остаётся прежним. Конфигурация
Edge отображается через совместимые server-поля для оставшихся клиентов чата.
Вспомогательный построитель ColBERT/sibling ещё Python: публикация основного
контракта использует нативный атомарный primitive, его полный перенос остаётся задачей.

Это не перенос всех адаптеров чата, специальных форматов, bootstrap и classic.
Изменения не установлены в рабочий LES. [Приёмка](../acceptance/native-index-setup-833.md).
