# Нативный диспетчер и исполнитель партии

Кандидат 829. Единица переноса — полный путь партии: исходник → нормализация →
производный файл → фрагменты → эмбеддинги → публикация → подтверждение каталога.
Число переписанных функций не означает удаления Python из приложения.

| Компонент | Владеет |
| --- | --- |
| `core/src/document/conversion/` | Поддерживаемые форматы, SHA исходника, сырые узлы, приватный spool |
| `core/src/tables/` | Нормализация, точная сумма, Snappy Parquet, активные ссылки редакций |
| `config/table-row-schema.json` | Общие поля и публичные типы таблиц; без специального сметного сценария |
| `api/src/document_dispatch.rs` | PDFium и явно переданный нативный OCR в отдельном worker |
| `api/src/index_batch.rs` | HTTP-вход целой партии, область/модель/RAM, соединение нативных владельцев |
| `core/src/index_batch/` | Попытки, блокировка набора, этапы, восстановление, подтверждение commit |
| `api/src/index_store/` | Поколение документа, Qdrant Server/Edge, лексический индекс и каталог |

## Целая партия без Python callbacks

`POST /api/light/internal-index-batch` получает frozen `les.index-batch.v1`.
Доступ — только внутренний ingestion-token, без браузерного Origin. База,
производные и spool должны принадлежать этому экземпляру. Сравнение учитывает
фактическую идентичность Windows-путей. Программу worker задаёт Rust API;
переданное вызывающей стороной имя программы не исполняется. Порог RAM — 4 ГиБ.

Модель и пространство векторов не выбираются автоматически. Переданное
`embedding_execution.revision_id` проверяется против frozen descriptor до
изменения статусов. Проверяются кеш, размерность, ответ модели и длина бинарного
результата. Без revision разрешён только явно настроенный локальный ONNX-компонент
прежнего пространства `sentence_transformers`. Облачный вызов требует
явного `allow_remote`.

Перед захватом партии Rust проверяет все выбранные зарегистрированные файлы.
Обработчики: XLSX/XLSM/XLS/CSV/PPTX, DOCX/DOC, Unicode TXT/MD, JSON/JSONL и PDF.
Неперенесённый формат отклоняет всю партию с HTTP 412
`DOCUMENT_NATIVE_DISPATCH_REQUIRED`, до изменения статусов документов.
Конвертация, эмбеддинги и публикация не вызывают Python callbacks.
Для внешних зарегистрированных источников не нужен обход отсутствующего или
большого каталога производных файлов; внутренние источники сохраняют проверки
пути, неоднозначных имён и фактического наличия файла.

Это не полная совместимость всех прежних форматных сценариев. Почта,
специальные CAD/BIM-проекции, подписанные контейнеры, некоторые OCR/VLM,
паспорта чертежей и legacy-определение кодировок остаются открытыми.
Неизвестная кодировка не подменяется испорченным текстом. Непрочитанный скан
не превращается в успешный доказательный фрагмент.

PDF читается физически PDFium. Сохраняются страница, часть и `#page=N`;
сырой размер страницы по умолчанию 1800 символов, перекрытие 150, затем общий
токеновый бюджет и иерархия. Скан требует явно заданных OCR-параметров;
модель распознавания скрыто не назначается. Нативные параметры OCR замораживаются
до старта партии; изменение `.env` не меняет обработчик посреди задания.
Кавычки в сохранённых настройках Windows/Tesseract учитываются. Supervisor ограничивает память,
время, кадры и потомков, заменяет остановившийся worker и сохраняет причину.

## Таблицы и редакции

Apache Rust `parquet 60.1.0` читает и пишет Snappy без PyArrow/Pandas в этом пути.
Сохраняются null, bool, int64, uint64, конечные float и Unicode. Недопустимое
смешение больших целых и float отклоняется без округления. Ограничены размер,
footer, колонки, группы и распакованный объём. SHA связывает продолжение чтения.
`worker_tables` имеет отдельный пул.

Blob под `_parquet/.les-versions/` получает имя из SHA исходника и результата.
Footer/fsync завершаются до публикации. `les_table_artifacts` переключается
в одной SQLite-транзакции с лексическими данными и состоянием документа.
Неподтверждённые blob не попадают в активные таблицы; старый соседний Parquet
не учитывается второй раз. Старый blob читается по прежней точной ссылке.
Автоматическая сборка неиспользуемых версий пока не включена.

Точная сумма возвращает `exact_total`, не заменяет отсутствующее значение
другим полем и сохраняет ноль. Прежние неиспользуемые `table_query_service.py`
и `table_sql_service.py` удалены после проверки потребителей; проверки нуля
и чтения выполняются через действующий нативный владелец. Удаление этих старых
helpers не объявляется новой функцией чата.

## Применение и незакрытая граница

Штатная нативная ветка `_sync_parse` теперь вызывает HTTP-исполнитель напрямую.
`backend/native_index_batch.py` передаёт frozen-настройки, а
`native_index_store.execute_batch` — JSON/итог. Конвертер, эмбеддер и publisher
Python больше не callbacks этой партии. Ошибка/обрыв HTTP не запускает их
скрыто и не меняет статусы документов от имени потерянного клиента.
Rust освобождает использованные локальные обработчики и точную loopback Ollama
модель поиска; кешированный проход не выгружает неиспользованную модель.
Отмена/смерть HTTP-клиента не прерывает владеющий заданием Rust процесс.

Оригиналы и производные имеют разные корни: `source_root` остаётся под
состоянием приложения, `content_root` задаётся владельцем хранилища. В Edge
Parquet проверяется в его content-каталоге, а исходный PDF — в каталоге оригиналов.
Launcher передаёт PDFium и самому Rust API; DLL читается напрямую, без Python.

Фоновому intake нужны замена прежнего запуска/политики и собственная приёмка.
Старые комплекты без нативного API ещё имеют совместимый путь. Этот кандидат
не переключает установленный Лес. Общий dispatcher/API/bootstrap/classic нельзя
объявлять закрытыми, пока эти потребители и перечисленные специальные форматы
не работают без Python приложения. CPython внешних навыков сохраняется отдельно.
