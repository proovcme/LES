# Навигационная карта набора в Rust

Кандидат 831. От каталога и задания до вызова модели, проверки результата и
сохранения карты путь выполняется Rust. Ручное чтение и автоматическое чтение
после индексации используют один исполнитель. Прежние Python-подготовка
reader-контекста, модельный цикл, sanitizer, запись результата и task-set удалены;
совместимые функции передают локальный JSON и проецируют результат в прежний вид.

| Владелец | Ответственность |
| --- | --- |
| `core/src/catalog/dataset_reader/` | Снимок каталога, очередь, контекст, схема, ссылки, история и CAS |
| `api/src/dataset_reader.rs` | Доступ, worker lease, выбранная модель, ответы/ошибки и продолжение |
| `core/src/index_events.rs` | Общий outbox завершения партии или восстановленного intake |
| `config/dataset-reader-schema.json` | Единственная локальная схема ответа |
| `backend/native_index_store.py` | Только совместимый локальный HTTP-клиент |

## Что видит модель

Это **карта для навигации**, а не прочтение полного корпуса. Модель получает
имена, актуальные статусы, типы, число фрагментов, группы папок, доступные
заголовки и явное описание набора от оператора. Сметные маршруты и предметные
keyword-планы в нативный вход не переносятся. Фактический ответ всё равно
требует поиска и чтения доказательств из источников.

Контекст — законченный JSON в ограниченном бюджете. Он сокращается целыми
элементами, с явными included/total и признаком пропусков. Даже очень длинные
имена не обрывают JSON посередине. Соблюдаются `LES_DATASET_READER_FILE_LIMIT`,
`LES_DATASET_READER_CONTEXT_CHARS` и `LES_DATASET_READER_MAX_TOKENS`; модельный
вход дополнительно ограничен доступным контекстом закреплённого подключения.

Результат проверяется локальной JSON Schema. Ссылка на файл вне фактически
переданного контекста отклоняется, включая существующий, но опущенный файл.
JSON может быть обёрнут единственным fenced-блоком; произвольный окружающий
текст не считается структурированным успехом. Сводки и подписи имеют пределы
длины. `is_evidence=false`; confidence остаётся самооценкой модели.

## Сохранность и допуск

Снимок зависит от ID/имени, SHA, mtime/размера, статусов, числа фрагментов,
маршрута, профиля и заголовков. Замена текста при прежнем числе фрагментов
меняет редакцию. Старый результат не публикуется поверх новой редакции или
после удаления набора. Ранее сохранённая карта без такой привязки не получает
ложный статус актуальной модели через совместимую проекцию.

Роль `answer` выбирается явно; её ревизия фиксируется в задании и сохраняется
при рестарте. Новая привязка роли не переключает незавершённый вызов. Нет
назначения/возможностей/памяти — есть сохранённая причина, без другой модели.
Для loopback действует прежний порог свободной памяти 4 GiB. Внешняя отправка
требует явного `allow_remote`; для автоматического режима — отдельного
`LES_DATASET_READER_ALLOW_REMOTE=true`. По умолчанию она выключена.

SQLite хранит задания `queued/running/completed/failed/stale`, число попыток,
модельную ревизию, причину ошибки и ограниченный предыдущий невалидный ответ.
OS lease исключает второго worker. После потери процесса продолжается то же
задание; счётчик попыток и причина исправления не сбрасываются. Потеря HTTP-
клиента не отменяет очередь. Обрыв/лимит ответа не считается успешной картой.

`les_index_events` — durable outbox только новых успешно завершённых партий.
Receipt и постановка reader фиксируются вместе. Поэтому падение после commit
индекса и до HTTP-уведомления не теряет автозапуск.
Также проверен kill после commit последнего файла, когда повтор уже не читает
ни одного документа: событие создаётся при восстановлении batch или завершении
intake с готовыми документами. Повторная обработка файла/эмбеддинг не нужны.
Старые исторические партии не превращаются в новые модельные вызовы при первом запуске 831.
Автозапуск opt-in: `LES_DATASET_READER_AFTER_PARSE=true`. Отключение приостанавливает
ещё не начатые auto-задания; явные ручные задания остаются доступными.

## API и граница переноса

- `POST /api/notebooks/{dataset_id}/memory/read`: синхронное ожидание либо
  `background=true` с durable job ID; поддерживает force и 1–3 попытки.
- `GET /api/notebooks/{dataset_id}/memory/reader`: текущая карта, состояние,
  редакция модели, код и понятное описание ошибки.
- Внутренний `/api/light/internal-dataset-reader` защищён ingestion-токеном и
  запретом Origin; клиент не задаёт файл базы, команды или модель.

Это закрывает модельный reader, не весь notebook/чат. Старые построители
типизированной/тематической карты и остальных API, bootstrap, classic и
специальные форматы ещё требуют переноса. Автономный CPython внешних навыков
не менялся. Кандидат и проверка установленной версии — отдельные состояния.
