# Дочитывание страницы и ошибки истории — кандидат 817

Продолжение уже выбранного чтения выполняет Rust в `core/src/harness_evidence.rs`.
После успешной порции он группирует интервалы по документу, хешу и странице,
проверяет редакцию и находит первый непокрытый диапазон. Возвращается точный
вызов `read_pdf_source` с закреплёнными ID, страницей, SHA-256 и offset. До
приёма итогового ответа всё полное чтение должно иметь сплошное покрытие.

Контроллер чата исполняет такую порцию как продолжение начатой операции.
Повторного решения Qwen на каждую порцию нет; trace помечает
`native_pdf_cursor` и `not_sent_cursor_continuation`. Модель выбирает документ
и вид чтения, а не управляет транспортным курсором. Лимиты вызовов, deadline,
проверка scope и проверка файла сохраняются. Новая редакция не достраивает
покрытие старой; лимит или ошибка не превращают недочитанную страницу в успех.
Для адресного чтения `q` сохраняется режим буквального совпадения без заявления
о полной проверке страницы.

`core/src/catalog/history.rs` сохраняет публичный code и detail в artifact_json
и атомарно переводит запрос в FAILED до отправки SSE error. Новые token/reset
и поздний финальный save не могут перезаписать FAILED. Начатый запрос хранит
единственную строку истории; ошибка не становится успешным ответом или памятью.

`core/src/catalog/history_view.rs` читает строки истории и собирает сообщения,
локаторы источников и meta.error. SQL и Python-проекция `/api/chat/history`
перенесены в Rust. В Python остались HTTP-вызов catalog_call и передача события
в нативный checkpoint. Интерфейс показывает сохранённую причину, не добавляя
к пустому ответу сообщение о якобы сохранённом тексте. Для частичного ответа
сохраняется и его текст, и причина остановки.

Полностью убрать Python из LES этим изменением не заявляется: ещё остаются
оркестрация чата, другие API/обработчики и совместимость навыков. Новых
зависимостей не добавлено. Рабочая установка и рабочий индекс не менялись.
