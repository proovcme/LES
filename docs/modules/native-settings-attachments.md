# Скрепка и настройки моделей · 842

Испытательный запуск `--chat-owner rust` показывает нативный экран «Модели».
Список, обнаружение, создание и изменение подключения, запись ключа,
проверка возможностей, назначение роли и отключение обслуживаются Rust.
Установленное приложение ещё не переключалось.

- Скрепка предлагает «Прочитать в чате» и «Добавить в поиск» при запущенной
  нативной очереди. После загрузки чат читает сохранённое состояние задания.
  Кнопка «Искать во вложениях» появляется после публикации, а область поиска
  меняется только после её нажатия. Черновик остаётся в диалоге. Текущий
  номер задания восстанавливается при перезагрузке на том же локальном адресе.
- Роль закрепляется за проверенной ревизией по явному действию. Запись
  защищена от устаревшей формы. Отключение модели, у которой остались
  назначения, требует явного подтверждения. Проверка использует фиксированный
  пробный текст, ограничивает сеть и размер ответа и проверяет его формат.
  Повторная проверка не стирает ещё действительные результаты по другим
  возможностям и не продлевает срок этих результатов.
- Ключ не попадает в ответы и журнал реестра. Ревизия с сохранённым ключом
  не может перенести этот ключ на другой адрес; для нового адреса создаётся
  отдельное подключение.
- В режиме чтения Rust разбирает сохранённые EML/EMLX: тема, адреса, дата,
  текст и небольшие текстовые/DOCX-вложения. Для остальных вложений показано,
  что прочитаны только метаданные. Почтовый ящик не затрагивается.

За границей кандидата: диагностика расширений моделей и прежние операции
promotion, почтовые аккаунты и синхронизация, индексация почты, Outlook, часть
специальных инструментов, API и экранов. Python API и NiceGUI остаются в
штатном запуске до проверки этих сценариев.
