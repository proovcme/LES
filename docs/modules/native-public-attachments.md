# Вложения и внешняя модель публичного Rust-чата · 840

В явном запуске `--chat-owner rust` работают `POST /api/chat/attachments`
(201) и совместимые `POST /api/rag/attach?mode=read|quick` и
`POST /api/rag/attach-folder`. Штатные клиенты сохраняют прежнего владельца
до паритета. Полный установщик и рабочее состояние не переключались.

- Загрузка ограничена по размеру, времени и числу параллельных запросов.
  После падения следующая загрузка убирает незавершённые файлы своего
  временного каталога под эксклюзивной блокировкой.
- Повтор `Idempotency-Key` привязан к авторизованному клиенту, имени, виду,
  размеру и SHA-256. Карточка результата и квитанция публикуются вместе.
  Повтор проверяет оригинал; другой клиент не может прочитать новое вложение
  по его ID. Истечение срока удаляет содержимое и сохраняет только запись
  о занятом ключе, чтобы старый черновик не прочитал другой файл.
- Папка читается без индексации, только из разрешённой области. Максимум 25
  документов, 50 МиБ и 48 тыс. символов; список и хеши сверяются повторно.
  Ошибка одного файла останавливает создание всего снимка. Снимок не обрезается
  при чтении в чате; если превышен контекст модели, запрос не выдаётся за полный.

Внешнее OpenAI-совместимое подключение использует явно выбранную ревизию и
согласие `LES_CLOUD_CONSENT`. Без набора допускается явно отправленный текст;
для RAG проверяются метки P1/P2 всех наборов. P0, неизвестная маркировка,
вложения и рабочая память запрещены. Прежняя история допускается только при
совпадении квитанции клиента, области данных и ревизии модели. Допуск области
проверяется перед модельным вызовом и внешними эмбеддингами. Внешнему чату
доступны ограниченные инструменты чтения источников; локальные файлы,
исполняемые навыки, веб и MCP к нему не подключаются. Автосводка не ставится
в очередь для внешнего ответа.

В кандидат 840 не входили: индексирование из скрепки, неперенесённые форматы,
остальные специальные инструменты и API, штатный запуск без NiceGUI.
В 841 [индексирующий маршрут подключён](native-indexed-attachments.md).
Внешняя передача реальных документов не выполнялась.
