# Зависимости следующего этапа переноса

Статус: весь набор согласован владельцем 01.11.2026. Первым подключается
SQLite и Axum для переноса владения диалогами/черновиками и HTTP-границы;
Calamine подключён в 790 для чтения XLSX/XLSM в чате. Для проверки архива
Rust использует ту же библиотеку zip, которую подключает Calamine. Кандидат 803
подключает pdfium-render для текстового слоя и использует уже поставляемый PDFium
7825 через набор функций 7763.
Уже выполненная сборка `runtime/` использует существующий локальный Cargo-кэш,
`--offline`, точные прямые версии и отдельный Cargo.lock; модели не устанавливались.

| Пакет | Предлагаемая версия | Назначение | Первичный источник |
| --- | --- | --- | --- |
| axum | 0.8.9 | Rust HTTP API, потоковый чат и общая граница запросов | [Документация](https://docs.rs/crate/axum/0.8.9) |
| rusqlite | 0.41.1 + bundled | Совместимые SQLite-транзакции, каталог, память, задания и BM25 | [Документация](https://docs.rs/crate/rusqlite/0.41.1) |
| calamine | 0.37.0 | Чтение Excel без openpyxl/pandas | [Документация](https://docs.rs/crate/calamine/0.37.0) |
| pdfium-render | 0.9.3 | PDF текст/координаты/превью с фиксированным PDFium | [Документация](https://docs.rs/crate/pdfium-render/0.9.3) |

Это не автоматическое разрешение заменить поведение парсеров. Для каждого формата
нужен паритет доказательств, координат, формул, пустых значений, ошибок и лимитов.
Docling не считается заменённым одним PDF-reader. OCR и почта сохраняются до
проверки их собственных замен. Существующий нативный PDFium предпочтителен новому
дублирующему дистрибутиву; ABI выбирается после сверки фактического asset.

При подключении: закрепить точные версии и транзитивные checksum в Cargo.lock,
проверить лицензии/уведомления и сборку из lock; новые загрузки выполнять только
сборщику, не пользователю при обычном запуске. Изменение моделей/их ролей не входит
в этот пакет. CPython для автономных навыков остаётся отдельной явно учтённой частью.
