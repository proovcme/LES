# LES RAG: macOS preview

Локальная браузерная редакция Light для macOS. Это кандидат исходников build 759,
а не опубликованный, подписанный DMG или нативная оболочка Windows/Tauri.

## Установка

Нужны macOS, Python 3.12/3.13, `uv` и Xcode Command Line Tools для сборки
небольшого OCR-helper. Установка требует интернета и использует `uv.lock`.

```sh
uv sync --locked --extra mcp
uv run python -m tools.light_runtime_assets --destination native/qdrant
uv run python -m tools.install_light_macos
```

Приложение устанавливается в `~/Applications/LES RAG Preview.app`, состояние —
в `~/Library/Application Support/LES Light Mac Preview`. Параметры `--app` и
`--state` позволяют выбрать другие каталоги. Существующее приложение не
перезаписывается: для кандидата укажите новый путь, сохранив возможность отката.

Код и отдельная `.venv` размещены внутри приложения. Python управляется `uv`:
preview не является полностью автономным офлайн-пакетом. Приложение открывает
интерфейс в браузере; отдельного нативного окна и трея пока нет. Закрытие вкладки
не останавливает службы.

Qdrant 1.19.1 — собственный нативный процесс с отдельным хранилищем, ключом,
динамическим loopback-портом и проверкой архива SHA-256. Пакеты для Apple Silicon
и Intel закреплены в `config/light-runtime.json`. Intel пока проверен только
на уровне выбора архива, не на реальном компьютере. Windows packaging продолжает
выбирать Windows-архив независимо от платформы сборки.

## Модели и первый индекс

Модели не включены в приложение. Подключения и назначения чата/эмбеддингов
выполняются явно, через локальную Ollama или совместимый OpenAI API. Для поиска
нужен отдельный embedding-провайдер; чатовая модель его не заменяет.

Модель и размерность роли поиска должны совпадать с контрактом индекса. Одно
назначение роли не мигрирует существующую коллекцию. При несовпадении LES
останавливает индексацию с `EMBEDDING_INDEX_MODEL_MISMATCH`. Для нового тестового
индекса можно явно задать отдельную коллекцию и модель в `.env` каталога состояния,
затем перезапустить только этот экземпляр:

```dotenv
EMBEDDING_MODEL=qwen3-embedding:0.6b
EMBED_MODEL=qwen3-embedding:0.6b
EMBED_BACKEND=ollama
MLX_URL=http://127.0.0.1:11434
EMBED_URL_PARSE=http://127.0.0.1:11434
RAG_VECTOR_SIZE=1024
RAG_COLLECTION_NAME=les_mac_preview_qwen
RAG_CHUNKING_UNIT=chars
```

После этого явно назначьте проверенное подключение той же модели роли поиска.
Не используйте эти параметры для миграции пользовательского индекса без отдельного
плана. Для текста и сканов используется одна цепочка поиска; macOS OCR работает
через Apple Vision без скачивания дополнительной модели. Таблицы и сложную
вёрстку необходимо проверять по оригиналу.

При нехватке памяти защита блокирует локальный ответ. Не снижайте пороги ради
проверки: завершите конкурирующую работу или выгрузите собственные тестовые модели.
Кандидат 760 измеряет память непосредственно при допуске запроса и после ожидания слота;
фоновая телеметрия не подменяет эту проверку. Порог защиты сохранён.

## Проверка

`make verify`, `make test` и `uv lock --check` проверяют исходники. Проверка
установки должна запускать Python именно из `.app/Contents/Resources/runtime`,
загрузить вымышленный документ, подтвердить реальные фрагменты, поиск, ответ со
ссылкой и точное совпадение открытого оригинала. HTTP-успех не заменяет просмотр UI.
Состояние локального испытания фиксируется отдельно в `docs/acceptance/macos-758.md`.

Кандидат 759: [аудит RAG и надёжности](acceptance/rag-reliability-759.md).
Mac supervisor завершает собственные службы при аварии launcher. При recovery
свободные API/UI-адреса сохраняются; при занятом порте открывается новый адрес.
Light API принимает только loopback Host/Origin.

Кандидат 760: [полный чат, OCR, таблицы и сохранность оригиналов](acceptance/full-chat-760.md).
Создание первого индекса из выбранной роли без ручной настройки пока остаётся открытым.
