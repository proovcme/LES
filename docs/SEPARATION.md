# Самостоятельный LES RAG

Кандидат 833: [первый индекс в Rust](modules/native-index-setup.md), включая
новый пустой Edge, измерение размерности, план/восстановление и лексическую схему.
Прежний Python layout и FTS-миграция удалены. Чат/специальные форматы/classic
ещё требуют переноса. [Приёмка](acceptance/native-index-setup-833.md); установка прежняя.

Кандидат 832: [политика доступа к API в Rust](modules/native-access-bootstrap.md).
Обычный холодный допуск и proxy/CORS больше не спрашивают Python. Старые callback-
обработчики удалены. Общий launcher/backend, первый индекс и classic ещё остаются.
[Приёмка](acceptance/native-access-bootstrap-832.md); рабочая установка прежняя.

Кандидат 831: [модельная карта набора в Rust](modules/native-dataset-reader.md).
Ручной/автоматический reader, выбранная модель, валидация и revision-safe результат
имеют одного нативного владельца. Старый Python-исполнитель удалён; обычные
typed/topic map, прочие API/bootstrap/classic ещё требуют переноса.
[Приёмка](acceptance/native-dataset-reader-831.md). Рабочая установка не менялась.

Кандидат 830: [фоновое подключение папки целиком в Rust](modules/native-intake-execution.md).
Политика источников и старт партии больше не требуют Python API; старые внутренние
обработчики удалены. Сохранённый контракт/явная модель обязательны. Синхронный preview,
первичная настройка индекса, специальные форматы и остальной API/bootstrap/classic
ещё требуют переноса. [Приёмка](acceptance/native-intake-execution-830.md).

Кандидат 829: [таблицы/Parquet и нативный HTTP-исполнитель партии](modules/native-table-dispatch.md).
В этом исполнителе нет Python callbacks конвертации/эмбеддингов/публикации;
неподдерживаемая партия отклоняется целиком до изменения статусов. Общий intake,
специальные форматы, чат/API/bootstrap/classic ещё не заменены полностью.
[Приёмка и границы](acceptance/native-table-dispatch-829.md). Рабочая установка прежняя.

Кандидат 828: [чтение Excel/CSV/PPTX в отдельном Rust-процессе](modules/native-format-conversion.md).
Нативный структурный XLS-reader заменяет временную конвертацию через Pandas.
Общий форматный диспетчер, классификация и остальная серверная Python-часть
ещё не удалены. [Приёмка](acceptance/native-formats-828.md).

Кандидат 827: [встроенный расчёт Excel в Rust](modules/native-builtin-calculations.md)
и [отдельный комплект внешних Python-навыков](modules/skill-runtime-package.md).
Launcher и совместимый API используют один Rust-selector. На копии проверен
ранее одобренный скрипт; общая серверная Python-часть ещё остаётся.
[Приёмка](acceptance/native-builtins-runtime-827.md).

Кандидат 826: [исходные PDF/Markdown-узлы в Rust](modules/native-source-nodes.md).
Страницы, части, ID, бюджеты и provenance собираются нативно; короткая
физическая страница не теряется на финальном пороге. Форматный процесс и
классификация ещё совместимые адаптеры. [Приёмка](acceptance/native-source-nodes-826.md).

Кандидат 825: [JSON/JSONL в Rust](modules/native-json-sources.md), без индексирования
диагностики как содержимого. Убрана похожая подмена для непрочитанного скана.
UTF/BOM и парсинг нативные; legacy-детектор ещё совместимый Python.
[Приёмка и незакрытая миграция прежних JSON](acceptance/native-json-sources-825.md).

Кандидат 824: [финальная подготовка фрагментов в Rust](modules/native-node-preparation.md).
Штатная партия сама создаёт бюджеты/ID/иерархию/родителей из сырого JSONL.
На реальной копии все 4 вектора взяты из кеша, остальные 43 215 точек совпали.
Начальная конвертация и типизация ещё retained-адаптеры. [Приёмка](acceptance/native-node-preparation-824.md).

Кандидат 823: [управляющий цикл основного чата в Rust](modules/native-chat-loop.md).
Итерации модели/инструментов, бюджет, привязка scope, дочитывание PDF и повтор
пустой финальной генерации больше не решаются Python-циклами. Адаптеры промпта,
evidence и специальных обработчиков ещё остаются. [Проверки](acceptance/native-chat-loop-823.md).

Кандидат 822: [координатор партии в Rust](modules/native-index-batch.md).
Штатным нативным путём больше не управляет Python `process_one`.
Форматная подготовка ещё отдельный адаптер.
[Проверка на копии реального индекса](acceptance/native-index-batch-822.md).

Кандидат 821: [автономные навыки и MCP в Rust](modules/native-skills-mcp.md).
Исходящий клиент не зависит от Python SDK; старые функции исполняются отдельным
CPython под нативным контролем. Общие координаторы ещё требуют переноса.
В 821 [допуск инструментов и журнал исполнения](modules/native-tool-execution.md)
также принадлежат Rust; старый диспетчер — совместимый адаптер.
Изолированная приёмка, включая отдельный CPython без приложения:
[результаты 821](acceptance/native-skills-mcp-821.md).

Кандидат 820: [Edge, BM25, Unicode и эмбеддинги в Rust](modules/native-edge-embeddings.md).
На копии 43 219 точек проверен путь от текста запроса до родительского
контекста без Python backend и Qdrant Server. [Измерения и ограничения](acceptance/native-edge-embeddings-820.md).
Штатная установка и общий цикл чата пока не переключены.
Профили, библиотека инструкций, реестр инструментов и шесть файловых операций
теперь имеют нативного владельца; прежние Python-реализации профилей и обхода
файлов удалены. [Граница и проверки](modules/native-profiles-files.md).

Кандидат 819: [модельный транспорт и интернет-инструменты в Rust](modules/native-web-inference.md).
Поиск и обычное чтение сайтов выполняются нативно; общий цикл чата и API
пока используют адаптер Python. Рабочая установка не переключалась.

Кандидат 818: [реестр моделей, чтение истории и доверенные сети в Rust](modules/native-model-registry.md).
Пять дополнительных HTTP-пар работают без Python backend; холодный запуск
проверяется с явно заданной политикой доступа. Общий runtime ещё нужен.
[Приёмка и ограничения](acceptance/native-registry-history-818.md).

Кандидат 813 переносит ручной выбор документов и проверку исходных файлов

Кандидат 810 собирает полный файл точек Qdrant в Rust и вызывает эмбеддер

форматов, подготовка иерархии и модельный цикл ещё используют Python.
[Граница переноса](modules/python-exit.md).

Кандидат 806 переносит выбор документов партии, публикацию в Qdrant и SQLite

[Контракт партии и восстановления](modules/auto-parse-resume.md).

Установлен локальный патч 783: чтение DOC и разбор цитат в Rust; исправлены
PDF/OCR, ограничение геометрии и запуск embedded обработчика. Рабочая повторная
индексация всех 95 прежних настоящих ошибок завершилась без отказов. [Результат](acceptance/document-extraction-783.md).

Сохранены этапы 780–782: Rust владеет BM25-хранилищем/оценками/RRF,
упаковкой контекста, ограничениями цикла инструментов и подтверждениями действий.
Исправлено ложное PARSING автоочереди. [Установленная приёмка и ограничения](acceptance/auto-parse-resume-782.md).
[RAG-ядро](modules/native-rag-harness.md), [контроллер harness](modules/native-harness-loop.md).

Репозиторий содержит продукт для Windows: чат, документы, память, проекты,
MCP и поиск по источникам. Он не управляет другим экземпляром ЛЕС, пользовательской
Ollama или сторонним Qdrant. Сметный интерфейс и его специализированный код удалены.

Состояние находится отдельно от установки. Источники используются только для чтения.
Стандартный Windows-ярлык с этапа 779 явно выбирает Rust launcher/API
и Svelte-чат. [Проверка установленного пути](acceptance/agent-native-779.md).
Оставшиеся 245 API-пар, модельная оркестрация, сеть/streaming, executor/MCP,
дочитывание, публикация индекса, исполнитель очереди, парсеры и часть UI ещё Python;
полный установщик и публичный выпуск не заменены этим локальным патчем.
Запуск: tools/light_launcher.py. Сборка: tools/build_light_package.py.
Этапы 775/776 добавили явные режимы Rust-запуска и API. [Владелец служб](modules/native-runtime.md),
[владение API](modules/native-api.md), [цель переноса](modules/python-exit.md).
Новый чат Svelte/TypeScript выбран стандартным ярлыком. Запуск EXE без флагов
ещё может открыть classic; полный установщик не переведён. [Граница frontend](modules/svelte-desktop.md).
Некоторые общие модули ещё содержат унаследованные ветви; их удаление требует
проверки зависимостей. Это отражено в [бэклоге](BACKLOG.md).

macOS browser preview использует тот же Light launcher с отдельным состоянием
и собственным нативным Qdrant. [Граница установки](MACOS_PREVIEW.md).
