# Границы LES RAG

LES RAG — самостоятельное настольное приложение. Windows-запуск идёт через
Tauri, нативного владельца служб, Rust API и Svelte. Пакет поставляет локальный
Qdrant Server и изолированный Python для внешних навыков. Состояние приложения
хранится отдельно. Внешние папки остаются на месте и открываются для чтения.

- [Точки входа и состав сборки](CODE_RUNTIME_MAP.md) показывают, какой код
  включается в Windows, Edge preview, macOS preview и поддерживаемые адаптеры.
- [Архитектура](LIGHT_ARCHITECTURE.md) и [карта модулей](MODULE_INDEX.md)
  описывают владельцев функций.
- [Журнал выпусков](RELEASE_LEDGER.md) и [отчёты приёмки](acceptance/)
  фиксируют версии, результаты и известные ограничения.

В границы приложения входят документы, поиск, чат, проекты, память, модели,
навыки и MCP. Внешние специализированные данные доступны через явно выбранные
MCP-инструменты. Назначения моделей для ответов и поиска независимы. Обычный чат
по набору берёт фрагменты из индекса. Чтение оригинала остаётся доступно по ссылке
и через явные инструменты источников.

Совместимые Python-маршруты и [macOS preview](MACOS_PREVIEW.md) имеют свои точки
входа. Экспериментальный Edge работает с отдельным состоянием и копией индекса.
Совместимость при обновлении проверяется отдельно для чистой установки,
обновления и отката.
