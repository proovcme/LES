# Договор интерфейса LES RAG

Светлый тёплый фон, глубокий зелёный, лес знаний и спокойная типографика.
Общие компоненты, перенос текста и доступная клавиатурная навигация важнее
декоративных метрик. Не добавлять CSS-переопределения без проверки существующих правил.

Каждый путь: вход, действие, результат, доказательство, возврат. Диалоги имеют
закрытие и Escape; рабочие страницы — Назад и Главная. Поток и обработка показывают
фактический этап и результат. Не выдавать HTTP 200 за визуальную приёмку.

Проверка браузера, нативного WebView2 и экранного диктора — разные результаты;
не объявлять полное соответствие WCAG по одним автоматическим тестам.
