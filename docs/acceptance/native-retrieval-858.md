# Кандидат 858: диагностика поиска и контекста

Проверки выполняются на отдельном Edge/SQLite с двумя пользовательскими
наборами: 638 индексированных документов, 82 203 фрагмента. Ранние служебные
фикстуры исключены областью наборов. Рабочая установка, назначения моделей
и исходные документы не изменяются. Полные вопросы, ответы и оригиналы
содержат личные данные и остаются за пределами публичного репозитория.

## Подтверждённые причины

1. Иерархические кандидаты повторно участвовали в RRF и сдвигали глобальные
   совпадения. Заменено отдельным навигационным списком без второго голоса.
2. Раскрытие первого большого родителя расходовало остаток бюджета до
   продолжения небольших следующих разделов. Ранжированные совпадения
   сохраняются первыми, затем завершаются помещающиеся родители; частичные
   разделы делят оставшиеся возможности.
3. Исключённый из контекста текст мог скрыть и идентификатор найденного
   документа. Добавлены отдельные краткие карточки для выбора чтения;
   карточка не является доказательством и не разрешает цитату.
4. Модель завершала ответ по первичным выдержкам без инструмента чтения.
   Добавлена явная проверка чтения для нативного Pull/Hybrid с ответом только
   по источникам. Повторный пропуск чтения сохраняет ошибку и пустой ответ.
   Это не семантический судья и не гарантия правильности чисел или выводов.
5. Буквальный запрос внутри PDF мог не совпасть с текстом страницы.
   Только `PDF_QUERY_NOT_FOUND` допускает чтение той же страницы без фильтра:
   ID, SHA-256 и физическая страница сохраняются; отсутствие буквального
   совпадения явно остаётся в квитанции. Остальные ошибки не обходятся.
6. Обязательные квитанции инструментов дублировали расположение источников,
   а отчёт покрытия резервировался для уже невидимых поисковых кандидатов.
   Квитанция модели использует ссылки на блоки доказательств; полная запись
   остаётся в истории. Покрытие резервируется только для достижимых источников.

## Проведённые проверки и пределы вывода

- На 20 контрольных вопросах выполнены парные запросы к реальному индексу
  с одинаковыми векторами, областью и поколением. Включение иерархии сохраняет
  все ID, порядок и оценки 64 глобальных результатов. Отдельные кандидаты
  не дублируют глобальные point ID. Это инвариант ранжирования, не Recall@64.
- На промежуточной сборке прошли 107 тестов core. После управления окном прошли
  28 тестов API и 48 целевых проверок контекста, PDF, DOCX и режимов поиска,
  включая последовательные чтения с окном 8192 токена. Они не подтверждают качество
  всех ответов живой модели.
- В повторе с настоящей Qwen3.5:9b без ручного выбора файла один прежний
  пропуск числового ответа исправился: выполнено чтение и дан ответ со ссылкой.
  Два других запроса остановились из-за переполнения контекста. Следующее
  сокращение дублированных метаданных требует повторной проверки.

На следующем промежуточном варианте выполнен пилот из 20 запросов к Qwen3.5:9b,
без имён или ID целевых файлов в запросе чата. Завершились 4 ответа: три числовых
ответа соответствуют проверенным данным; ответ об изменении листов неполон и
содержит неподтверждённое обобщение. Остальные: 13 `SOURCE_READ_REQUIRED`, одно
переполнение контекста, одна ошибка оформления цитаты и один `CORE_BATCH_LIMIT`.
Отказ защиты не считается правильным ответом или улучшением полноты поиска.

После этого добавлены расчёт допустимой порции тем же packer и резерв метаданных
каждого фрагмента. Лексическое чтение длинного документа обрабатывает фрагменты
партиями по 256; контрольный ответ после 599 фрагментов не теряется. В отдельном
повторе трёх запросов нет переполнения и `CORE_BATCH_LIMIT`: есть два последовательных
чтения разделов, чтение PDF порциями и ограниченный отказ назвать отсутствующее
в текущем окне число. Это исправление выполнения, а не подтверждение точности:
в запросе о заключении модель использовала пояснительную записку и неверно
назвала её страницу страницей заключения. Такой ответ не прошёл смысловую приёмку.

Окно допускает исключение целых старых доказательств, пар инструментов и ходов
диалога; сохраняет текущее чтение, активные задания и последний ход. Восстановление
хронологии и запрет цитаты невидимого доказательства проверены отдельно. Полные
результаты остаются в журнале. Размеры окна, назначения моделей и защита RAM
не менялись. Общий gate приложения проверен отдельно от этой живой серии:
`make verify` прошёл, `make test` — 2123 passed, 2 skipped, 18 subtests passed.
Полный прогон занял 986,35 секунды. Предыдущая промежуточная попытка gate
остановилась на изменившейся генерируемой карте кода; после обновления карты
финальный прогон завершился с exit 0. Эти проверки не закрывают описанные
ошибки выбора источника и взаимодействия с настоящей моделью.

Это целевой пилот, а не размеченный набор из 100 вопросов. Смысловая точность,
достаточность дочитывания, составные вопросы и выбор действующей редакции
остаются предметом приёмки. Испытания без модели и HTTP 200 не заменяют её.
Установщик и публичный релиз этой проверкой не объявляются готовыми.
