# Build 754 — связанная цепочка в основном чате

Основной маршрут чата использует ChatSectionReader, общий evidence packet и
ContextGovernor. [Контракт](../modules/chat-section-context.md).
Проверка проводится на копии состояния; исходные документы и основной индекс
не изменяются. Для живой приёмки явно выбрана пользователем Qwen 3.5 9B в Ollama.
Назначение модели меняется только в экземпляре приёмки.

## Результат

Установлен локальный патч из девяти файлов с сохранением исходных SHA-256 и
отката. Основные данные, индекс и назначения моделей не менялись. Использован
отдельный набор изменений без непрошедшего установленную приёмку табличного
кандидата 746. Полный установщик и публичный выпуск остаются прежними.
Пользовательское нативное окно принудительно не перезапускалось; уже открытый
процесс получит новый Python-код после обычного перезапуска приложения.

Поиск → необязательный реранкер → чтение индексированного родителя → бюджет
контекста → ответ теперь составляют одну цепочку основного чата. Единый механизм
используется также для поиска инструментом модели и повторной генерации.
Ошибки чтения раздела не поглощаются запасной веткой tool-loop. Источники в
потоке и истории ограничены фрагментами, действительно переданными модели.
Панель цитаты показывает полный использованный текст, включая сведения за
пределами прежнего короткого превью.

## Живая проверка Qwen 3.5 9B / Ollama

Копия корпуса: два документа, 227 точек, включая 159 доказательных фрагментов
и 68 навигационных. Реранкер отключён; поисковые веса не изменялись. В трёх
случаях кандидата проверены 62 включения источников: текст, ID, датасет,
документ и страница совпали с индексом; 32 включения добавлены дочитыванием.
Это не 62 разных документа и не оценка правильности всех утверждений модели.

| Сценарий | Результат | Полный ответ | Оценка токенов входа |
| --- | --- | ---: | ---: |
| Прямой ответ | Правильный ответ и нужная страница | 72,1 с | 12048 |
| Противоречащие числа | Необоснованный выбор одного значения; ошибка качества | 76,8 с | 11779 |
| Ответ отсутствует | Модель сообщает, что в переданных фрагментах ответа нет | 101,0 с | 12316 |

Все пакеты ниже входного бюджета 19968 токенов; значения — оценка упаковщика,
не точный tokenizer модели. Дочитывание и сбор контекста: 55–77 мс. Первый
токен: 66–82 с. Основное ожидание приходится на модель.

В одном сравнении на том же вопросе и подключении прежняя цепочка использовала
17125 токенов и 115,6 с, новая — 11779 и 76,8 с. Это одиночное измерение, не
обещание общего ускорения. Обе цепочки неустойчиво трактуют противоречия:
прежняя назвала контрольное значение, но допустила альтернативное без основания;
новая выбрала альтернативное как якобы более точное. Улучшение смысловой
точности и отсутствие регрессии качества этим сравнением не доказаны.

Установленный runtime отдельно запущен встроенным Python на копии состояния:
прямой ответ получен за 75,1 с, дочитывание/контекст — около 79 мс. После
финальной правки обработки ошибки и панели цитат экземпляр перезапущен;
сохранённый ответ восстановлен, полная цитата и PDF на нужной странице открыты
через основной чат. Проверка выполнена в браузере, не в нативном WebView2.
Локальные журналы, SHA-256, снимки и ответы сохранены в рабочей папке приёмки;
личные документы и адрес подключения в репозиторий не добавлены.

## Что остаётся открытым

Полноценный BM25 всё ещё отдельный кандидат: установленный `bm25_sparse` —
TF с IDF Qdrant. Нужна явная миграция весов, её этот патч не выполняет.
Независимые 100 случаев, смысловое разрешение противоречий, задержка Qwen,
нативное окно и экранный диктор остаются в бэклоге. Живая проверка включённого
реранкера здесь не проводилась. Полнота чтения касается индексированного
раздела и не гарантирует правильность OCR или полноту исходного документа.
