# 829 · таблицы, диспетчер и нативный HTTP-исполнитель партии

Кандидат исходников и отдельные тестовые экземпляры. Рабочая установка,
модели, исходные документы и рабочий индекс не переключались. Полный установщик
и путь установленного приложения не проверены. Полный Python-exit не завершён.

## Проверки

- Нормализованные строки сравнены с замороженным generic-oracle на 300 случаях.
  Проверены порядок raw-колонок, Unicode, поля источника, null/NaN, физические
  строки и листы. Специальный сметный workflow не переносился.
- Rust → PyArrow и PyArrow → Rust: Snappy, типы, null, точные int64/uint64,
  отказ потере точности, повреждению и неподдерживаемому codec. Неудачная запись
  сохраняет прежний законченный Parquet; SHA связывает продолжение чтения.
- Standalone Rust worker выполняет good → bad → good без Python. Повреждённый
  JSON не оставляет частичного spool. DOCX сохраняет заголовок и таблицу;
  Unicode TXT/MD проверены в UTF-8, UTF-16, UTF-32.
- Настоящий двухстраничный PDF прочитан Rust worker с недоступными Python,
  PYTHONPATH/PATH. Проверены обе страницы, части длинной страницы, последние
  строки и ссылки `#page=N`. Это не приёмка всех вариантов PDF/OCR.
- На настоящем Qdrant Server выполнена публикация таблицы с запрещёнными прежними
  конвертером/классификатором Python. Кандидат не меняет активную ссылку до commit;
  старая версия читается после переключения, соседний старый Parquet не дублируется.
- Весь HTTP-путь партии выполняет Rust API без живого Python application server.
  Контрольный HTTP эмбеддер проверяет протокол, настоящий Qdrant — публикацию;
  это не замер качества эмбеддингов. Проверены token/Origin, чужая база,
  подставленная программа worker, несовпадающая модель и отказ всей партии
  с неподдерживаемым форматом до изменения статусов.
- Rust API остановлен во время замены редакции, пока эмбеддер удерживал запрос.
  Прежние точки/векторы и blob остались читаемыми. После запуска API повторный
  запрос продолжил работу; SQLite сохранил точный PID прежнего владельца и
  `INDEX_BATCH_OWNER_LOST`. Spool убраны. Автоматический запуск через установленный
  intake этим тестом не подтверждён.

## Настоящий корпус

Без публикации обработаны все 138 зарегистрированных книг: 119 XLSX и 19 XLS.
Полный нативный путь подготовил **27 630 строк** и **15 113 сырых узлов**.
Все 138 Parquet прочитаны PyArrow с тем же числом строк; SHA оригиналов совпали.
Драйвер с контрольным чтением и хешированием занял **31,933 с**; это не чистый
замер скорости индексации. Приватные результаты находятся вне репозитория.

Полный HTTP-прогон на копии настоящего индекса выполнен с XLS и двухстраничным
PDF: **35 фрагментов, 0 ошибок**, все 35 эмбеддингов заново вычислены настоящим
BGE-M3 через Rust tokenizers/ORT, кеш отключён. Обработка партии заняла
**52,413 с**. Все **43 184 посторонние точки вместе с payload и векторами**
совпали по полному SHA, SHA оригиналов сохранены. PDF-узлы сохраняют страницы
1 и 2 и ссылки на них. Драйвер с копированием/полной проверкой занял 321,791 с;
это не задержка обработки документа. Python application server, callbacks
конвертации/эмбеддингов/публикации не запускались.

После подключения к штатной ветке отдельный тест вызывает `_sync_parse`
с запрещёнными Python C ABI-координатором/callback и `_convert_file`.
Настоящие Rust API/Qdrant читают PDF, публикуют, возвращают физическую страницу
и повторяют проход из кеша. Контрольный HTTP эмбеддер назначен через реестр;
после партии Rust отправляет unload только использованной loopback-модели.
Табличный тест штатного входа также использует HTTP эмбеддер вместо Python encode.

Штатный `_sync_parse` повторно проверен на той же изолированной копии настоящего
корпуса с запрещёнными Python C ABI coordinator, `_convert_file` и `encode_sync`.
**2 файла, 35 фрагментов, 0 ошибок**, 35 новых эмбеддингов BGE-M3; партия —
**55,193 с**. Посторонние **43 184** точки/вектора, оригиналы и страницы 1/2
сохранены. Освобождение нативных workers вернулось в результате партии.
Драйвер с полной проверкой — 199,021 с, без повторного копирования.

На Server и Edge отдельно проверен обрыв только HTTP-клиента: Rust продолжает
партию и завершает каталог без повторного клиента. Скан проверен с настоящим
рендером PDFium и контрольным PowerShell helper, включая кавычки настроек и
отказ helper без частичного spool. Это проверка wiring/ошибок, не качества OCR.

До последнего подключения штатного входа общий gate: **1933 passed, 3 skipped**,
18 subtests; последующая целевая проверка штатного входа/обрыва/OCR — **30 passed**.
Итоговый повтор общего gate фиксируется после завершения проверки.

## Незакрытые условия

Штатный intake/bootstrap ещё обращается к прежнему API за политикой и запуском.
Специальные форматы/метаданные, legacy-кодировки, некоторые OCR/VLM и оставшийся
чат/API/classic требуют замены владельцев и приёмки. Автономный runtime внешних
навыков сохраняется отдельно. Не удалять общий Python runtime и не делать merge
как завершённый Python-exit по результату этого кандидата.
