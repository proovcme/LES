# Кандидат 824: подготовка фрагментов в Rust

Состояние: исходники, отдельная копия индекса и регрессии. Установка пользователя
и рабочий индекс не переключались. Весь Python этим этапом не удаляется.

Итоговые проверки: `make verify` — **1805 collected**; `make test` —
**1802 passed, 3 skipped**, 18 subtests. Пропуски: POSIX reuse, macOS supervisor,
необязательная offline embedding spec. Rust core/API/runtime — 63/10/7.
Целевые узлы/партия/форматы/комплект — 50 passed. Исходники заморожены после
разделения модуля и подключения общих сообщений; установочный пользовательский
путь и чистая Windows остаются отдельной незакрытой приёмкой.

## Реальный индекс

Повторно обработан настоящий PDF в копии 43 219 точек. После переноса:

- прежние 4 фрагмента, все четыре вектора взяты из кеша, нового encode нет;
- остальные **43 215 точек** совпали по UUID, payload и dense/sparse векторам;
- оригинал и fingerprint модели не изменились;
- нативный поиск дал результаты, дочитаны два родителя и физическая страница;
- индексацией управляет Rust, подготовкой узлов — `rust.document.nodes`;
  общий Python HTTP backend для этого прогона не запускался;
- повторная партия заняла **6,93 с**. Это прогон с полным кешем, не доказательство
  ускорения относительно прежней холодной партии с новыми эмбеддингами.

Форматный child, первичные узлы и типизация файла ещё Python. Снимок и исходные
пути остаются в частной лаборатории; в публичные материалы не включены.
Заключительное разделение модуля и общие сообщения не меняют алгоритм; после
них отдельно повторяются паритетные проверки и общий gate.

## Контрольные сценарии

Полное равенство прежнему результату проверено для заголовков и их наследования,
навигации, родительских окон, границ страниц, строк таблиц/листов, нулевых
индексов, существующих полей, Unicode-разделителей строк, кириллицы/CJK/emoji,
санитарной очистки и выбранного локального токенизатора.

Также проверены публикация только подготовленных узлов, отказ лишней строке
до encode, проверка конфигурации до попытки обработки, понятная причина в
каталоге и гибель владельца со сформированным prepared-spool. После запуска
подтверждённый первый файл не повторяется, второй продолжается; оба JSONL
очищены. Реальные PDF/Qdrant/publication/cache-регрессии сохранены.

Остаются начальная конвертация/классификация, их диспетчер, адаптеры промпта и
специальных инструментов, API/bootstrap/classic и конечная автономная поставка
старых навыков. Очистка исходников, push и merge обусловлены завершением всего
переноса и приёмкой; это условие ещё не выполнено.
