# 877: оригиналы Word, OCR страниц и общий читатель MCP

Статус: кандидат на отдельной копии. Рабочая установка, штатный MCP,
назначения моделей и рабочий индекс не переключены. Это проверка данных
читателя, а не качества сгенерированных справок; Qwen не вызывалась.

## Исправленные причины

| Причина | Изменение |
|---|---|
| Физический читатель отказывал на сканах | Настроенный OCR работает с настоящей страницей; один снимок закреплён хешем для всех порций |
| Старые Word-чанки разрывали строки и повторяли текст | Отдельное представление чтения из оригинала: заголовки, абзацы, целые строки и повторяемая шапка |
| Якорный номер страницы вклеивался в слово или количество | Плавающие объекты сохранены отдельной историей, без подмены позиции в строке |
| Docling не возвращал маркер из колонтитула | Основное тело и связанные колонтитулы/примечания имеют разных владельцев; контроль маркеров тела сохранён |
| Автоматический поиск распознавал все найденные Word до отбора | План чтения и финальный контекст используют общий селектор |
| Ранг совпадения размножался по всем абзацам Word | Дополнительные единицы получают `rank=null`; фиктивного dense-голоса у колонтитула нет |
| Трасса рангов вытесняла прочитанный текст из MCP | Приоритет текста и первичных ссылок; усечение диагностики/детальных дублей обозначено явно |
| Один долгий оригинал срывал весь обзор | Ограниченное автоматическое чтение, явный список непрочитанных источников и независимое предупреждение в чате |
| OCR запускал новый процесс на каждый рисунок | Системный движок переиспользуется; Rust контролирует очередь, срок и завершение |
| Внутренний контекст обрезался по транспортному лимиту MCP | Лимит применяется к внешнему ответу; внутренние страницы и каталог доходят до модельного упаковщика |
| Предварительный расчёт места прерывал освобождение схем инструментов | Оба переполнения проходят один путь повторной сборки контекста без потери прочитанного |
| Пустая последняя страница поиска считалась переполнением | Исчерпанный поток возвращает пустую страницу и `next_offset=null`; непрочитанная непомещающаяся единица остаётся ошибкой |

## Реальная проверка через MCP

Использована прежняя копия Edge/SQLite с 638 зарегистрированными оригиналами
и двумя основными наборами. Дополнительный индекс для этого прогона не создавался.
Клиент запускал настоящий `les-runtime --cli mcp`, выполнял инициализацию,
получал список инструментов и вызывал их через stdio. Перед соединением
проверялся владелец копии. Модель эмбеддингов осталась прежней.

Переиндексация всего подключённого корпуса не выполнялась. Реальные Word
проверены через представление физического чтения поверх прежнего индекса;
это не приёмка миграции всех сохранённых Word-чанков. Новый путь подготовки
структурных единиц проверяется отдельно от фактической публикации индекса.

Три обычных вопроса касались состава документации, категорий электроснабжения
и внешних источников питания. Имена и ID файлов в поисковые запросы не
подставлялись. Последующие чтения использовали возвращённые идентификаторы.

| Запрос | Передано фрагментов / символов текста | Время одного прогона | Непрочитанные источники |
|---|---:|---:|---:|
| Состав документации | 4 / 5576 | 83,59 с | 1, явный таймаут |
| Категории электроснабжения | 5 / 5087 | 82,52 с | 0 |
| Внешнее питание | 5 / 5079 | 38,81 с | 0 |

В переданных данных присутствовали строки состава, конкретные категории,
решение об отсутствии потребителей особой категории и описание питающих
подстанций. Это ограниченные подборки, не полное прочтение всех томов.
В первом случае клиент получил предупреждение о неполном обзоре; отказавший
источник не попал в доказательства. Рост скорости всего пути не принят:
десятки секунд на запрос остаются проблемой.

Для пяти найденных Word-документов пройдены все порции извлечённого
представления: 1914 структурных единиц в 278 ограниченных вызовах.
Для каждого тела сверены SHA-256, непрерывность
UTF-8-диапазонов, порядок и отсутствие повторённых единиц. В четырёх документах
независимый разбор основных таблиц сопоставил 646 строк с сохранением чисел
и связей ячеек; несовпадений не осталось. Пятый документ не имел основных
таблиц, доступных этому независимому разбору. Таблицы вложенных объектов и
графическая семантика таким сравнением не объявляются проверенными.

Шрифт Symbol в независимой проверке декодировался по опубликованной таблице
кодировки, а не по ожидаемому ответу. Нормализация проверки ограничена
разметкой, пробелами и явным шрифтовым кодированием; цифры не исправлялись.

Три найденные сканированные PDF-страницы дали 6060 символов. Их полный текст
точно совпал с объединением 17 коротких окон с закреплённым `view_sha256`.
Номера страниц и SHA-256 оригиналов сохранены. Это проверка чтения и курсора,
не доказательство безошибочного OCR всех чисел или геометрии таблиц.
На трёх изображениях также совпали результаты одиночного и переиспользуемого
вызова системного OCR.

Тяжёлый Word после автоматического таймаута прочитан отдельным вызовом:
90,58 секунды до первой порции, 0,64 секунды до следующей. При этом 92
визуальных объекта остались без распознанного текста. Их оригиналы сохранены;
это ограничение явно возвращается и не считается полным пониманием документа.

## Интерфейс и границы приёмки

Итоговые автоматические проверки кандидата:

- Rust core — 137 тестов; Rust API с Edge — 92; runtime — 7. Форматирование
  трёх crates проверено. Линкер Windows выводит служебное предупреждение
  о создании import library; отсутствие любых предупреждений не заявляется.
- Svelte — 46 тестов, проверка типов без ошибок и предупреждений, статическая
  сборка с действующей квитанцией.
- Отдельный регрессионный сценарий настоящего Docling: 500 строк таблицы,
  точные значения и продолжения, отказ по изменённому представлению/оригиналу.
- Финальный `make verify test public-check`: 2214 собрано, 2212 passed,
  2 skipped, 55 предупреждений, 18 subtests passed; полный тест — 1089,37 с.
  Пропущены POSIX TCP reuse и macOS lifetime supervisor на Windows.
  Аудит публикации не обнаружил запрещённых данных, личных путей и
  высокосигнальных признаков секретов; это не гарантия поиска любых секретов.

Журналы и частные исходные доказательства сохранены вне публикуемых файлов.
Удаление около 10 ГиБ завершённых неудачных тестовых каталогов отклонено
автоматической проверкой (`blocked by policy`); полная локальная очистка
не объявляется выполненной. Рабочие базы и оригиналы не удалялись.

Окно источника Svelte обращается к тому же `/api/rag/sources/call`, что MCP.
Добавлены таблицы, продолжения с хешем, предупреждения OCR и непрочитанных
объектов. Стили боковой навигации ограничены её классом: они больше не
меняют и не скрывают навигацию порций. Проверка в браузере не подтверждает
все сценарии нативного окна и экранного диктора.

Новая цитата Word передаёт номер единицы и хеш представления в общий читатель.
Начало чтения в середине и достижение конца не означают показ всех порций.
Старые цитаты без этих полей открываются с начала. Переход к нужной единице
проверяется компонентным сценарием; старый сохранённый ответ в браузере
не выдаётся за новый ответ модели.

На финальном бинарном API повторена сверка настоящего MCP и прямого API
интерфейса: первая и следующая порции Word, первая и следующая порции OCR
страницы совпали по тексту, идентичностям и метаданным. Неверный хеш и
продолжение без закрепления дали явные отказы в обоих каналах. Оригинал PDF
по выданной ссылке совпал с SHA-256. Проверен список из 20 инструментов;
это не утверждение о полном совпадении всех экранов настроек с MCP.

В отдельном браузерном окне на копии проверен сохранённый ответ → найденный
Word → чтение таблиц → порция 2 → порция 1 → возврат к тому же ответу.
Проверены видимые кнопки и клавиатурный переход к концу порции на ширине
1068 пикселей окна. Область поиска и пустой черновик сохранены. Новые вопросы
модели при этом не задавались. Это не приёмка экранного диктора, мобильного
экрана или установленного WebView2.

Первый общий прогон обнаружил регрессии доставки контекста/каталога и
последней пустой порции; они не были объявлены успешной приёмкой. Два отказа
упаковки также показали устаревшую сборку интерфейса после правок; интерфейс
пересобран. Четыре сценария маленького окна повторены после исправлений:
несколько чтений подряд, пустой конец поиска, длинные аргументы и переход
без схем инструментов прошли. Повторяющееся описание полей в модельных
схемах удалено без изменения ограничений; увеличение окна модели не применялось.

Автоматическое чтение Word ограничено 30 секундами на оригинал, отдельное —
120 секундами. Это защита от блокировки обзора, не устранение стоимости
полного разбора больших OLE/рисунков. Нарушения области, смена оригинала и поколения
по-прежнему дают отказ; текст из старого индекса не подставляется как оригинал.

Остаются открытыми: ускорение тяжёлых Word и обзорного пути, визуальная
проверка сложных сканов/вложений, содержательная приёмка генерации и полная
приёмка установленного приложения. Установщик и публичный релиз не собраны.
