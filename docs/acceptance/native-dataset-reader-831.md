# Приёмка нативного reader 831

Проверяется отдельный кандидат; рабочее приложение, его роли и индекс не
переключаются. Новый reader читает карту каталога и заголовки, не полный PDF.
Его результат не является доказательством утверждений.

Регрессии используют настоящий SQLite и Axum, локальный контролируемый HTTP-
ответчик и отсутствующий Python upstream. В дочернем API намеренно нерабочие
PYTHONHOME/PYTHONPATH/PATH. Проверяются strong revision при неизменном количестве
фрагментов, неизвестные и опущенные источники, Unicode/длинные имена, целый
ограниченный JSON, повреждённый snapshot, удаление набора, ошибки/исправление,
история ремонта и попытки после рестарта. Native HTTP-путь проверяет auth/Origin,
фиксацию модельной ревизии при изменении роли, потерю клиента, crash/restart и
постановку по durable outbox без Python-уведомления. Совместимому caller запрещена
Python-подготовка карты. Штатная партия отдельно проверяет создание outbox
при её атомарном завершении.

Отдельно проверен kill после commit последнего документа, до завершения партии:
повтор не конвертирует и не эмбеддит уже готовый файл, но создаёт outbox. Intake
с уже готовыми документами также публикует событие при терминальном checkpoint.

На копии реального каталога (2 документа, 35 фрагментов) локальная Qwen3.5:9b
создала карту за 20,734 с с одной попытки. Все ссылки принадлежат переданному
входу, `is_evidence=false`; Python-сервер приложения отсутствовал. Хеш исходной
копии каталога до/после совпал. Это проверка навигации по метаданным, не качества
ответов по полному PDF и не сравнение скорости с прежней реализацией.

Итоговые проверки кандидата: Rust core/API/runtime — 65/10/7 passed;
целевые регрессии — 34 passed, 1 skipped; `make verify` — 1969 collected;
`make test` — **1967 passed, 2 skipped**, 18 subtests (406,70 с).
Полный gate включает нативные Server/Edge-пути и автономные внешние навыки.
Использованы отдельные dev-бинарники; установщик и рабочее окно не менялись.

Полный Python-exit, установленный кандидат
и публичный релиз не объявляются. Остатки указаны в
[контракте](../modules/native-dataset-reader.md).
