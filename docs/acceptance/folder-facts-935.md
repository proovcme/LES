# ЛЕС Light 935. Проверка после системного аудита

Исходное условие — датасет, в котором человек ищет количество позиции из PDF.
В 934 и верная строка с количеством 17.25, и ответ 999 с той же ссылкой
проходили с `validation=not_performed`. [Контрольный опыт 934](system-architecture-934.md)

В итоговой сборке API 935 запрос через обычный чат по датасету с `Register.pdf`
и `Notes.txt` получил четыре поисковых кандидата. Управляемый провайдер
вернул «999 pcs» с ссылкой на правильный PDF. При втором вызове он указал
адрес строки. В ответе браузер показал «1 · Alpha item · pcs · 17.25».
Кнопка «Источник 2» открыла выдержку `|1|Alpha item|pcs|17.25|`, кнопка
«Показать оригинал» открыла изображение страницы 1. Успешная попытка имеет
`history_id=1`. [Запись хода](folder-trace-935.json) · [Экран ответа](folder-answer-935.jpg) · [Страница оригинала](folder-source-935.jpg)

В отдельном прогоне этого API и Qdrant прошли **24 из 24** проверок.
Двенадцать относятся к извлечению PDF и чату по PDF-таблице, восемь — к
числу в Excel и в обычном абзаце PDF, две — к чтению качественного текста,
ещё две — к повторной отправке и повтору действия с записью. Контроли
включают двукратную подмену, отсутствие данных и повреждённый отпечаток
страницы. В четырёх вариантах PDF-абзаца подмена `17.25 m` на `999 m`
потребовала адрес выдержки. Тот же ответ с `17.25 m` прошёл за один вызов.
Происхождение выбранной строки подтверждает программа. За выбор подходящей
позиции из нескольких похожих строк отвечает модель.
SHA-256 проверенного здесь API — `4326d43890db7c6984552b5d889a2b0e1b44c7d456469a80c89e036c52665d41`.

Общий `make verify` собрал 2272 теста. В `make test` прошли 1954, пропущены
318, падений нет. Целевой нативный прогон выше выполнен отдельно с явными
путями к собранным компонентам. В интерфейсе прошли 68 тестов компонентов.
Три падения общего прогона 934 в этой серии не воспроизвелись.

## Установщик и живая модель

Полный установщик стандартной Windows-версии занимает 156 325 810 байт.
SHA-256 — `77dce50730cd484bff0cfda465f8c33c334a440e14061b3d68e700a74d0eeb72`.
В изолированном профиле штатный установочный скрипт из этого архива обновил
927 до 935. Сохранился прежний диалог. После перезапуска повтор с тем же
ключом вернул ровно тот же ответ и тот же ID. Явный откат вернул запускаемую
927 с прежним диалогом. Затем реальный рабочий профиль обновлён полным
NSIS-установщиком с 928 до 935. Проверены загрузка окна, состояние API,
сохранность документов, истории и назначений моделей. Доступен откат на 928.

**Проверка качества с живой Qwen 3.5 2B выявила ложный отказ.**
Через установленную 935 проиндексированы PDF и текстовая заметка с BGE-M3.
Для вопроса о количестве Alpha item журнал подтвердил первое окно модели
и отпечаток нужной строки у источника №1. Модель ответила, что количество
в таблице отсутствует. Пользователь не получил ни 17.25 pcs, ни ссылки.
Управляемый опыт в браузере проверял другую ошибку — публикацию подменённого
значения. Для следующих изменений остаётся отдельный критерий: живая модель
на этом же вопросе должна вернуть количество и ссылку, а после удаления
строки — явно сообщить об отсутствии. Проверка на чистой Windows остаётся
открытой. [Ответ модели, вход и хеши](folder-install-935.json)

В следующем опыте первичное сообщение этого же чата и его короткие варианты
получила одна живая Qwen. Затем выбор ячеек проверили на двух рабочих книгах.
[Сравнение способов чтения папки и решение по архитектуре](folder-window-935/README.md)

## Изменения

- В табличном окне модель выбирает адрес. Программа читает значения из
  фактически отправленного фрагмента и связывает цитату с версией документа.
  При недопустимом ответе предусмотрен один повтор. Для смешанного набора
  применяется тот же порядок, когда ответ ссылается на подтверждённую строку.
  Источники без табличного утверждения допускают свободный текст.
  [Обработка ответа](../../api/src/chat/runner.rs) · [Сохранение происхождения выдержки](../../api/src/chat/tools/sources/pdf_focus.rs)
- До подтверждения финала интерфейс держит ключ одной отправки. Сервер
  может вернуть сохранённый ответ. Следующее самостоятельное сообщение
  получает новый ключ. [Клиент](../../desktop/light/frontend/src/lib/workspace.svelte.ts)
- Квитанция сборки учитывает подключённые через `include_str!` и
  `include_bytes!` данные из исходников зависимых модулей внутри проекта.
  Стандартный комплект проверяет вариант исполняемого файла. Сценарий выпуска
  запускает тест PDF на байтах из собранного комплекта. Отдельный откат
  установки использует журнал и восстанавливает указатель на установленную
  версию. [Квитанция](../../tools/native_asset.py) · [Откат](../../installers/windows/light/package.ps1)
- При повторном использовании подготовленного Python навыков сборщик сверяет
  записанный хеш `uv.lock` и хеш перечня фактически скопированных файлов с
  предыдущей квитанцией. Контроль отдельно меняет lock и один файл среды.
  [Упаковка](../../tools/build_light_package.py) · [Тест](../../tests/test_light_skill_python_asset.py)
- При EOF обработчика Windows Rust даёт процессу ограниченное время
  завершиться со своим кодом до освобождения группы процессов. Для наблюдаемого
  окна модели источником размера служит измеренная вместимость с ограничениями
  оператора и профиля. Исправлены 11 устаревших значений сохранённого эталона,
  остальные поля и случаи сохранены. [Обработчик](../../core/src/worker_host.rs) · [Правило окна](../../core/src/model_profile.rs)

## Свободный текст и готовый движок

В двух новых папках было по три коротких оригинала. Шесть вопросов заданы
дважды живой локальной Qwen 3.5 2B. Перед каждым прогоном папки заново
проиндексированы через API с BGE-M3 и Qdrant. Стенд сверял хеши оригиналов
и наличие каждого полного отрывка в первом запросе к модели.
LlamaIndex 0.14.22 получал тот же первый набор отрывков в том же порядке.
Оба варианта работали через один локальный адаптер с общей инструкцией
о ссылках. У первого оставался штатный шаблон CitationQueryEngine, у второго
шаблон задавал правила частичного ответа и отказа.
Каждый прогон использовал отдельную контрольную сборку API 935. Хеши записаны в протоколе.
Полный зачёт требует однозначного ответа на запрошенное свойство и точного
набора ссылок. При отсутствии сведений зачтён явный отказ без связанных ссылок.
Формулировки проверены вручную, номера ссылок — парсером ЛЕСа.
[Входы и 36 ответов](folder-transfer-935.json) · [Код повтора](../../tools/evaluate_folder_transfer.py) · [Документация CitationQueryEngine](https://developers.llamaindex.ai/python/examples/query_engine/citation_query_engine/)

| Вопрос | ЛЕС | LlamaIndex, стандартный | LlamaIndex, свой шаблон |
|---|---|---|---|
| Температуры на двух постах | Обе верны | Добавил ссылку про хранение | Обе верны |
| Температура и неизвестный интервал на Кедре | Лишний пост или отсутствует ссылка на Кедр | Обе части верны | Обе части верны |
| Отсутствующий срок гарантии | Срок оставил неизвестным | Ответил «19 градусов Цельсия» | Срок оставил неизвестным |
| Редакция на июнь 2024 года | Отказался при наличии срока | 14 дней | 14 дней |
| Редакция на февраль 2025 года | 6 дней | 6 дней | Отказался при наличии срока |
| Тот же вопрос другими словами | 6 дней, дополнительная ссылка на старую редакцию | 6 дней | Отказался при наличии срока |
| **Полный зачёт в каждом прогоне** | **3/6** | **4/6** | **4/6** |

На каждый прогон потребовалось семь вызовов модели у ЛЕСа и по шесть у двух
вариантов LlamaIndex. Время записано отдельно. ЛЕС проходил весь путь от
публичного API через поиск. LlamaIndex начинал с готовых выдержек.
Первый запрос первого прогона включал ожидание свободной памяти.
На этой выборке замена движка целиком привносит новые ошибки. Для следующего
сравнения нужны реальные папки с похожими объектами и пересекающимися редакциями,
а также отдельная проверка отказа. Для явно размеченного кода или периода
действия отбор можно проверить программно перед передачей фрагментов.
В корпусе этого опыта интервалы заданы обычным текстом. Стенд RAGHOUND из
обсуждения служил примером постановки контроля и здесь не запускался.

## Наблюдение за папкой

На локальном NTFS диагностический опыт создал 64 файла по 1 МиБ. Полная
сверка хешей прочитала 64 МиБ за 64 мс. Уведомление Windows при записи одного
файла позволило прочитать 1 МиБ и подтвердить замену за 21 мс. Размер и время
записи сохранились. Когда уведомление намеренно пропустили, полная сверка
нашла тот же изменённый файл. Измерение описывает локальный синтетический
набор и файловый ввод-вывод. Для решения о смене штатного наблюдателя
остаётся испытание на реальной сетевой папке. [Код повтора](../../tools/measure_folder_notifications.ps1)

## Состав Windows-поставки

В обычной сборке `build()` вызывает `stage_native_code()`. Этот путь переносит
нативные компоненты, фронтенд и отдельный Python навыков. Унаследованный
`stage_code()` со списком `backend/` и `proxy/` — другая функция.
Семь кандидатов в неиспользуемые модули `proxy/services/` из аудита 934
не участвуют в формировании ответа штатным Windows API. Удаление таких
файлов из репозитория затрагивает поддержку старых точек входа и не исправляет
ошибку значения в чате. [Сборка поставки](../../tools/build_light_package.py) · [Карта Python](../CODE_RUNTIME_MAP.md)

В стандартной Rust-сборке компилятор помечает `query_cache::packet` как
неиспользуемую функцию. У неё есть потребители в варианте Edge и в тестах.
[Условная компиляция и вызовы](../../api/src/chat/tools/sources/retrieval/query_cache.rs)

## Очерёдность дальнейшей работы

1. Для папок с идентификаторами и редакциями проверить имеющуюся разметку.
   Сравнить поиск по точному идентификатору и сроку действия с нынешним
   Hybrid на одних вопросах. Отдельно посчитать попадание нужной карточки
   в выдачу, попадание в сообщение модели и корректность ответа.
2. Прогнать обычный чат и два варианта CitationQueryEngine на независимых
   примерах из рабочих папок. Успех требует верного объекта, значения,
   применимой редакции, открываемого оригинала и отказа при отсутствии
   данных. По каждому расхождению сохранять первый неверный этап. Решение
   о замене сборщика принимать после повторяемого выигрыша на этих примерах.
3. Для публичного выпуска пройти установку, обновление и откат на чистой
   Windows с живой моделью. Для смены наблюдателя папок измерить чтение и
   задержку на SMB при потере уведомления и разрыве соединения.
