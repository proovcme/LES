Проверен отдельный экземпляр Rust API с `--chat-owner rust`, без адреса
старого сервера, Python API и NiceGUI. Рабочая установка и её назначения
моделей не переключались.

Целевые проверки: **38 passed**. Публичная авторизация; изоляция ключей
повторов между клиентами и приватным входом; повтор JSON через SSE;
отказ от неподдерживаемых параметров до генерации; блокировка внешней модели
до DNS и чтения её ключа. Проверены восстановление карты источников и
причины сбоя, незавершённые действия, выдача разных страниц PDF и вырезка,
отказ при неверном SHA и область «только выбранные источники». Автономный
внешний навык проверен в том же Rust-цикле с отдельным CPython.

## Реальный корпус

Копия существующей выборки из двух документов (PDF и XLS) и индекса Edge.
По обычному JSON-адресу Qwen3.5:9b выполнила `search_sources` и вернула
ссылку на индексированный фрагмент. Повтор по обычному SSE-адресу вернул
тот же сохранённый ответ. Первое обращение — **65,09 с** с холодным поиском
и генерацией; это не замер задержки Rust или Edge отдельно.

Из веб-чата отправлен следующий запрос на физическое чтение страницы 2.
Модель вызвала `read_pdf_source`; проверены точный ID, страница и полнота
чтения инструмента. После перезагрузки браузерного диалога кнопка цитаты
открыла карточку, а «Показать оригинал» отобразило изображение страницы 2.
Дополнительно проверены SHA выдаваемого оригинала, PNG на том же адресе
страницы и неизменность оригиналов. Скопированный индекс, временные
оригиналы и состояние удалены; тестовая Qwen выгружена.

Проверены механика источников и интерфейс на выборке, без независимой
оценки точности по всему корпусу. Остальные API, специальные сценарии и
экранная часть NiceGUI до полного паритета ещё используются штатным запуском.
