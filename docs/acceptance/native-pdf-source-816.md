Проверка 7 ноября 2026 года. Изменены исходники; для испытания собраны Rust DLL

## Настоящий чат Qwen

Отдельная копия содержит 19 245 точек, контрольный PDF — 45 страниц и 339 точек.
Работают штатный `/api/chat/stream`, история, Svelte, BAAI/bge-m3, SQLite BM25/RRF,
контекст и локальная Qwen3.5:9b через Ollama. Подставленных ответов нет.
Проверка генеративным судьёй и реранкер отключены явно в запросе стенда.

Контрольный вопрос просит на конкретной физической странице найти строку
«Имя файла», проверить её через `read_pdf_source` с буквальным `q` и привести
имя DWG с цитатой. Модели предоставлен сам поисковый литерал: этот эксперимент
не доказывает самостоятельный подбор литерала или качество на 100 вопросах.

| Сценарий | Проверенный результат |
| --- | --- |
| Обычный чат | Реальный вызов read_pdf_source, extractor les.pdfium.page.v1, настоящий ID каталога, SHA-256 редакции 1, физическая страница 5 |
| Запись редакции во время чата | Qwen прочитала физическую страницу 5 редакции 1; публикация новой редакции ждала завершения запроса |
| После публикации | Новое физическое чтение страницы 6 редакции 2 и ссылка на этот оригинал |
| Падение Edge во время дочитывания индекса | SECTION_READ_UNAVAILABLE, ноль текстовых событий, финального ответа нет |
| Падение Edge во время настоящей генерации Qwen, фаза committing | Ответ завершён по собранному контексту, реальное чтение PDF и ссылка на страницу 5 сохранены |
| Восстановление после двух падений | Редакция 1 и 19 245 точек; незавершённая редакция удалена |
| Изменение исходного PDF после того, как Qwen выбрала инструмент, до его выполнения | Rust вернул PDF_REVISION_CHANGED; чат выдал понятную ошибку, ноль текстовых событий и ни одного final |
| Старый хеш после публикации | HTTP 409, прежний оригинал не подменён новым |

Для ошибки изменения файла использован failpoint перед настоящим исполнением
выбранного Qwen инструмента. Только файл в копии временно заменён другими
байтами, затем восстановлен с проверкой SHA-256. Ответ модели не имитировался.

Во всех четырёх успешных итогах есть успешный физический вызов инструмента.
Его текст целиком сопоставлен с тем же диапазоном символов физической страницы
в независимом Python/PDFium reader. Хеши всех source_map соответствуют одной
ожидаемой редакции; источник физического чтения включён в evidence и цитаты.
Проверены оригинальные байты, PNG и SHA-256. В браузере открыт сохранённый
ответ, цитата, изображение физической страницы 6 и возврат к ответу.

В потоках успешных запросов получено 210 / 231 / 216 / 70 текстовых событий
соответственно для baseline / crash-generation / overlap / after-update.
Полное время — 23,24 / 16,61 / 13,60 / 19,88 с. Это отдельные прогоны с прогревом,
не p50/p95 и не сравнительный бенчмарк.

## Оставшиеся ограничения, выявленные испытанием

- Общая достоверность ответа без вызова инструмента этим guard не проверяется.
  В отдельном вопросе о странице 9999 Qwen отказалась вызывать инструмент,
  но сама неверно заявила максимальное число страниц по найденным фрагментам.
  Этот сценарий не принят как проверка отказа инструмента. Ошибка настоящего
  вызова проверена отдельно через замену байтов копии, как указано выше.
- В предварительном прогоне полного чтения длинной страницы Qwen остановилась
  после первой порции. Guard не пропустил terminal answer и вернул
  PDF_PAGE_INCOMPLETE. Надёжное автоматическое прохождение всех курсоров
  маленькой моделью не заявляется. Адресное чтение конкретной строки прошло.
- Живой SSE передаёт конкретную понятную причину. После повторного открытия
  прерванного диалога существующий UI показывает общее «Ответ прерван»:
  сохранение конкретной причины в истории остаётся отдельным долгом.
- OCR/vision не подменяются текстовым чтением. Скан без текстового слоя даёт
  PDF_OCR_REQUIRED; распознавание и проверка графики идут отдельными функциями.
- Edge остаётся экспериментальным транспортом стенда. Читающая блокировка,
  указатель публикации SQLite и согласование каталога принадлежат стенду;
  BM25-снимки подготовлены заранее, старые поколения удерживаются. Новая
  редакция получена добавлением пустого первого листа и переносом координат,
  а не повторным прогоном производственного импорта. Масштаб 100 тысяч точек,
  очистка поколений и полный переход runtime на Rust не подтверждены этим тестом.
