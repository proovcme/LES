# Кандидат 777 · проекты, заметки и состояние контекста в Rust

Дата: 01.11.2026. Отдельная Windows-сборка; установленный 773, пользовательские
документы и модельные назначения не менялись. Установщик/публичный релиз не
собирались и не публиковались. Это продолжение переноса, не его завершение.

## Изменения

- Удалён SQL из project_service, memory_service и conversation_context_service.
  Те же таблицы/ID/meta.db теперь обслуживает Rust catalog: проекты/привязки,
  заметки/старые колонки, состояние сводки/забывания и выборки истории.
- HTTP напрямую в Rust: 20 из 265 method/path пар вместо 6. Остальные 245
  явно проксируются; отдельные проверки require_admin для изменений проектов.
- Сохранены построение связей после создания заметки и прежняя генерация сводки.
  Они пока Python, как и отдельный Memory Core с типизированными записями.
- Сравнение revision, запись/забывание и связанные изменения атомарны.
  SQL-отказ откатывает операцию; исходная история после забывания сохраняется.

## Автоматическая проверка

С одинаковыми сценариями против frozen Python и Rust: **78 passed** в целевом
наборе, включая реальные Axum/SQLite маршруты. Проверены чужие области,
администратор/пользователь, ссылки, старые колонки, byte-preserving reads,
12 конкурентных изменений контекста (один победитель), rollback удаления проекта
и изменения заметки, реальная деривация связей, задержанная сводка после forget.

`make verify`: версия/карта/API baseline и **1499** собранных тестов.
`make test`: **1497 passed, 2 skipped, 18 subtests passed**, 152,24 с.
`make test-mail`: **66 passed**, 8,84 с. Rust core **12**, API **1**, runtime **3**
тестов; их release assets собраны из lock offline с remap. Tauri-код в этом
этапе не менялся, использован ранее проверенный executable кандидата 776.
Пропущенные сценарии не считаются выполненной приёмкой.

## Живое отдельное окно

Собственный staged runtime и состояние, принятые Python-зависимости совместимости,
новые native core/API/runtime и собственный Qdrant. Test-only oracles в payload
отсутствуют; Python импортирует только соответствующий candidate runtime.
Заголовки подтвердили фактического владельца каждого проверяемого маршрута.

Через настоящее поле чата сохранён Unicode-черновик. Через native API установлены
сводка/переключатели enabled и auto_summary, отключена заметка в своей области и
сохранена её связь с проектом. Принудительно завершён собственный Rust API, затем
собственный legacy API. После каждого сбоя восстановлены службы, совпали черновик,
проект и память. После обоих сбоев отдельно сверены revision/сводка/переключатели,
отключённая заметка и project link. Предыдущие PID служб завершились.

Восстановленный текст и «Черновик сохранён» проверены визуально. Штатная кнопка
закрытия завершила окно, наблюдатель, runtime и четыре службы; статус stopped.
Сгенерированные ответы/реальный Qwen и пользовательский корпус в этом сценарии
не использовались. Отдельные формы проектов/памяти в classic UI в этой приёмке
вручную не проходились; API-проверки не объявляются визуальной приёмкой этих форм.

## Оставшаяся работа

Авторизация, чат/harness, поиск/BM25, очереди и публикация индекса, граф, отдельный
Memory Core, модельная генерация сводки, форматные адаптеры и NiceGUI ещё Python.
Автономные Python-навыки по-прежнему используют прежний runtime;
выделенный совместимый исполнитель и его inventory/replay ещё предстоят.
Calamine/PDFium согласованы, но не подключены. Нет приёмки чистой Windows или
обещания ускорения всего приложения. Откат — прежний согласованный код/DLL,
переключение нынешних фасадов на Python SQL не предусмотрено.
