# Приёмка публичных вложений Rust-чата · 840

Отдельный экземпляр `--chat-owner rust` работал без Python API и NiceGUI.
Штатный запуск и назначения моделей рабочего экземпляра не менялись.

Из выборки рабочего датасета взяты два оригинала: PDF и XLS. XLS загружен
через публичный API; повтор с тем же ключом вернул прежнюю квитанцию.
Папка из двух файлов прочитана целиком без записи в индекс. PDF прикреплён
через браузер; локальная Qwen3.5:9b прочитала вложение и указала его раздел и
год. В истории сохранена квитанция именно этого PDF. Сверены SHA-256 исходных
и сохранённых файлов. Тестовые оригиналы и состояние удалены, модель выгружена.

Отдельно проверяются остановка посреди загрузки и очистка при следующей
загрузке, запрет повтора чужим клиентом, срок хранения ключа, ошибка
неполной папки и пустой список наборов при первом запуске. Для внешней
модели проверяются отказы до обращения к провайдеру: нет согласия, закрытый
набор и вложение; с разрешённой областью запрос доходит до проверки
настройки ключа. Живой внешний сервис в этой приёмке не использовался.

Результаты относятся к чтению вложений, а не к индексации из скрепки,
полному корпусу или установленному приложению.
