# Build 746 — ограниченный контекст и журнал проверки таблиц

Статус: кандидат в исходниках. Не установлен поверх пользовательского экземпляра;
публичный установщик и GitHub не изменены. Код написан независимо от большого ЛЕС.
Предметных сметных функций, новых зависимостей и скрытой смены модели нет.

## Проверено

После живой проверки и исправлений `make verify` прошёл. `make test`:
1058 тестов и 18 subtests прошли, 24 предупреждения зависимостей/жизненного цикла,
102,31 с. Целевые проверки протокола и capabilities: 35 прошли.
`make public-check` прошёл; публикация не выполнялась.

- XLSX/XLSM/CSV сохраняют координаты, нули, пустые промежутки, многострочный текст,
  формулы и ошибки. Повреждённая книга возвращает ошибку чтения, а не падение API.
- Задание на 300 строк продолжается с новым соединением хранилища после каждого
  пакета; повторная доставка и параллельные записи не удваивают счётчики.
  Неполный пакет, чужие ячейки и устаревшие решения отклоняются атомарно.
- Реальный ToolHarness проходит 70 синтетических строк с заголовком; прежние
  пакеты не накапливаются в модельном контексте. Непоместившийся обязательный
  пакет останавливает запрос, вместо незаметного удаления данных.
- Изолированный экземпляр API/UI/Qdrant проверен с управляемым OpenAI-ответчиком:
  создание подключения и диалога, загрузка CSV с кириллицей и пробелом в имени,
  next → record → ответ; следующий запрос без вложения видит то же задание.
  Это проверка соединения компонентов, не качества рассуждений модели и не GUI.
- Пользовательская книга проверена только на чтение, вне репозитория: 77 непустых
  строк, 431 ячейка, шесть нулевых значений. Все координаты и исходные значения
  совпали с независимым обходом оригинала. Содержание в публичные тесты не включено.

## Осталось до установленной приёмки

Первоначальная ошибка подключения оказалась отсутствующим локальным SSH-туннелем;
он восстановлен. Прежний ID 35B сервер больше не принимает. По явному выбору
пользователя последующие проверки проведены с моделью Mara, заявленный контекст
24576 токенов. Соответствие Mara конкретным весам Qwen не установлено.

Живые проверки выявили и закрыли дефекты протокола: повторный start терял текущий
пакет; передача результата как справочного текста вызывала цикл; tools-probe с
одним выходным токеном давал серверную ошибку. Теперь последний шаг передаётся
парой assistant/tool, пакет сохраняется при повторном start, probe допускает
полный вызов инструмента (128 токенов). Координаты явно описаны в JSON-схеме.

Маленькая таблица: 3/3 строки сохранены через реальный API изолированного Light.
Однако следующая фраза о продолжении привела к новому заданию вместо прежнего:
автоматический выбор продолжения моделью приёмку НЕ прошёл, старые решения целы.
Пользовательская книга: только 6/77 строк сохранены. Модель ошибочно исключала
строки с данными как заголовки, затем передала значения вместо координат и чужой
ID пакета; запись отклонена. В ответе она всё равно заявила о сохранении результатов.
Это отрицательный результат проверки качества, а не успешное завершение задания.
Добавлено независимое уведомление о неполноте перед итоговым текстом модели;
полная обработка этой книги на Mara остаётся открытой.

Назначения моделей и установленный пользовательский экземпляр не изменены.
Требуется довести устойчивое продолжение и качество обработки, затем пройти
пользовательский путь в установленном приложении.
Счётчик покрытия не доказывает правильность текста модели. Ограничения длинных
ячеек, экспорта, удаления и возобновления внешних цепочек перечислены в
[контракте модуля](../modules/document-tasks.md).
