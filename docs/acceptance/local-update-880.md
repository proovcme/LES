# Локальное обновление 880

14 ноября 2026, локальная программа 0.1.1/880. Это обновление установленного
приложения, а не публикация нового установщика GitHub.

## Выполнено

- Rust runtime, API, Docling/Xberg-обработчик и оконная оболочка собраны
  в оптимизированном режиме из текущих исходников. Манифест полного комплекта
  проверен штатным установщиком; предыдущая программа сохранена для отката.
- Внешняя Python-среда сохранена с прежними зависимостями и их происхождением.
  Она не выдана за новое разрешение зависимостей из текущего dev lock.
  Шесть синтетических проверок исполнителя прошли, включая числовые библиотеки,
  завершение дочернего процесса и возобновление подтверждённых строк.
- Новый native owner, API и MCP запущены на отдельной копии состояния.
  MCP опубликовал 21 инструмент; вызовы каталогов выполнены без модели ответов.
- Установщик заменил только программу. До запуска новой версии проверены
  контрольные суммы сохранённых файлов состояния. Предварительно созданы
  SQLite-копии восстановления; автоматическое исправление старых баз не выполнялось.
- `les start` подтвердил готовность установленного экземпляра. Его API ответил,
  прямой запуск установленного MCP прошёл и вернул прежние идентичности каталогов.
  Старые `.venv` и вход NiceGUI отсутствуют в активном каталоге программы.
  Временный экземпляр на копии остановлен, его копия состояния удалена.

## Ограничения

Текущее соединение Codex с прежним MCP закрылось при обновлении (`Transport closed`).
Прямая проверка нового сервера успешна, но она не подменяет переподключение клиента.
Computer Use остановил проверку браузера: не удалось уверенно определить URL.
Автоматизация окон в этом проходе прекращена; визуальная приёмка не заявляется.

Документы и модель ответов в этом обновлении не использовались для оценки генерации.
Проверка копии состояния не является новым испытанием RAG на пользовательском корпусе.
Не закрыты ограничения [источников](native-source-performance-878.md) и
[пары с Увязкой](uvyazka-viewer-handoff.md). Отдельная установка Увязки и её выпуск
не выполнены этим обновлением LES. Старый пользовательский индекс не заменялся
исследовательской копией и не переводился на Edge.

## Проверки GitHub

В запуске проверок PR #7 оконная оболочка прошла. Основная Windows-задача
прервана на ограничении 90 минут при сборке Word/PDF-зависимостей; аннотация
GitHub подтверждает превышение максимального времени. Лимит увеличен до
150 минут, все команды и поведенческие проверки сохранены. Новый полный
запуск GitHub не объявляется завершённым до его фактического результата.
Предыдущий локальный gate исходников: 2215 passed, 2 skipped; это отдельно
от установочной проверки и не подтверждает качество ответов модели.
