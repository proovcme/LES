# Native runtime 775 · состояние приёмки

Кандидат в исходниках и отдельном executable. Пользовательский установленный 773
не изменялся; полный установщик и публичный выпуск не собраны.

Первые проверки без моделей:

- `runtime/`: 3 Rust-теста (аргументы, lock, случайные идентификаторы, безопасный browser reopen).
- Tauri: 8 Rust-тестов, включая запрет скрытого Python-fallback в native-режиме.
- 7 интеграционных тестов отдельного native executable с настоящим Qdrant и
  специальными тестовыми API/UI. Взаимные lock с Python, защита среды, восстановление
  после API crash с сохранением SQLite и точки Qdrant, нормальное закрытие, EOF,
  авария native owner с завершением внука, предел перезапусков, receipt/откат asset.
- Модельные подключения и пользовательский набор не использовались/не менялись.

Эти тестовые API/UI проверяют управление процессами, не весь RAG и не интерфейс
продукта. Пользовательский пакет по-прежнему содержит Python API/парсеры/UI;
новый executable сам по себе не доказывает удаления Python из основы.

## Отдельное окно полного кандидата

Собран release Tauri с явным native launcher. Runtime продукта поставлен сборщиком
в новый каталог, embedded Python использует его собственные модули; отдельное
состояние без копирования пользовательского корпуса или назначений моделей.

В нативном окне Svelte создан диалог «Проверка Rust 775». Поле ввода заполнено
через UI значением с кириллицей, эмодзи и длинным тире; API подтвердил сохранение.
Завершён только принадлежащий этому кандидату API, проверена его связь с native PID.
Rust восстановил службы. Черновик появился в том же диалоге и снова показал
«Черновик сохранён»; API подтвердил сохранность проекта и проектной памяти.

Обычная кнопка закрытия окна прошла native flush/ack: внешний наблюдатель и native
owner завершились с кодом 0; статусы стали stopped, API/UI/Qdrant исчезли. Список
окон подтвердил отсутствие кандидата. Рабочее пользовательское окно не трогалось.
Снимки использовались для проверки, новый визуальный дизайн этим этапом не вводился.
Модельный ответ, OCR/вложения/почта в этом live-пути отдельно не проверялись;
их исходные реализации сохранены и проверяются прежними регрессионными gates.

## Совместимость API

`tools/native_api_contract.py` в отдельном процессе с временным состоянием и пустым
env снимает контракт действующего Light API. Зафиксированы 265 method/path пар,
operation_id и SHA схем входа/выхода и components. `make verify` проверяет отсутствие
нерассмотренных изменений. Это baseline для последующего Rust API, не доказательство
его реализации или равенства бизнес-логики. Текущие handlers по-прежнему Python.

## Общие gates

- `make verify`: версия/карта, 265 API-контрактов, синтаксис, 1430 собранных тестов.
- `make test`: 1428 passed, 2 skipped, 18 subtests, 133,91 с. Указаны свежий
  LES_CORE_LIBRARY, LES_CORE_MODE=native, LES_TEST_NATIVE_RUNTIME и настоящий
  LES_TEST_NATIVE_QDRANT. Форматные mock-тесты остаются inline; новый worker gate
  отдельно вызывает настоящий native-host/адаптер, как описано в приёмке 774.
- `make test-mail`: 66 passed, 8,30 с; кандидат закрыт до этого прогона.
- Rust core: 11 passed; native runtime: 3 passed; Tauri: 8 passed.
- Rust fmt core/runtime, `git diff --check`; отдельные remapped release builds
  native runtime (1 796 096 байт) и desktop. Это размер контроллера, не установки.

Следующий этап API/SQLite и форматов требует новых зависимостей по
[зафиксированному предложению](../modules/native-dependencies.md). Они не загружались
до согласования; перенос основы не завершён. Автономные Python-навыки сохранены
по прямому уточнению владельца как отдельное исключение совместимости.
Проверки всех сторонних импортов одобренных навыков
должны предшествовать сокращению их совместимого окружения.
