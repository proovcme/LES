## Выполнено

- Apple Silicon, macOS 26.6.2: установка из frozen `uv.lock` в отдельную `.app`.
- Собственный Qdrant 1.19.1, SHA-256 архивов из официального GitHub release;
  отдельные state, коллекция, случайные loopback-порты и проверка instance ID.
- Холодный запуск через `.app/Contents/MacOS/LES`: launcher `ready`, API и UI
  подтверждают тот же instance ID. Автоматическое открытие внешнего браузера
  при CLI-проверке подавлено; интерфейс проверялся через отдельную тестовую вкладку.
- Реальные роли: локальная Ollama, Qwen3 8B для ответа и Qwen3 Embedding 0.6B
  для поиска. Служба Ollama уже существовала; embedding-веса загружены отдельно.
- Вымышленный UTF-8 документ с кириллицей, пробелами и `#` в имени:
  INDEXED, один непустой фрагмент, dense/BM25 поиск, ответ с правильной датой
  и ответственным, source map. Байты оригинала совпали с загрузкой.
- UI: выбор набора → отправка вопроса → завершённый ответ (6,3 с в этом
  одиночном опыте) → цитата → встроенный оригинал → возврат к ответу.
  Этот результат не является общим бенчмарком.
- Реальный Apple Vision OCR на искусственном изображении: извлечены текст
  `GREEN LIBRARY` и год `2031`; модель для OCR не скачивалась.
- Настоящий адаптер MLX Manager: список наборов и один валидный источник из
  запущенного LES. Постоянное подключение в пользовательском Manager не менялось.
- Полные исходные `make verify` и `make test`; `uv lock --check`, `git diff --check`.
  Итог: 1134 passed, 56 skipped, 18 subtests passed.
  Дополнительные macOS/пакетные проверки — 12 passed после изменения повторного запуска.

Доказательства локального опыта находятся только в игнорируемом `artifacts/`:

## Найденные ограничения

Назначение embedding-роли не мигрирует контракт индекса. Первый опыт был
остановлен `EMBEDDING_INDEX_MODEL_MISMATCH`; для успешного опыта явно создана
отдельная коллекция с согласованной моделью и размерностью. Автоматическое
исправление пользовательских индексов не добавлялось.

Ollama оставляла обе тестовые модели в памяти. Защита отказала в ответе при
нехватке свободной памяти; после выгрузки именно тестовых моделей и обновления
метрик ответ прошёл. Пороги защиты не уменьшались.

Нативный Tauri Mac shell, Finder/double-click, чистый Mac без developer tools,
подписанный DMG, Intel-железо, почта, сложные таблицы и полный OCR-корпус не
проверены. Это работающий локальный browser preview, а не готовый массовый
macOS-инсталлятор. [Установка и зависимости](../MACOS_PREVIEW.md).
