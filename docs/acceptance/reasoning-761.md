# Явное размышление модели — кандидат 761

Дата: 2026-10-10. Исправление подготовлено в отдельном установленном Mac preview
с отдельным состоянием. Рабочее приложение и его назначения моделей не менялись.
История, частные промпты, документы, галерея и постоянные журналы не читались.

## Что исправлено

Размышление больше не принудительно отключено для всех запросов. В редакторе
версии профиля есть явный переключатель и общий бюджет размышления/ответа.
По умолчанию режим выключен; сохранение создаёт новую ревизию и не переписывает
старые чаты. Диапазон бюджета — 512–8192 токенов, исходное значение — 2048.

ContextGovernor резервирует этот общий бюджет до упаковки источников. Если
бюджет не помещается в ёмкость подключения, запрос отклоняется. «Короткий ответ»
не уменьшает включённое размышление до 512 токенов. Само подключение, корпус,
выбор модели и пороги памяти автоматически не меняются.

Локальный совместимый API получает `chat_template_kwargs.enable_thinking`,
проверенный native chat — `think`. Поддержка режима самой моделью всё ещё
необходима. Для generic облачного подключения протокол не подтверждён;
явное включение приводит к понятной ошибке, без скрытого изменения запроса.

Отдельные поля reasoning и inline-теги отделяются от ответа, включая заранее
открытый `<think>` и границы тегов между SSE-событиями. Клиент получает итоговый
текст и этапы «Модель думает» → «Модель пишет ответ», без внутреннего текста.
Исчерпание лимита на размышлении до итогового текста становится явной ошибкой.
Отдельные поля размышления учитываются в ограничении размера ответа.

## Выполненные проверки

[Квитанции и результаты](reasoning-761-results.json).

- 64 целевых теста: протоколы, разделение, пределы бюджета/контекста, неизменяемость
  привязки старого чата, ограничение размера и отказ неподтверждённого режима.
- `make verify`: 1241 тест собран. `make test`: 1185 passed, 56 skipped,
  18 subtests passed. Карта кода, версии и frozen lock проверяются отдельно.
- Установленный API вернул build 761, сохранил включённый режим с бюджетом 2048
  в активной тестовой версии и отверг бюджет 8193 (HTTP 409).
- Штатный `/api/chat/stream` прошёл поиск по прежнему синтетическому набору,
  упаковку источников и вызов авторского тестового протокольного сервера.
  Наблюдались `enable_thinking=true`, `max_tokens=2048`, правильный порядок
  generation → thinking → answer и совпадение стрима с итогом. Внутренний
  тестовый текст отсутствовал во всех клиентских событиях. Этот сервер не модель;
  испытание подтверждает проводку настроек и SSE, не качество ответов.
- SHA-256 десяти затронутых файлов установленного runtime совпали с исходниками.
  Контейнер Mac preview повторно использован, номер runtime и bundle — 761.

## Проверка реальной 35B — не завершена

Тестовая роль ответов явно назначалась локальному текстовому варианту
Qwen3.6-35B-A3B-oQ3; штатное рабочее назначение не менялось. Проверка возможностей
сервиса прошла, но пять попыток одного полного вопроса завершились
CHAT_MEMORY_PRESSURE. На Mac M4 с 24 ГБ приложение измеряло около 3,3 ГБ доступной
памяти при минимуме 4 ГБ и превышение предела swap. Перезапуск только тестового
сервера и явная выгрузка тестового embedding не дали завершённого полного ответа.
Ollama сообщала около 5,8 ГБ у резидентного embedding-процесса с контекстом 32768;
это наблюдение, не доказательство единственной причины.

Дополнительная попытка через установленный транспорт с заранее выбранными
синтетическими цитатами завершилась ReadTimeout/UPSTREAM_STREAM_INTERRUPTED.
Отдельный короткий запрос к сервису также истёк через 15 секунд. Причина остановки
движка не установлена: журналы не читались. Эти попытки не получили оценок смысла.

Следовательно, build 761 не имеет подтверждённой оценки качества штатного RAG
на 35B. Результаты трёх отдельных исключений из [760](full-chat-760.md) остаются
исторической диагностикой; они не заменяют это испытание. Не снижались пороги
памяти, не включался скрытый fallback и не подставлялись предметные ответы.

Открыты: ресурсный контур 35B + embedding, повторная полноценная оценка,
precision контекста и калибровка отрицательных запросов. Геометрия и клики UI,
нативная доступность и чистая Windows не проверялись; Computer Use не применялся.
Полного установщика 761 и обновления пользовательской установки нет.
