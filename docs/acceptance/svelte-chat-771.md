# Build 771 — кандидат чата Svelte

Это перенос части интерфейса, не публичный релиз и не обновление установленного
770. [Архитектура, запуск и остаток переноса](../modules/svelte-desktop.md).
Рабочая база, индекс и назначения моделей установленного экземпляра не менялись.

## Подтверждено

- Production frontend собирается без ошибок и предупреждений Svelte/TypeScript.
  Приблизительно 151 КБ JS, 11 КБ CSS; Node отсутствует в runtime.
- 20 frontend tests: split UTF-8/SSE/CRLF, final/reset/error, прерывание и отмена,
  draft CAS/поздняя запись/неопределённый commit, XSS и настоящие source_map,
  непотеря следующего вопроса, IME, blocked final, DOM возврат из оригинала.
- `make verify`: 1383 теста собраны. `make test`: 1364 passed, 19 skipped,
  18 subtests, 94,85 с. Пропущенный native gate дополнительно выполнен с
  проверенной библиотекой ядра: 31 passed. Эти результаты пересекаются,
  складывать их в общее число независимых тестов нельзя.
- Отдельная почтовая регрессия: `make test-mail`, 66 passed.
- Desktop Rust: 2 tests passed; release exe собран. Проверены допустимые
  адреса обоих renderer и отказ ошибочного `--state` без fallback на рабочую базу.
- Нативный кандидат в отдельном состоянии загрузил `/app/`; реальный WebView
  запросил конфигурацию, модель, наборы, сессию, историю и черновик — HTTP 200.
  Это подтверждает запуск/контракт, а не визуальную геометрию.
- Через API этого кандидата: настоящее read-вложение с кириллицей и пробелами,
  запись/чтение черновика, конфликт 409, правильный маршрут истории, CSP,
  отсутствие неявного назначения модели. После аварийного завершения только
  этого exe его дочерние службы остановились. Повторный запуск с новым
  instance_id/портом сохранил текст, emoji и идентичность вложения.
- Runtime assets включают лицензии и SHA receipt. Stale source, изменённый JS,
  лишний файл и выход за dist отвергаются тестами упаковки.
- `public-check` и `git diff --check` пройдены. Публикации не было.

## Ограничения приёмки

Computer Use не выполнялся: прежний запрет в LIGHT_PRODUCT_CONTRACT сохраняется,
запрошено разрешение на отдельное тестовое окно. Нет новых скриншотов, замеров
геометрии/масштаба и проверки реальных кликов WebView2. DOM подтверждает логику
возврата, но не заменяет эти действия. Экранный диктор и полный WCAG не приняты.

Проверка не использовала большие модели и не измеряла качество RAG. Отсутствие
модели в тестовом экземпляре сохранено намеренно, назначение не подменялось.
Ограничения Qwen/инструментальных подтверждений из build 770 остаются открытыми.

Autosave задерживается на 400 мс. Полная защита последних нажатий при закрытии
WebView требует отдельного протокола. Проверенный аварийный рестарт восстанавливал
уже подтверждённый сервером черновик, не последние неподтверждённые нажатия.

NiceGUI сохранён для остальных экранов, launcher ждёт обе службы. Снижение общей
памяти и времени холодного запуска этим этапом не достигнуто. Полный установщик,
обновление рабочего окна и удаление NiceGUI из зависимостей не выполнялись.

Audit npm: у production dependencies известных уязвимостей нет; DOMPurify
обновлён до 3.4.17. В build-only цепочке vite-plugin-svelte → deepmerge остаются
два low advisory без опубликованного исправления. Этот модуль не входит в
поставляемый bundle; внешняя конфигурация сборки не принимается.
