# Семантическая проверка RAG — build 759

Дата: 2026-10-10. Отдельный искусственный корпус, 22 коротких документа,
20 заранее размеченных вопросов: по четыре на действующие редакции, исключения,
противоречия, отсутствие ответа и точные факты. Пользовательские документы,
промпты, история и журналы не использовались.

## Что именно выполнено

Реальная Ollama: `qwen3-embedding:0.6b` (1024 измерения), `qwen3:8b`;
температура 0, thinking выключен, контекст 8192, максимум ответа 350 токенов.
Свой нативный Qdrant 1.19.1 и временное состояние. Использованы производственные
`QdrantRetrieval.retrieve_native_hybrid`, точные BM25 postings, RRF,
`ChatSectionReader` и evidence packet. Модели были установлены заранее;
назначения моделей приложения не менялись. После запросов тестовые модели
выгружались через `keep_alive: 0`.

Это изолированный опыт над retrieval/evidence и отдельным коротким промптом
ответа, **не полный пользовательский чат**: роли приложения, маршрутизация
агента, reranker, UI, ingestion, OCR, таблицы и memory в этот прогон не входят.
Проверка установленного конвейера описана отдельно в
[аудите надёжности](rag-reliability-759.md).

[Корпус и разметка](../../tests/fixtures/rag/semantic-v1.json) зафиксированы до
запуска. [Результаты с ответами и видимыми цитатами](semantic-759-results.json)
проверены вручную против этой разметки. Это авторская разметка, а не независимый
экспертный аудит. Веса/промпт/ранжирование по результатам не подгонялись.

| Метрика | Результат |
|---|---|
| Recall@5 по 16 вопросам с доказательствами | 1.000 |
| nDCG@5, бинарная релевантность документов | 0.969 |
| Ответ соответствует разметке | 18 из 20 |

| Отказ от выдуманного ответа | 4 из 4 |

В nDCG повтор одного документа не получает дополнительного зачёта. Вопросы
без ответа исключены из Recall/nDCG, а не засчитаны как успешный поиск.

Для даты запуска и телефона поддержки оба конфликтующих документа попали
в модельный контекст, но модель выбрала один вариант без основания. Для бюджета
и вместимости она честно показала противоречие. В вопросе об имени директора
ответ «Ответа нет» верный, однако ссылка на фрагмент не доказывает отсутствие
имени во всём корпусе. Существующая цитата не равна доказанному утверждению.

## Воспроизведение

В установленном локальном Ollama должны уже существовать явно указанные модели.
Выходной каталог должен быть новым, вне пользовательского состояния:

```sh
uv run python tools/evaluate_light_semantics.py \
  --fixture tests/fixtures/rag/semantic-v1.json \
  --output /tmp/les-semantic-trial \
  --qdrant-exe native/qdrant/qdrant \
  --ollama-url http://127.0.0.1:11434 \
  --embedding-model qwen3-embedding:0.6b \
  --chat-model qwen3:8b
```

Скрипт не читает настройки/историю приложения, не скачивает модели и не меняет
их роли. Это явный диагностический запуск моделей; его не следует запускать
одновременно с пользовательской генерацией на том же сервере.

## Ограничения и следующий gate

Маленький синтетический корпус проверяет конкретные трудные ситуации;
его 90% ответов и высокий Recall не означают 90% качества на реальных документах.
Открытым остаётся минимум 100 отдельно размеченных вопросов, более длинные
источники, несколько фрагментов раздела, OCR, таблицы, сквозной штатный чат и
проверка другим экспертом. Противоречия нельзя «исправить» предметным выбором
версии в коде: решение и объяснение остаются обязанностью модели.
