# Приёмка контекста чата 834

Кандидат исходников, без переключения установленного приложения и рабочих
моделей/индекса. Новый владелец не вызывает модели: это проверка сборки контекста,
не измерение качества ответов Qwen.

В частном стенде прежние реализации из зафиксированного build 833 сравнены с
новым Rust-владельцем на 180 случаях. Сообщения, полный packet и подготовленный
trace совпали, включая переполнение обязательного контекста, большие источники,
покрытие разделов, память, диалог и native tool call/result. Проверены Unicode,
границы строк и прежнее написание JSON float: аудит не хеширует другой текст.
Старая реализация в продукте не сохраняется как fallback.

Целевые регрессии: 132 passed. После удаления неиспользуемого Python-модуля
покрытия дополнительно прошли 14 проверок через прямой ABI. Сохранён прежний
сериализованный формат ContextObject без нового служебного поля. Ещё 29 проверок
включают 250 случайных сценариев прежнего packer и равенство обоих порядков
сообщений/полных объектов/cursor. Ожидания не ослаблены.
В тестах сохранены большой документ, обязательная пара tool call/result,
переполнение контекста, профили, память, PDF, таблицы и native API context report.

На частной копии реального PDF Rust прочитал страницы 1/2 через 13 продолжений
курсора с проверкой SHA. Новый Rust-контекст сохранил точный текст обеих страниц,
их номера, dataset/document ID и источник; SHA текста совпал с аудитом. Исходный
файл не изменился. Python-сервера приложения не было. Подтверждение передачи
в этом стенде моделировалось отдельным действием, генеративная модель не вызывалась.

Rust core/API: 69/10; `make verify`: 1993 collected;
`make test`: 1991 passed, 2 skipped, 18 subtests, 460,63 с.
Форматирование, аудит приватных данных и проверка публикации прошли.
Полная модельная генерация и установленный пользовательский путь не заявляются
выполненными этим тестом. Оставшиеся границы описаны в договоре модуля.
