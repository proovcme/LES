# 782 — установленный локальный патч harness/RAG

781 установлен с согласия пользователя. Модель/файловые операции доступны,
но реальный chat smoke выявил старую ошибку startup orchestration: неудачная
автоиндексация оставалась PARSING и блокировала чат. Фактическая причина отказа
поискового подключения — CAPABILITY_SNAPSHOT_STALE для уже назначенной BGE-M3.
Другая модель не назначается.

Исправление установлено после разрешённого перезапуска. Рабочее окно открыто;
стандартный ярлык запускает Rust runtime/API и Svelte. Состав нативного ядра
[780](native-rag-harness-780.md)/[781](native-harness-loop-781.md) сохранён.
[Контракт исправления](../modules/auto-parse-resume.md).

## Проверки и установка

- make verify: 1536 collected; make test: 1534 passed, 2 skipped, 18 subtests.
  Отдельный почтовый набор: 66 passed. Rust core предыдущего этапа: 28 passed;
  Rust-код в 782 не менялся. Новых зависимостей нет.
  После итогового отчёта: 27 проверок документации/версий/карты/руководства,
  договор ссылок и whitespace-проверка прошли.
- Шесть новых регрессионных случаев: preflight без ложного job, завершение ошибки,
  отмена, конкурентный scheduler, понятное устаревание проверки модели и отсутствие
  утечки внутренних ошибок. Старый строковый HTTP detail сохранён.
- Патч 781 заменил 14 файлов. Поверх него 782 заменил шесть файлов;
  before/after SHA-256 и пробный откат проверены. Бинарные файлы ядра совпадают
  с принятым кандидатом 781; квитанции API/runtime соответствуют 782.
  Резервные копии программных файлов и состояния сохранены локально.
- После готовности служб выдержан запуск автоочереди; чат реально ответил через
  назначенную Qwen3.5:9b. Нативные чтение/экспорт/удаление/восстановление рабочего
  файла сохранили точные UTF-8+BOM+CRLF байты. Самовольных записей USER/MEMORY нет.
- Назначения моделей и конфигурация сохранены. Обновлена только проверка
  возможностей уже назначенных Qwen и BGE-M3; альтернативные модели не назначались.

## Поиск и реальный ответ

В установленной программе запрос без реранкера вернул пять допустимых доказательств
с контекстом; trace подтвердил bm25_postings и local_rrf. Основной чат Qwen
ответил на контрольный вопрос по строке существующего Excel точным значением;
модель увидела пять источников из 34 найденных. Полный запрос занял 31,7 с,
из них генерация 23,1 с. Это единичный smoke, не статистика задержек или Recall@k.

В отдельной браузерной вкладке пройден путь ответ → карточка первого источника →
оригинал Excel → нужный лист → сверка строки → возврат к прежнему ответу.
Вкладка закрыта, рабочее окно не перенаправлялось. Отдельный дефект остаётся:
модель вывела «Источник 1» без открывающей скобки; карточка работает, но inline
ссылка и cited=0 не подтверждают корректного оформления цитаты. Не объявляем
всю цепочку доказательств или качество RAG полностью принятыми.

## Состояние корпуса и остаток

Все 337 зарегистрированных исходных документов сохранены. Обнаружены 13 старых
INDEXED-записей без фрагментов; отсутствие точек проверено через штатный API.
Только они возвращены в очередь существующим владельцем MetaDB для реальной
обработки, без смены подписей или изменения оригиналов. После завершения очереди:
229 INDEXED, 21 446 фрагментов, 108 ERROR, PENDING=0, INDEXED с нулём фрагментов=0.
Ошибки: PARSE_FAILED — 105, WORKER_EXITED — 2, FORMAT_READ_FAILED — 1.
Большинство отказов: документ не дал поискового текста. Причины каждого формата
и OCR требуют отдельного исправления; эти документы не объявлены готовыми.

Защита памяти и блокировка локальной генерации во время реальной индексации
сохранены. По завершении очереди допуск чата восстановился. Автопроверка
устаревших возможностей модели и приоритет чата перед фоновой очередью ещё нужны.
Сетевой модельный цикл, streaming, executor/MCP, сводки, дочитывание родителей,
публикация индекса, SQL очереди и парсеры пока Python. Автономные прежние
Python-навыки сохранены. Полного установщика и публикации GitHub этим патчем нет.
Личные пути, исходные строки и подробные журналы проверки оставлены вне репозитория.
