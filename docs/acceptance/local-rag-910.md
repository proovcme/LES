# Проверка ЛЕС 910 на Windows

Сравнение выполнено на отдельных индексах с одинаковыми оригиналами, локальными
Qwen 3.5 9B и BGE-M3, окном 8192 и режимом Hybrid. Восьми вопросам соответствуют
десять подтверждаемых фактов и один случай с отсутствующим показателем. Эталоны
закреплены перед изменениями. Проверка читает фактическое последнее сообщение
модели и квитанцию выбранных фрагментов. Для большого XLSX использована
контрольная книга с физической строкой 602.

## Первый сравнительный прогон

| Сценарий | Дошло 909 → 910 | Использовано 909 → 910 | Лишние цитаты 909 → 910 | Секунды 909 → 910 |
| --- | ---: | ---: | ---: | ---: |
| Три оригинала | 3 → 3 | 3 → 1 | 2 → 2 | 37,82 → 38,75 |
| Две страницы PDF | 2 → 2 | 1 → 2 | 1 → 0 | 12,90 → 13,37 |
| Книга с 601 строкой | 0 → 1 | 0 → 1 | 0 → 0 | 76,45 → 73,18 |
| Отсутствующий показатель | 0 → 0 | 0 → 0 | 16 → 0 | 9,17 → 78,90 |
| Случайный Word | 1 → 1 | 1 → 1 | 0 → 0 | 17,77 → 81,85 |
| Случайная PDF-схема | 0 → 0 | 0 → 0 | 1 → 1 | 78,31 → 78,26 |
| Случайный Excel | 1 → 1 | 1 → 1 | 0 → 0 | 9,40 → 79,00 |
| Случайная PDF-ведомость | 1 → 1 | 1 → 1 | 1 → 1 | 10,01 → 44,43 |

Для отсутствующего показателя указано число ссылок, показанных в ответе.
У 909 большая книга завершилась HTTP 503 с кодом `SOURCE_SECTION_NOT_FOUND`.
В 910 выбрана строка 602 листа «Позиции» с ожидаемым значением и единицей.
Задержка включает допуск холодной или выгруженной модели. Она приведена
отдельно от качества ответов.

Во время испытания приложение 880 не переключалось. Полная проверка
`make verify` остановилась на импорте старого Python API. `make test`
остановилась на отсутствии сборки фронтенда. Эта серия использовала
нативный API и существующие локальные модели. Папка реальных документов
копировалась в изолированное состояние теста.


## Проверки после доработки кандидата

- Семь целевых проверок подготовки Excel прошли. Они покрывают разреженную
  строку 20002, поздний заголовок, сохранение данных перед подробным описанием,
  порог 600/601 и отказ при неверной контрольной сумме Parquet.
- Для обеих книг по HTTP проверены поиск позиции и явный адрес. В четырёх
  вызовах значение и единица совпали, указан физический лист и строка.
  Переход по ссылке вернул исходные XLSX с ожидаемой контрольной суммой.
- На 4201 фрагменте поиск получил позицию 4199. Две последовательные порции
  пункта вернули позиции 4199 и 4200 из одной редакции. В журнале запросов
  к Qdrant для этих проверок нет операций scroll.
- Одиннадцать проверок Rust прошли, включая совпадение адресов до и после
  сокращения оформления и отсутствие цитат при пустом выборе.
- В повторе по трём реальным оригиналам дошли все три факта. Qwen снова
  выбрала один нужный и два лишних фрагмента. Это не проходит условие
  3 из 3 с нулём лишних цитат. Отдельный установочный прогон, восстановление
  из копии 880 и переключение рабочего запуска остались за пределами
  подтверждённой приёмки.
