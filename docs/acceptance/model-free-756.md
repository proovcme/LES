# Build 756 — обозначения, ошибки и нагрузка без модели

Работа выполнена без обращений к генеративным моделям. Нагрузочный стенд использует
вымышленные тексты, отдельный нативный Qdrant и двумерные фиктивные dense-векторы.
Сравнение поиска использует ранее сохранённые эмбеддинги вопросов и документов.
Настройки моделей и основной пользовательский корпус не менялись.

## Исправления

- Короткие обозначения больше не исчезают из BM25 при наличии обычного текста.
  Веса документов и запросы используют `les.lexical.v2`; старый индекс мигрирует
  один раз под журналом. ID, payload, dense-векторы и ссылки не меняются.
- Короткие запросы поддержаны и в SQLite FTS. Регрессии проверяют `PE`, `N`,
  `ОВ`, `ВК`, числа, `BB_63`, `ЩР/2`, регистр, Unicode и фильтрацию датасета.
- Режим отката TF сохраняет прежний словарь v1. Проверяется настоящий старый
  контракт, миграция, повторное чтение без записи и обратный переход.
- Общие правила словаря вынесены из сервиса FTS в отдельный небольшой модуль.
- Ошибка чата видна рядом с полем ввода. «Показать ошибку» прокручивает к карточке
  и передаёт ей клавиатурный фокус. Сам отказ не уводит пользователя из истории.
  Боковая панель источников при обычном отказе больше не открывается.

## Поиск на прежних контрольных вопросах

40 вопросов по двум документам; у 32 размечены группы доказательств. Остальные
8 не оцениваются как успешные отказы: генеративная модель не вызывается.
Это регрессионный набор, а не независимые 100 случаев.

| Средняя полнота групп | BM25 755 | BM25 756 |
| --- | ---: | ---: |
| @5 | 90,63% | 93,75% |
| @10 | 100% | 100% |

Использован рабочий иерархический маршрут с выключенным реранкером. Проверены
тексты, страницы, ID и область каждого попадания. Смысловая правильность ответа
и качество распознавания документов этим результатом не оцениваются.

## Нагрузка

| Синтетический корпус | Первая миграция | После добавления одного фрагмента | Обычный запрос, медиана / p95 |
| --- | ---: | ---: | ---: |
| 10 000 фрагментов | 5,21 с | 5,22 с | 60,4 / 66,4 мс |
| 100 000 фрагментов | 80,44 с | 79,30 с | 70,3 / 103,3 мс |

Средняя длина — 68 термов. По 30 коротких запросов на размер; измерение включает
проверку актуальности контракта и запрос sparse, без эмбеддера, реранкера и модели.
На выборочных точках сверены payload и dense-векторы. Это единичные замеры на
рабочей Windows, не изолированный сравнительный benchmark аппаратуры.

Стенд: `tools/benchmark_sparse_index.py --qdrant PATH --output NEW_DIRECTORY
--sizes 10000 100000`. Он создаёт только свою коллекцию в новом каталоге,
сохраняет JSON результатов и останавливает свой сервер. Модели не скачиваются.

Дополнительный опыт пакетной записи статистики дал 84,54 / 87,75 с на 100 тысячах;
ускорение не подтверждено, эта оптимизация не включена. Масштабная миграция и
обновление индекса остаются узким местом: нужно готовить новую версию заранее,
а не заставлять первый вопрос ждать полного пересчёта.

## Интерфейс

На отдельном демонстрационном профиле без назначенной модели проверены понятный
отказ, сохранение вопроса, отсутствие автоматически открываемой боковой панели,
видимое уведомление и переход к ошибке. В браузере проверены 1280×720 и 390×844;
на узком экране горизонтального переполнения нет, фокус получает карточка ошибки.
Нативное окно и экранный диктор отдельно не проверялись; WCAG полностью не заявляется.

## Проверки и установка

- `make verify`: пройден, 1173 теста собраны.
- `make test`: 1173 passed, 18 subtests, 25 предупреждений, 107,75 с.
  Нативный тест Qdrant выполнен с `LES_TEST_NATIVE_QDRANT`, без его пропуска.
- Контракт документации, карта кода, public-check и проверка пробелов пройдены.
- Восемь файлов локального runtime обновлены после проверки кандидата; исходные
  файлы сохранены для отката, установленные SHA-256 совпали с кандидатом.
- Встроенный Python установленного приложения проверил три точных коротких
  запроса через настоящий Qdrant, повторный поиск, TF-откат и обратную миграцию.
- Браузер установленного runtime: отказ без модели → сохранённый вопрос →
  Enter на «Показать ошибку» → фокус карточки → новый чат без старого уведомления.
  На этом профиле отсутствуют назначения моделей; в журнале запуска нет вызовов
  генеративного endpoint. Пользовательское окно не перезапускалось.

Исходники и локальный патч — 756. Для уже открытого приложения нужен обычный
перезапуск; первый поиск переведёт старый BM25-словарь в v2. Полный установщик
и публичный релиз остались 743. Экспериментальные таблицы в локальный патч не включены.
