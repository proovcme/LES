# Кандидат 818: реестр моделей, история и доверенные сети

Статус: исходники и изолированные Windows-процессы. Рабочая установка не
перезапускалась, её назначения моделей и индекс не менялись. Полный установщик,
публичный релиз и пользовательский путь установленной версии не проверены.

## Выполнено

- Rust владеет всеми SQL-операциями реестра моделей, CAS и аудитом. Прежняя
  реализация SQL удалена из Python-класса; сохранён типизированный фасад.
- Пять дополнительных HTTP-пар обслуживаются без передачи запроса Python.
- SQL списков диалогов и обратной связи удалён из Python-роутера. Ошибка
  чтения выдаётся явно, не подменяется успешным пустым списком.
- Политика доступа может загружаться из явно заданного ограниченного файла
  до первого запроса, без Python bootstrap.
- Общие проверки доверенных сетей и forwarding-заголовков вычисляет Rust.

## Изолированные сценарии

1. Восемь одновременных изменений одной ревизии: одна новая ревизия, семь
   конфликтов; восемь назначений роли: одно назначение, семь конфликтов.
2. SQL-триггер отклоняет запись аудита: голова и история ревизий не меняются.
3. Принудительное завершение отдельного процесса во время серии изменений:
   после открытия целостный SQLite, нет пропущенного аудита и сиротских ревизий.
4. Повторное открытие сохраняет отключённую голову, закреплённую старую
   ревизию роли и неизменяемый снимок возможностей.
5. Остановка тестового Python backend после загрузки политики: карточки
   моделей, шаблоны и все три маршрута истории продолжают работать.
6. Холодный запуск только `les-api.exe`, без Python-сервера: проверка ключей,
   отказ пользователю в административном действии, создание разговора и
   чтение истории. После принудительного завершения и повторного запуска
   сообщения и причина `PDF_PAGE_INCOMPLETE` равны прежним.
7. Повреждённая, слишком большая или несовместимая политика: отказ запуска
   до создания базы. Скрытый внутренний маршрут политики недоступен снаружи.
8. Более тысячи сравнений IPv4/IPv6 и масок с прежним контрактом stdlib;
   forwarding-заголовок от постороннего peer не даёт доверенную роль.
9. В браузере на отдельном Rust API с копией тестовой базы: восстановлена
   причина `PDF_REVISION_CHANGED`, открыто и закрыто окно «Диалоги», сообщение
   осталось. На этом UI-стенде непренесённые запросы обслуживал отдельный
   прежний backend; это не доказательство самостоятельности всего интерфейса.
   Скриншот сохранён локально вне публичного репозитория.

Точечный набор: 82 проверки пройдены. `make verify`: 1683 теста собраны,
синтаксис, карта исполнения, версии и прежний OpenAPI-контракт проверены.
`make test`: 1668 passed, 15 skipped, 18 subtests passed. Rust: 40 тестов ядра
и 2 теста API пройдены. Новых зависимостей не добавлено. Непроверенные
сценарии пропущенных тестов не объявляются исправленными; этот документ
не означает установленную приёмку.

## Границы

Контроль холодного старта относится к перенесённым маршрутам с явно заданной
политикой. Обычный runtime всё ещё запускает Python и не формирует её файл.
Неперенесённый маршрут при отключённом backend возвращает 503. Полный чат
Qwen, OCR, classic и совместимость всех старых навыков этим набором не доказаны.
Новый тест не заменяет прежние испытания Edge/Qwen и не закрывает открытый
дефект привязки цитаты из [817](pdf-cursors-history-817.md).

Общий размер Python-репозитория включает тесты и инструменты и не является
процентом завершённости переноса. Актуальная достижимость:
[генерируемая карта](../CODE_RUNTIME_MAP.md). Полностью убрать общий runtime
пока нельзя: [договор и остаток](../modules/python-exit.md).
