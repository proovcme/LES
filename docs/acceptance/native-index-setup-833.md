# Приёмка первого нативного индекса 833

Отдельный кандидат; рабочие модели/индекс/приложение не переключаются.
HTTP-исключения проверяет реальный Rust API без приложения Python. Подменяются
только контролируемые ответы внешних сервисов, не решения контроллера.

Проверяются точный count при ложном/неизвестном summary, недоступность сервиса,
существующие точки без fingerprint, явное принятие/замена пустого legacy-layout,
writer busy, повреждённый контракт, отсутствие/смена роли, размерность и Unicode.
Для Server процесс останавливается после создания коллекции, до ответа PUT:
сохранённый план продолжает работу без принятия постороннего индекса и без
повторного модельного запроса. Отдельно проверяется восстановление native Edge.

Полный intake проверяется на Server и Edge, на подготовленном и новом хранилище.
Новый путь не получает готового контракта/лексических таблиц. PDF сохраняет две
физические страницы и source_ref, повтор после аварии завершает только оставшееся.
Отдельная миграция FTS сохраняет старый текст и восстанавливает поиск по нему.

На частной копии реальных XLS и PDF получены 2 документа, 35 фрагментов,
35 лексических строк и страницы 1/2 со ссылками. До старта не было Edge, контракта
и лексических таблиц. Python-сервер отсутствовал; хеши источников совпали.
Повтор на окончательном кандидате: 53,363 с, включая запуск API, контрольный
вектор и полную индексацию. Это один прогон, а не статистический benchmark.
Модель после проверки размерности остаётся прогретой до конца непрерывной партии;
завершение или ошибка освобождает worker. Защита RAM не ослаблена.

Целевые проверки: 70 passed, включая остановку нового Edge после публикации
контракта до финального commit каталога. Повтор продолжает тот же план, без
повторной пробы модели. Настоящий QdrantClient читает конфигурацию нового Edge;
SDK-поле memory преобразуется в совместимый on_disk. Проверены запрет перезаписи
контракта, отказ при изменённом fingerprint и миграция FTS без потери текста.
Rust core/API/runtime: 69/10/7; vector: 1 unit + 2 integration.
`make verify`: 1987 collected; `make test`: 1985 passed, 2 skipped,
18 subtests, 492,05 с. Автономный комплект внешних навыков проверяется отдельно
от приложения: без app imports, с отказом от fallback при повреждении комплекта.
Проверки форматирования, приватных данных и публикации прошли.

Падение на каждом отдельном syscall самой ранней инициализации Edge ещё не
инъецировалось. Эти результаты не доказывают исчерпывающее покрытие всех окон сбоя.
Это выборка из подключённого корпуса, не приёмка всего большого датасета и не
доказательство качества генеративных ответов. Установленная версия не менялась.
