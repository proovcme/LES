# Docling Word и Xberg PDF: кандидат 872

Проверка выполняется на существующей отдельной копии каталога и Edge.
Рабочая установка, её индекс и назначения моделей не переключаются.
Новые обработчики и оба этапа нарезки выполняются в Rust. Python в стенде
используется для управления проверками и независимой сверки, не для обработки
документов приложением.

## Граница проверки

Опубликованы 19 оригиналов из двух пользовательских наборов: 11 DOCX, один DOC
и семь PDF. В выборку входят источники прежних контрольных вопросов, два
тяжёлых Word, PDF с OCR и дополнительно два PDF с 47 таблицами.
Это сквозная проверка выбранных файлов, не повтор всех 638 оригиналов через
новый конвейер. [Стенд 871](native-parser-comparison-871.md) остаётся отдельным
сравнением извлечения; его результаты не подменяют эту приёмку.

[Договор компонентов](../modules/native-document-parsers.md): Docling.rs
владеет обычной структурой Word; прежние нативные обработчики LES сохраняют
рисунки, OMML/MTEF, OLE, OCR и оригиналы. Xberg возвращает PDF-таблицы;
PDFium сохраняет физическую страницу и идентичность цитаты. Excel остаётся
на Calamine с различением сохранённых значений и отсутствующего кеша формул.

## Найденные причины и исправления

- Docling 2.82.1 применяет к внешней ячейке `gridSpan/vMerge` из вложенной
  таблицы. В производном OOXML значения по умолчанию сделаны явными;
  оригинал не меняется. Повторы вставки допускаются только по геометрии
  одной логической ячейки. Необоснованный дубль или потеря дают отказ.
- Результаты OCR и формул возвращаются внутрь исходной ячейки с
  экранированием строк и разделителей. Они не создают новые колонки или строки.
- PDFium отдаёт служебный символ переноса, Xberg — дефис; границы слов также
  могут отличаться. Исходный дефис восстанавливается только по флагу PDFium;
  алфавитное разбиение сверяется без пробелов. Числовые атомы остаются точными:
  другое число на той же странице не подтверждает требуемое.
- В реальном чате оборванная строка `|` вызывала панику проверки заголовка.
  Оба табличных прохода используют безопасное отделение границ; проверены
  все Unicode-префиксы контрольной таблицы.
- Старый порог минимальной длины удалял короткие разделы, заголовки и обычный
  абзац из 99 символов. Проверенные source-nodes и финальный бюджет сохраняют
  содержимое и границы разделов, включая короткие формулы и хвост разбиения.
  На двух этапах восстановлены все 13 ранее пропадавших контрольных фрагментов
  четырёх реальных Word. Пустая табличная разметка узлов не создаёт.

## Доказательства сохранности

У 11 Word сверены оригиналы, manifests и все 924 сохранённые части по SHA-256.
362 части проходили OCR. Это проверка сохранности и использования OCR,
а не оценка точности распознавания всех рисунков.

После повторной публикации в индексе найдены все 15 451 контрольное окно
из 11 исходных Word. Сверка использует нормализованное алфавитно-цифровое
представление текстовых участков; она обнаруживает пропуски, но не заменяет
контроли точного написания чисел, формул и знаков.

Для реального PDF проверена физическая страница 5 из 11: 2059 символов
прочитаны девятью порциями по 240 символов; их объединение совпало с полным
чтением страницы. Идентификатор документа, хеш и номер страницы сохранены;
холодное чтение выделяет одну страницу, а не разбирает весь PDF повторно.

Пустые Word и PDF прошли настоящий путь публикации на финальном кандидате:
оба получили `ERROR / NO_SEARCHABLE_TEXT`, ноль фрагментов и отсутствие
lexical-записей. Пустых `INDEXED` нет.

## Состояние приёмки

Целевой прогон: **41 проверка без пропусков**; Rust — **122 проверки ядра
и 73 API**. Финальные `make verify` и `make test` прошли: **2205 тестов,
два пропуска**, 18 дополнительных проверок subtests. Числа относятся к
финальному варианту после исправления потерь короткого текста.

Qwen3.5:9b выполнила все **39 запросов** по двум наборам без выбранного файла,
включая четыре обзорных вопроса, 15 дополнительных и 20 регрессионных.
Обрывов прежнего типа нет. 38 запросов завершились HTTP 200; один остановлен
как `TABLE_VALUE_INVALID`, причина сохранена в истории, ответ не подставлен.
Из ответов: 30 имеют статус проверки исходных строк, восемь — недостаточности
доказательств. Среди последних есть намеренные вопросы без ответа в корпусе;
этот счётчик не является числом ошибок поиска. HTTP-статус и проверка строк
не дают оценки фактической правильности в процентах.

Проверены **257 ссылок**, 95 уникальных оригиналов и 118 PDF-локаторов:
соответствие каталогу, SHA-256 исходных файлов, привязка URL к редакции,
открытие ссылки и границы физической страницы — без расхождений.

В двух дополнительных запросах Qwen прямо просили прочитать физический PDF
без ручного выбора файла. Reader не вызван в обоих случаях; использованы
индексированные источники. Связь намерения пользователя с вызовом
физического reader **не принята**. Прямое чтение страницы через Rust API
проверено отдельно выше.

## Ограничения

Обзорная справка не становится принятой только потому, что возвращены строки
источника и прошла проверка ссылок. Полноценный синтез, выбор стадии/редакции
и достаточность найденных материалов остаются отдельными задачами RAG.
Все четыре обзорных задания остаются непринятыми: два вернули недостаточность
доказательств, два — подборку исходных строк вместо запрошенной связной справки.

Один из дополнительных PDF имеет неверное буквенное отображение шрифта
без ошибки Unicode-map со стороны PDFium. Совпадение двух извлечений не
доказывает читаемость такого текста. Автоматическое угадывание кодировки не
добавлено; качество OCR/чтения подобных источников не объявляется принятым.

Публичный установщик, обновление рабочего экземпляра и installed journey
в эту проверку не входят. Частные debug assets отклоняются упаковщиком;
для выпуска нужны сборка с проверенной квитанцией и отдельная приёмка установки.
