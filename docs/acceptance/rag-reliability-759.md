`214e4444bf914ca0ede4a1c3fb7dbf0ade4166f0`. Mac preview 758 и исправления

Пользовательские журналы, историю, промпты и документы не читали.

## Архитектурная оценка

Сильные стороны: явные роли моделей, контракт пространства эмбеддингов,
сохранение предыдущего индекса до успешной подготовки замены, durable commit
журнал, транзакционный BM25, проверки поколения при дочитывании источников.
Память — совет модели, не самостоятельное доказательство. Проверка цитат
проверяет существование ссылок, а не истинность выводов модели.

Основной долг: координаторы чата и поиска остаются большими; первоначально
чат и API имели разные механизмы контекста. Состояние распределено между
MetaDB, Qdrant, FTS, BM25 и журналом. Это требует общего владельца поколения,
проверок сбоев и отказа от неявных записей в обход журнала. Статистика архитектуры
из карты кода не является мерой качества продукта.

считается чужим listener. При реально занятом порте выбор нового сохраняется.

## Проверки

Регрессии используют только временные каталоги, искусственные документы и
собственные процессы. Они проверяют изменённый исходник, lease во время
эмбеддингов, stale hit того же ordinal, пустой lexical query, качество выдачи,
Host/Origin, аварийное завершение и TCP TIME_WAIT.

Установлен отдельный macOS-кандидат. Холодный запуск, загрузка искусственного
документа, INDEXED, реальный нативный Qdrant, BM25/FTS/dense API, проверенный
контекст и byte-exact original выполнены. Embedding endpoint в этом опыте —
синтетический HTTP fixture; генеративную модель не запускали. Это проверка
целостности конвейера, не измерение семантического качества.

`make verify` прошёл; `make test`: 1153 passed, 56 skipped, 18 subtests passed.
`uv lock --check`, `git diff --check` и public-check прошли.
В installed recovery API и UI сохранили адреса после остановки API;
SIGKILL launcher завершил все 7 собственных процессов. Финальный установленный
модуль также отверг stale hit и подтвердил бюджет целых фрагментов контекста.
Локальные доказательства находятся в игнорируемом `artifacts/` вне репозитория.

Семантический пилот: [20 размеченных вопросов и реальные модели](semantic-759.md).
Его результаты не заменяют установленную приёмку или полноценный benchmark.

## Что остаётся открытым

- Независимый размеченный набор минимум 100 вопросов: точные ответы, исключения,
  противоречия, устаревшие версии, отсутствие ответа, несколько документов,
  OCR и таблицы. Измерять Recall/nDCG, точность утверждений и цитат отдельно.
- Назначение другой embedding-модели не мигрирует готовый индекс. Нужен явный
  сценарий создания нового индекса/переиндексации; скрытый fallback запрещён.
- Постепенное разделение больших координаторов по контрактам, без переписывания
  профессиональных решений модели в коде.
- Произвольное изменение Qdrant в обход журнала, смена весов за тем же model ID
  и отказ диска требуют отдельной приёмки.
- Чистый Mac, Finder/Gatekeeper, подписанный автономный пакет, Intel,
  пользовательский корпус и Windows installed regression этим опытом не доказаны.
