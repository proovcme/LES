# Кандидат 815 — PDF, источники и испытание Edge

Проверка выполнена 7 ноября 2026 года на отдельном восстановленном снимке
индекса LES. Из него перенесены 19 245 настоящих точек с dense-векторами и
payload. Контрольный PDF содержит 45 страниц, 339 точек и 220 текстовых
доказательных фрагментов. Все 220 фрагментов сверены с исходными страницами
после удаления служебного заголовка страницы и нормализации пробелов.

Для второй редакции копии PDF добавлен пустой первый лист. Контрольная
цитата переместилась с физической страницы 5 на страницу 6.

| Сценарий | Видимая страница после завершения или восстановления |
| --- | --- |
| Чтение одновременно с записью редакции | 6, начатое чтение закончило работу со страницей 5 |
| Остановка Edge после поиска | 5 |
| Остановка Edge после чтения PDF | 5 |
| Остановка после публикации указателя | 6 |

Во время контрольного читающего запроса писатель во всех сценариях
продвинулся с первой до 43-й порции. Для воспроизводимости между порциями
из восьми точек добавлена задержка 50 мс. Смена видимой редакции ждала
освобождения читающего запроса. В прерванных запросах итоговая цитата
не выдавалась. После восстановления повторное чтение возвращало целую
редакцию. Ссылка с прежним хешем после публикации отклонена с HTTP 409.

## Изменение исходников

`source_map_for_context` теперь сохраняет известный `source_sha256` обычного
PDF и формирует локатор. Панель источника использует его при запросе
оригинала. Раньше сборщик создавал локатор только для специальных режимов
чтения таблиц и Word, из-за чего известная редакция PDF терялась.

Добавлена регрессия сохранения страницы и хеша. Тест также проверяет, что
отсутствующий хеш не присваивается фрагменту. В существующем тесте
семантической выборки явно указана UTF-8 для чтения JSON на Windows.

## Границы испытания

Использованы действующие сервисы LES для hybrid-поиска, SQLite BM25, RRF,
дочитывания родителей и соседних страниц, чтения оригинала PDF, списка
источников, обработки меток цитат и маршрутов просмотра.

Edge подключён экспериментальным Rust-транспортом. Указатель SQLite,
читающая блокировка и фильтр активного поколения реализованы в стенде.
BM25 подготовлен в двух неизменяемых базах. Предыдущие поколения точек
сохраняются, производственная очистка не реализована этим испытанием.

Поисковый зонд использовал сохранённый вектор фрагмента и его полный
текст. Ответ формировался извлечённой цитатой. Качество новых эмбеддингов,
генерация Qwen и установленное окно в этот прогон не входят. HTML
просмотрщика, номер страницы, PNG и байты PDF проверены через ASGI.
Переход в SourcePanel проверен с идентификатором фрагмента и разрешением
документа по датасету и имени.

Рабочая установка не переключалась на Edge. Кандидат 815 проверен
в исходниках и отдельном контуре. Публичного выпуска этим шагом нет.

## Проверки исходников

`make verify` завершился успешно. `make test` завершился с 1618 пройденными
проверками, 39 пропусками и 18 успешными subtests. Тринадцать целевых проверок
источников и семантической выборки также прошли. Пропущенные сценарии
не входят в подтверждённое покрытие.
