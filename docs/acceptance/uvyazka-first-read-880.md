# Кандидат 880: первичное чтение через Увязку

Форма и MCP получили `sources` / `read_import`. Выбор проекта читает только
каталог. Нужен отдельный клик для чтения оригинала и подготовки снимка.
Разрешены только зарегистрированные project_id/doc_id; произвольный путь
не передаётся. Известный SHA выбранной редакции сверяется с результатом.
Чтение создаёт производный кеш Увязки, после чего полный снимок поступает
в прежнюю очередь LES. Постановка не называется готовностью поиска.

Проверены: список/недоступные читатели/продолжение, локальное рукопожатие
без раскрытия токена, правильная идентичность и отказ при смене редакции,
явный клик и повтор того же запроса после тайм-аута, синтетический DXF через
настоящие API и читатель Увязки.

## Фактический прогон

В отдельном временном проекте создан синтетический DXF. Перед вызовом список
снимков был пуст. Настоящий `les-runtime --cli mcp` инициализировал протокол,
проверил владение тестовым API и вызвал `uvyazka_integration/read_import`.
Увязка прочитала зарегистрированный оригинал через ezdxf; Rust-адаптер получил
полный снимок и поставил его в обычную очередь. Повтор того же действия через
API формы вернул прежнее intake_job_id, без второго задания.

До специального изменения оригинал сохранил SHA-256. После изменения старый
снимок и ссылка во вьювер были заблокированы. После остановки тестового сервиса
получен отказ доступности. Временные процессы/проект закрыты; рабочая пара не
трогалась. Индекс и модель ответов в этом проекте не назначались: это проверка
чтения/обмена/очереди/ссылки, а не качества поиска или генерации.

Настоящий API выявил первоначальную ошибку адаптера: временное подтверждение
подключения ошибочно проверялось как SHA-256. Проверка исправлена на ограниченное
печатное значение заголовка, без присвоения формату чужого сервиса собственной
семантики. Регрессия и реальный первый запуск повторены; токен нигде не выведен.

API/Edge: 101 passed; runtime: 8 passed; frontend: 53 passed, проверка типов и
сборка. `make verify`: 2217 случаев; полный `make test`: 2215 passed, 2 skipped,
18 subtests passed за один непрерывный прогон. Числа описывают только этот набор,
не полноту поддерживаемых форматов. Проверка публичных файлов пройдена.

Рабочая установка и пользовательские проекты не меняются. Это не подтверждение
всех версий DWG/RVT, качества выдачи RAG или установленной подсветки. Сохраняются
лимиты 879 и необходимость совместимого приёмника ссылок во вьювере. Большие
снимки, постоянное хранение подключения, автосинхронизация и installed journey
остаются открытыми. Новых зависимостей и Python-компонентов LES нет.
