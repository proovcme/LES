# Build 753 — схема устройства Леса

На вкладке «Лес знаний» добавлено раскрытие «Как устроен Лес».
Две последовательности: подготовка документов и поиск с ответом.
Схема использует текущую лесную палитру и нативные details/summary;
без зависимостей, сетевых вызовов и анимации. При закрытой схеме
остаётся компактная строка над картой. На узком экране шаги идут вертикально.

Это описание архитектуры, не живой монитор. Не выдаёт модель или индекс
за готовые. Реранкер помечен как отключаемый; в технических подробностях
отделены действующие TF+IDF от испытательного BM25 и полного чтения родителя.
Происхождение цитаты не названо доказательством правильности вывода.
Поиск, назначения моделей и пользовательский индекс не меняются.

## Проверки и установка

- make verify: 1129 тестов собраны; make test: 1129 passed, 18 subtests,
  24 предупреждения. Четыре регрессионных теста forest прошли отдельно.
- Браузер: 1280×900 и 390×844; на узком экране нет горизонтального переполнения.
  Шаги перестраиваются в одну колонку. Исправлен flex-basis строки поиска:
  поле на узком экране занимает отдельную строку.
- Оба раскрытия работают клавишей Enter; скрытое содержимое явно исключено
  из раскладки. Поиск по названию, выбор документа, ссылка на оригинал
  и возврат кнопкой «Назад» в чат проверены на копии состояния.
- Локально установлены только index.html, forest.css и маркер build 753.
  Сохранены исходные файлы для отката и контрольные суммы. Проверка выполнена
  на сервере установленного runtime с отдельным состоянием приёмки.
  Перезапуска пользовательского окна не потребовалось.
- CSS имеет версию в URL, чтобы старый браузерный кэш не скрывал правку.
- Нативный WebView2 и экранный диктор отдельно не проверены;
  полное соответствие WCAG не заявляется.

Исходники — 753. Локальная установка — 753 с прежним поисковым backend:
испытательный RAG 752 не переносился. Полный установщик и публичный выпуск
не обновлены. Снимки и квитанции хранятся в частных материалах приёмки,
поскольку каталог на снимках содержит пользовательские имена документов.
