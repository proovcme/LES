# Кандидат 827: встроенные расчёты и отдельный исполнитель навыков

Состояние: исходники и изолированные компоненты. Рабочая установка и модельные
назначения не заменены. [Расчёты](../modules/native-builtin-calculations.md),
[комплект внешних навыков](../modules/skill-runtime-package.md).

Через реальный C ABI проверены 2200 контрольных расчётов против прежнего
Decimal-контекста с precision=1024 и trap Inexact, большие/малые числа,
взаимное сокращение, пороги отображения, отсутствующий кеш формулы,
пересечения/merged-ячейки, нечисловые значения и повторные координаты.
Большой Unicode-снимок больше 8 МиБ проходит порционный протокол.
Standalone exe прочитал двухлистовую книгу с 70 строками и получил точную
сумму при недоступных Python/PYTHONHOME/PYTHONPATH. Он не запрашивал модель.

Собран изолированный исполнитель с NumPy/OpenPyXL и уже имевшимся в uv.lock
pywin32 311: 8 distributions, без новых загрузок/установок. Подтверждены
явные пути/DLL, отсутствие startup site и импортов приложения. Проверки
включают запуск/продолжение 70 строк, гибель владельца, отсутствие оставшегося
процесса, тайм-аут, отсутствующий interpreter/dependency, запись причины,
отказ изменённому хешу и автоматический выбор отдельного комплекта в launcher.
Повреждённая stdlib останавливает запуск до старта служб. Совместимый API
использует того же Rust-владельца выбора, без второго алгоритма на Python.

После всех запусков повторно проверен полный инвентарь исполнителя:
**4019 файлов, 120 119 556 байт**. Все SHA-256 совпали, неожиданных файлов
и каталогов `__pycache__` нет. Это проверка изолированного компонента,
а не размера полного переходного установщика.

На копии существующей одобренной библиотеки проверен её единственный
разрешённый скрипт: прежний SHA-256, 70 успешных строк, контрольный
десятичный результат. Исходный пользовательский код/разрешение не изменены,
его содержимое и пути не включены в репозиторий или публичный пакет.

На пяти реальных XLSX из корпуса standalone Rust exe вычислил явные
контрольные диапазоны и совпал с Decimal; SHA-256 оригиналов до/после совпал.
Это выборочные расчёты ячеек, без изменения файлов/индекса и без проверки всех
формул/сложных книг. Форматный fallback сложных XLSX ещё остаётся в приложении.
