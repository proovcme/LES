# Кандидат 776 · нативный API и хранение диалогов

Дата: 01.11.2026. Исходники и отдельный Windows-кандидат; установленный 773,
его корпус, подключения и модельные роли не менялись. Полного установщика,
обновления пользовательской установки и публичной публикации нет.

## Что перенесено

- SQLite диалогов/черновиков в `core/src/workspace`, прежние таблицы/файл,
  единственная реализация записи, атомарный compare-and-swap, явные ошибки.
- Шесть method/path пар Rust API. Остальные 259 пар проксируются в существующий
  сервер; авторизация всё ещё require_user. Это не завершённый перенос harness.
- Native runtime владеет Qdrant, Rust API, legacy API и UI. Отказ любого PID
  вызывает ограниченное восстановление; причины и exit code сохраняются.
- Проверяемые сборочные receipts и staging API/runtime; кандидатные workflows
  включают сборку/проверки и native assets. Workflows удалённо не запускались.

## Выполненные проверки

`make verify`: 1459 тестов собрано; версия/карта кода/API baseline проверены.
`make test`: **1457 passed, 2 skipped, 18 subtests passed** (143,20 с).
`make test-mail`: **66 passed**. Rust: core **12**, runtime **3**, API **1**,
Tauri **8** тестов; fmt core/runtime/API и release-сборки прошли.
Два пропуска не объявляются проверенными сценариями.
Собраны notices для 327 Rust-пакетов, включая Axum/rusqlite/SQLite из Cargo.lock.

Существующие проверки хранения выполнялись против прежнего test-only Python
oracle и нового Rust; отдельно проверены byte-preserving reads, rollback
триггера, Unicode/пробелы, временные зоны/микросекунды, scope и отказ отсутствующей
DLL без создания пустой БД. Оракул отсутствует в staged runtime.

Реальный Axum против отдельного upstream: авторизация до открытия БД, Host/Origin,
CORS, конфликт revision, 20 конкурентных записей одного revision (одна принята),
занятая БД без остановки HTTP, SSE с UTF-8 по одному байту до отложенного final,
отмена потока, upload 2 МиБ без изменения хэша, публичный origin и редиректы.

## Отдельное нативное окно Windows

Staged текущий исходный runtime, прежний принятый embedded Python для
совместимости, собственные Qdrant/состояние и новые remapped core/API/runtime/
Tauri binaries. Проверено, что Python импортирует собственный candidate runtime.
Запуск `--svelte --native-api`, api_native=true, api_pid принадлежит les-api.exe,
legacy_api_pid — отдельному Python. Заголовки различают нативные и proxy-маршруты.

Через настоящее поле интерфейса сохранён Unicode-черновик. Принудительно
остановлен только собственный Rust API, затем только собственный legacy API.
После каждой аварии владелец восстановил службы; черновик/revision, проект и
заметка памяти совпали. Предыдущие PID служб завершились. Визуально проверены
восстановленный текст и «Черновик сохранён». Штатная кнопка закрытия завершила
окно, наблюдатель, runtime и все четыре службы; статус stopped подтверждён.
Модели не запускались, документы пользователя не копировались.

## Что остаётся открытым

Авторизация, проекты/память/задания, поиск/BM25/иерархия, чат/harness и большинство
API-реализаций, NiceGUI и форматные адаптеры ещё Python. Calamine/PDFium согласованы,
но не подключены. Полная автономная совместимость всех одобренных Python-навыков
требует отдельного выделенного исполнителя и проверки импортов/поведения;
его нельзя молча ограничить stdlib. Чистая Windows, весь реальный corpus и
модельный end-to-end в этой приёмке не проверялись. Ускорение всего продукта
по данному переносу не измерено и не заявляется.
