# Кандидат 823: цикл основного чата под управлением Rust

Состояние: исходники и отдельный проверочный контур. Рабочая установка не
заменена; полного переноса приложения и публичного релиза ещё нет.

Перенесён [управляющий цикл](../modules/native-chat-loop.md), включая привязку
параметров к scope/provenance, бюджет, повторы, курсор PDF и строгую повторную
попытку только при пустом ответе. Основной чат использует этот владелец вместо
Python `while`/`for` с решениями о следующей итерации.

Проверены через настоящий C ABI:

- дочитывание длинной физической страницы без дополнительного вызова модели;
- сохранение контекста запроса и выполнение IO в исходном event loop;
- отказ при смене редакции до финального ответа;
- исходное исключение с кодом и подробностями без потери причины;
- истечение времени и отмена запроса без новых инструментальных шагов;
- отказ неизвестному нативному инструменту;
- повторное чтение после изменения ревизии и остановка повтора без изменений;
- строгая вторая генерация только после пустого ответа;
- отказ пустому итоговому ответу и вызову инструмента после закрытия бюджета.

Целевой набор чата, физических PDF и старых автономных навыков: **69 passed**.
Расширенный итоговый набор с координатором партии и настоящим нативным
Qdrant: **88 passed**. Предыдущий целевой запуск без переданного Qdrant
пропускал один интеграционный сценарий; в итоговом он выполнен.
Эти модульные результаты не выдаются за installed user journey.

Итоговая заморозка после исправлений конфликта/таймаута:
`make verify` — 1790 collected; `make test` — **1787 passed, 3 skipped**, 18 subtests.
Пропуски: POSIX reuse, macOS supervisor и необязательная offline embedding spec.
Rust core — 63 tests, API с Edge — 10, runtime — 7. public-check и diff-check
проверяются отдельно. Один промежуточный прогон прерван нехваткой места от
тестовых копий; он не учитывается как gate. После обычной очистки своих
промежуточных каталогов итоговый прогон выполнен заново на свежем каталоге.

Повтор с настоящим Ollama обнаружил несовместимость JSON-моста с неизменяемыми
`MappingProxyType` вызовами транспорта. Исправлена сериализация вложенных
Mapping с сохранением ID и аргументов; отдельная регрессия воспроизводит
этот тип. Смешанный список разрешённых и неизвестных нативных инструментов
теперь отвергается до первого эффекта, а не фильтруется до разрешённой части.

Отдельно сохранена прежняя семантика конфликта записи рабочих файлов:
`AGENT_CONFLICT` разрешает модели заново прочитать изменившуюся редакцию.
Иначе новый координатор ошибочно считал такое чтение повтором старого.
Счётчик состояния теперь только в Rust, дублирующий Python-счётчик удалён.

## Настоящий чат с Qwen3.5:9b

Дополнительный итоговый прогон включает и нативный модельный транспорт:
три ответа имеют `x-les-handler: rust.inference`, протокол `les.inference.v1`.
Основной SSE-чат, физическая страница 6 новой редакции и ссылки проверены;
один запрос занял 30,62 с. Интерфейс/API-обвязка чата в этом контуре ещё Python.

Проверены основные HTTP/SSE-маршруты чата на отдельной копии реального PDF и
предыдущем экспериментальном транспорте Edge. Вызовы модели, инструмента и
финальной попытки управляются Rust; физическую страницу читает PDFium в Rust,
запрос кодируется BGE-M3 через Rust ORT. Python HTTP/адаптеры чата ещё работают.

- Поиск → `read_pdf_source` → ответ: **18,86 с** в одном прогретом прогоне.
  Проверены физическая страница 5, ID каталога, SHA и открываемость ссылки;
  имя DWG в ответе действительно присутствует в извлечённом тексте страницы.
- Изменение копии PDF после поиска: `PDF_REVISION_CHANGED`, ноль токенов,
  нет финального ответа. В SQLite сохранены `FAILED` и публичная причина.
- Падение отдельного процесса Edge перед дочитыванием: `SECTION_READ_UNAVAILABLE`,
  ноль токенов, нет финального ответа. Причина сохранена в истории.
- Чтение одновременно с записью новой редакции Edge: ответ и ссылки остаются
  на старой странице 5 с прежним SHA. Следующий запрос после публикации читает
  физическую страницу 6 с SHA новой редакции. Ссылки проверены на оригиналах.

Это не p50/p95, не приёмка полного установщика и не производственный перенос
всего HTTP-чата в Rust. Публикацией поколений и удержанием snapshot в этой
проверке управляет прежний стенд; нативная производственная партия проверена
отдельно в [822](native-index-batch-822.md). Рабочие источники/индекс/назначения
моделей не изменены. Финальное усиление различения собственного TimeoutError
обработчика и истечения бюджета покрыто отдельной ABI-регрессией.

Предварительный запрос несуществующей страницы 9999 не считается пройденной
проверкой отказа инструмента: Qwen не вызвала его и ответила по имеющейся выдаче.
Вывод об отсутствии страницы без физической проверки не подтверждён. Для
проверки отказов выше ошибки вводились после фактического выбора инструмента.

Сырые ответы, исходные названия и снимки остаются в частной лаборатории;
публичная документация их не содержит. Новые файлы установки не применялись.

Остаются retained-адаптеры промпта/evidence/специальных обработчиков, форматная
подготовка партии, остатки API/bootstrap/classic и конечная автономная поставка.
Python-exit не завершён; условие очистки, push и merge пока не наступило.
