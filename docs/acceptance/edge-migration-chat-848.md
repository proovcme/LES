# Edge на изолированной копии · сборка 848

Рабочий Лес не переключался. Проверяли Rust API с включённым Edge
и локальной Qwen3.5:9b. Публичный установщик 848 по-прежнему поставляется
с Qdrant Server. Проверены перенос всего сохранённого экспорта
(19 245 точек) и отдельный сценарий с 339 точками реального PDF и двумя
редакциями. Это архивная копия; актуальное рабочее состояние не переносилось.

- Оба импорта прервали после 256 записей. Незавершённый Edge отказывался открываться.
  Повтор продолжил с сохранённой позиции и сверил идентификаторы, содержимое
  и векторы. SHA-256 исходного экспорта не изменился.
- Во время незавершённой публикации API записал точку новой редакции. Чат
  остановил ответ с `INDEX_RECOVERY_REQUIRED`, без текстовых событий. Затем
  убили процесс, владевший Edge. При холодном старте Rust удалил незавершённую
  точку; поиск снова видел 339 исходных точек.
- Вторую редакцию опубликовал штатный Rust API. Поиск вернул точки только
  второй редакции; старая ссылка с хешем получила 409. При пробном возврате
  на Qdrant Server восстановили сохранённый каталог и векторы исходной версии.
  Смысловой поиск вернул шесть исходных точек. Ссылка на старый PDF снова
  открылась, хеш второй редакции был отклонён.
- Qwen прочитала оригинал на физической странице 5, назвала найденный в PDF
  DWG и сослалась на страницу. По ссылке вернулись байты исходной редакции
  с ожидаемым SHA-256. Запрос страницы за
  пределами PDF дал `PDF_PAGE_OUT_OF_RANGE`; причина сохранилась в истории,
  текст ответа не выдавался. Полное дочитывание длинной страницы при бюджете
  стенда 8192 токена остановилось с `CONTEXT_REQUIRED_SECTION_OVERFLOW`.
  После смены редакции инструмент прочитал физическую страницу 6. На
  OpenAI-совместимом маршруте отдельные прогоны дали верный текст без ссылки
  на нужный источник или остановку `REASONING_BUDGET_EXHAUSTED`. При повторе
  через нативный Ollama API Qwen назвала DWG со страницы 6 и поставила ссылку
  именно на неё. Скачанный оригинал совпал с SHA-256 второй редакции.

Переключение установленного Леса не принималось. Для него нужна отдельная
сборка с Edge и проверка обновления на свежей копии рабочего состояния.

Целевой прогон: 34 теста миграции, восстановления Edge, импорта и публичного
чата прошли. Доказательства с текстом и именем документа в репозиторий не входят.
