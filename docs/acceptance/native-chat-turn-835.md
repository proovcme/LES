# Приёмка кандидата 835

Проверяется изолированно. Рабочее приложение не перезапускалось; его модели,
папки и индекс не переключались. Публичный чат ещё не переведён на кандидата.

## Выполнено

- Целевой HTTP/PDF/context/model gate: **34 passed**. Нативный API запускается
  с отсутствующим upstream, недействительными `PYTHONHOME`/`PYTHONPATH`/`PATH`.
  Проверены JSON/SSE, replay без второго обращения к модели, частичный обрыв,
  аварийное завершение процесса и восстановление, отсутствие финального ответа
  после ошибки PDF, длинная страница с курсором, правильные ID/хеш/страница,
  запись рабочего файла и автономный одобренный Python-навык без импорта приложения.
  Исчерпание выходного лимита сохраняет частичный ответ и причину вместо успешного final.
  Подтверждены 76 Rust core и 12 Rust API тестов.
- Удалены три неподключённых модуля: прежний PDF layout, извлекатель правил с
  Gemini-веткой и старый выбор кандидатов. Проверены ссылки, импорты и имена
  экспортов; запись удалённого файла исключена из version inventory. Перестроена
  карта исполнения. Проверки документации/inventory/версий после очистки: 23 passed.
- README обновлён: текущий статус, схема архитектуры, актуальный снимок демо-леса
  835. Прежние кадры вынесены в явно обозначенный архив.
- Проверены выбор полного/короткого имени, запрет чтения другого выбранного файла,
  открытие оригинала, старое точное provenance, непроиндексированный файл,
  byte-range/206 и HEAD. Исходные PDF не изменились.
- На отдельной копии выборки реального корпуса, подготовленной в 833, настоящая
  **Qwen3.5:9b** выполнила `search_sources`, затем `read_pdf_source` страницы 2
  и дала ответ. Оригинал по полученной ссылке открыт через Rust; SHA-256 совпал.
  Два исходных документа не изменены. Полная холодная цепочка заняла **71,559 с**;
  это не результат независимой оценки качества и не бенчмарк ускорения поиска.
- Во время этой проверки выявлены и исправлены старый 30-секундный допуск
  семантического поиска и потеря подпапки в имени выбранного файла. Схемы ограничены
  обычным числом инструментов профиля, дублирование evidence в контексте устранено.

Проверки всего репозитория и окончательная квитанция публикации фиксируются в
[журнале выпусков](../RELEASE_LEDGER.md). Не проверялись установка кандидата,
геометрия native-окна, экранный диктор, чистая Windows, 100 контрольных вопросов,
независимая фактическая оценка ответа и конкурентное обновление Edge с новым чатом.
Старые подтверждения публикации/восстановления индекса не заменяют последнюю проверку.
