# Build 765 — очередь проверки и адресное чтение таблиц

Состояние: локальный кандидат исходников. Приложение пользователя, назначения
моделей, документы и рабочий индекс не изменялись. Публикация и установка
этим отчётом не подтверждаются. Новые модели/зависимости не устанавливались.

Добавлено:

- Явный список документов/разделов, возобновление, история ревизий и безопасный
  повтор записи через инструмент document_review основного чата.
- Проверка SHA исходника и fingerprint индексированного раздела; устаревание
  выводов и их явно заявленных зависимостей без удаления истории.
- Передача порций чтения через обязательный контекст; учёт доставленных порций
  после успешного вызова модели; сохранение результата с цитатами и локаторами.
- Чтение окон таблицы по строкам и столбцам, объединениям и координатам;
  дочитывание длинных значений отдельной ячейки по символьному курсору.
- Общий транспорт SQLite отделён от схемы заданий по строкам.

Целевые проверки проходят без генеративной модели: реальный временный SQLite,
Qdrant в памяти, штатный ToolHarness, ChatSectionReader, рендер доказательств и
ContextGovernor. Проверяются перезапуск, отсутствие прав чужого диалога,
конкурирующие записи, пропуски чтения, неверные цитаты, точный повтор request_id,
изменение байтов при прежнем mtime/размере, транзитивное устаревание выводов,
сохранность старых версий, правильная область Qdrant и кэш по поколению.
Таблицы: ноль/False/ведущие нули, формулы и отсутствующий кэш, объединения,
пустые координаты, пробелы в именах листов и длинные строки с Unicode.

Целевой прогон: 34 теста прошли (включая прежние задания по таблицам).
Полный прогон: 1313 passed, 4 skipped, 18 subtests passed, 124.14 секунды.
make verify: 1317 тестов собраны, компиляция, версии и карта runtime проверены.
make test, public-check и git diff --check прошли. Это проверки исходников,
не установленного пользовательского пути.

Ограничения: нет проверки поведения реальной модели на этих новых инструментах
и установленного Windows GUI. Нет панели принятия/удаления очередей, экспорта
отчёта, самостоятельного фонового агента или автоматического обнаружения всех
смысловых зависимостей. Очередь проверяет выбранный индексированный текст;
оригинальная графика и достаточность OCR требуют отдельной проверки.
Длинную ячейку можно дочитать, но прежний row-пакет сверх бюджета остаётся
незавершённым: адресное чтение не превращается в скрытое подтверждение строки.
Ранее отсутствующая и явно пустая XLSX-ячейки в снимке ещё не различаются;
новое окно честно возвращает blank_or_absent.
