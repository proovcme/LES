# Кандидат 860: один владелец доказательств

Работа выполняется в исходниках и на прежней отдельной копии корпуса.
Установленный LES, исходные документы и назначения моделей не переключены.

## Удалённое дублирование

| Причина | Изменение |
| --- | --- |
| `Evidence` и `SourceFlow` отдельно хранили набор прочитанных источников; состояние `Phase` повторяло то, что уже следовало из квитанций и передачи контекста. | Удалены `SourceFlow`, `Phase` и промежуточный `ReadAdmission`. Один `Evidence` принимает текст и подтверждает его фактическую передачу. Стадия диагностики вычисляется из этих данных. |
| Координатор передавал отдельный признак строгости при каждом получении блоков, выбирал между двумя почти одинаковыми списками и отдельно решал, какие блоки считать доказательствами. | Политика закрепляется в реестре при создании. `required_blocks()` и `optional_blocks()` возвращают допущенные блоки; внутренний список больше не доступен координатору напрямую. |
| Начальная подборка и восстановление после ответа без источников независимо задавали одинаковые параметры поиска и чтения. | Оба пути вызывают `retrieval::initial`; инструменты используют тот же общий поиск и читатель. Второго алгоритма ранжирования не добавлено. |
| В рефакторинг попало недоказанное изменение режима по умолчанию и дополнительный протокол настройки фронтенда. | Удалены карта `retrieval_defaults`, её передача/обработка и автоматический выбор Push для профиля «Поиск». Сохранены прежний Pull и явный выбор всех трёх режимов. |
| Ошибка отсутствующего индекса предлагала проверить модель. | Для явного Push без подготовленного индекса выводится причина поиска до вызова модели; код и человеческий текст сохраняются в истории. |
| `dataset_map` отдельно читал каталог и обходил ограничение выбранных файлов. | Список набора и поиск имён используют одну страницу каталога с одинаковыми ограничениями области и файлов. Прежнее имя инструмента, лимит 100 и поля результата сохранены; описание соответствует фактическому списку документов. |
| Координатор отдельно выбирал проекцию метаданных; после первого чтения большой каталог уже не ограничивался. | Проекцией владеет `Evidence`. Каталоги обоих инструментов ограничиваются независимо от стадии; полные результаты остаются в журнале, метаданные не становятся доказательствами. |

`inspection.rs` теперь содержит только проекцию указаний для модели, без
контроллера или собственного состояния чтения. Проверки этого состояния
перенесены к его владельцу, не удалены. Новое чтение сбрасывает подтверждение
предыдущего окна до успешной новой передачи модели. Метаданные, пустой текст,
ошибки и устаревшее поколение по-прежнему не разрешают ответ.

В затронутых одиннадцати файлах после переноса было на 114 строк меньше;
последующее усиление проверки передачи добавило три строки теста. Это объём
данного рефакторинга, не показатель оставшегося Python во всём репозитории.
Новых зависимостей, моделей, процессов или пользовательских настроек нет.

## Проверки

Прошли 40 модульных проверок Rust API. До последнего объединения каталога
прошли 136 целевых интеграционных проверок, 41 проверка Svelte и сборка
интерфейса. В браузере проверены загрузка нового
чата, назначенная модель и прежние три режима без автоматического переключения.
Окончательный общий gate: `cargo fmt --check` и `make verify` прошли;
`make test` — 2132 passed, 2 skipped, 18 subtests passed за 883,49 с.
Проверка собрала 2134 теста. Это результат окончательного кода после
объединения каталога; предыдущие остановленные серии в него не включены.

Регрессия ограничения файлов сначала воспроизвела ошибку старого бинарного
файла: `dataset_map` вернул два документа вместо одного выбранного. После
объединения каталога та же проверка прошла. Модульная проверка отдельно
подтверждает ограничение большого каталога после уже выполненного чтения,
включая вызов через расширения, без изменения сырого результата в журнале.
Первый общий запуск 860 был остановлен до этой правки и не засчитывается
как проверка окончательного состояния.

Qwen на копии повторила три вопроса без выбора файла: строка Excel, составной
вопрос к PDF и изменение редакции. Во всех трёх случаях последовательности
SHA-256 реально переданных блоков текста совпали с 859. Строка Excel и изменение
листа получили основные правильные сведения; PDF по-прежнему не дочитан до
третьей страницы. Неправильное сложение типов камер также не засчитывается как
успех. Это проверка сохранения поведения при удалении дублирования, не приёмка
качества RAG. Полные вопросы, ответы и сравнение остаются в частном журнале.

Удалён один завершённый отладочный PDB модульных тестов (806 039 552 байта),
принадлежность проверена по журналу успешной сборки. Рабочие базы, модели и
общий каталог сборок не очищались целиком. Тестовые файлы убираются после
завершения проверок; минимальный запас диска сохраняется.
После окончательного gate в его временном каталоге не осталось файлов;
свободно 25 129 111 552 байта (около 23,4 ГиБ). Отдельные серверы приёмки
остановлены, пользовательские процессы не завершались.

Последняя общая серия 859: 2130 passed, 2 skipped, 1 failed. Единственный
отказ касался изменения значения по умолчанию: вместо прежней проверки
отсутствия доказательств запускалась подготовка несуществующего индекса.
860 сохраняет прежний договор этого сценария. Отдельный новый тест проверяет
явный Push без индекса и его правильную причину ошибки; старое ожидание не
ослаблено. [Предыдущие измерения и диагностика](native-retrieval-859.md).

## Что это не закрывает

Упрощение не считается улучшением смысловой точности само по себе. Открыты
выбор нужного вида документа, дочитывание всех частей составного вопроса и
доказательность отрицательного ответа. У пропущенной страницы подтверждено,
что весь четырёхстраничный индексированный текст занимает 4898 символов;
причина пропуска — отбор контекста, а не отсутствие текста в индексе.
Полнота поиска, весь Python-exit и установленный выпуск этим отчётом не
объявляются завершёнными.
