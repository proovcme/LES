# Приёмка нативной политики доступа 832

Отдельные процессы и временное состояние; рабочий LES не перезапускается.
Проверяются обычный холодный старт без backend и без вручную подготовленного
auth-policy файла, создание ключа в пустом реестре, рестарт с запретом доверенных
сетей/прокси, сохранение ключа и отказ ограниченному пользователю в мутации.
В процессе API заданы несуществующие PYTHONHOME/PYTHONPATH, upstream отсутствует.

Дополнительно: отзыв/истечение ключей, изменение роли, forwarded/real-IP,
настроенный proxy-header, невалидный байтовый адрес, CORS с пользовательским
правилом и preflight, повреждённая конфигурация и исправление без permissive
fallback. Старые callback-маршруты тестового upstream служат ловушкой: ни одного
вызова к ним не должно быть. Чтение памяти не меняет состояние экземпляра.

Поймана регрессия промежуточного кандидата: quoted-имя `'TRUSTED_NETWORKS'`
игнорировалось и оставляло доверие loopback. До исправления холодный тест давал
200 вместо ожидаемого 401. После исправления проверяются quoted-ключ, комментарий
с `${...}`, export, пустой список, перезапуск и прежний ключ; анонимный запрос
отклоняется. Это проверка кандидата, не утверждение об установленной версии.

Целевые HTTP/модельные/статические регрессии: **45 passed** на исправленном
бинарнике. Core: **69 passed**. Общий gate проверяется отдельно ниже.

Итоговые gates на исправленном кандидате: Rust core/API/runtime — **69/10/7 passed**;
`make verify` — **1975 collected**; `make test` — **1973 passed, 2 skipped**,
18 subtests (407,22 с). Проверки контрактов/версии, документации, форматирования
и публикации прошли; в staged-изменениях нет runtime-артефактов и частных путей.
Полный gate включает автономные внешние навыки и Server/Edge-пути.

Установленная версия, полноценный
холодный запуск всего приложения и полный Python-exit этим тестом не объявляются.
