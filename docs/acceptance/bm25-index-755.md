# Build 755 — поиск и надёжность без Qwen

## Разделение работ

| Без генеративной модели | Требует генеративной модели |
| --- | --- |
| Формула BM25, IDF, длина и частота термов | Верность окончательного вывода |
| Миграция, добавление, замена, удаление, восстановление | Выбор между противоречащими источниками |
| Фильтры, native RRF и маршрут по иерархии | Корректный отказ при недостатке доказательств |
| Точность ID, текста, страниц, бюджет контекста | Качество сводки и памяти диалога |
| Скорость поиска на сохранённых эмбеддингах | Скорость генерации и первого токена |

Первый столбец проверяется независимо. Он не должен ждать доступности Qwen.
Новые модели и зависимости не устанавливались, назначения моделей не менялись.

## Изменения

Подключён [рабочий BM25](../modules/bm25-index.md), включая собственный точный IDF
по живым точкам. Миграция не меняет dense-векторы, документы, цитаты и иерархию.
Изменение корпуса инвалидирует веса; следующая выдача предварительно пересчитывает
их под журналом. Проверены добавление, замена, удаление, неполная запись и ошибка
публикации контракта, повторный запуск, откат и защита от двойного IDF.

## Проверка поиска

Использованы прежние 40 вопросов по двум документам: 32 имеют размеченные группы
доказательств, 8 не имеют ответа. Эмбеддинги документов и запросов сохранены
заранее. Реальный нативный Qdrant, рабочий `retrieve_native_hierarchical`,
одинаковые фильтры, top-10 и выключенный реранкер. Вызовов Qwen — ноль.
Это не независимые 100 случаев и не проверка правильности ответа.

| Средняя полнота размеченных групп | Прежний TF+IDF | BM25 |
| --- | ---: | ---: |
| @5 | 89,06% | 90,63% |
| @10 | 96,88% | 100% |

Результаты отличаются от 752: здесь рабочий иерархический маршрут, тогда —
изолированный плоский native RRF. Сравнивать проценты между этими двумя отчётами
как регрессию нельзя. Совпадение засчитывается по точному ID или размеченному
якорю; для строгой оценки независимого корпуса нужна отдельная разметка.
Восемь вопросов без ответа не засчитаны как правильные отказы.

Для каждого возвращённого фрагмента проверены точный текст, документ, датасет,
страница и отсутствие навигационного узла среди доказательств. После цикла
TF → BM25 → TF → BM25 сверены исходные payload, ID и dense-векторы.

Улучшены два случая, ухудшений этих метрик в данном наборе не найдено: case-009
@10 с 0 до 1, case-029 @5 с 0,5 до 1. Медиана рабочего иерархического поиска на
сохранённых эмбеддингах: TF 99,4 мс, BM25 96,2 мс. Разница мала; ускорение не
заявляется. Пересчёт 227 точек в BM25 — 0,29 с, повторный — 0,31 с.

## Проверки и установка

- `make verify`: пройден, 1154 теста собраны.
- `make test`: 1154 passed, 18 subtests passed, 25 warnings, 89,92 с.
- 13 специальных проверок BM25, включая реальный нативный Qdrant и скалярный
  независимый расчёт. Без переменной `LES_TEST_NATIVE_QDRANT` один серверный тест
  пропускается; в этой приёмке он выполнен, пропусков нет.
- `make public-check`, `git diff --check`: пройдены.
- В установленный runtime перенесены 12 проверенных файлов с исходными SHA-256
  и резервными копиями. Установленный код совпадает с кандидатом; табличный
  непринятый сценарий 746 не переносился.

API кандидата: три поиска с живым назначенным эмбеддером, без генератора,
0,36–0,92 с. Установленный runtime отдельно запущен встроенным Python на копии
состояния: первый запрос с подготовкой и прогревом — 5,26 с, следующие —
1,37 и 1,60 с. Это единичные проверки при работающих тестах, не стабильный
benchmark задержки. В установленной копии подтверждён контракт `mode=bm25`,
`idf=exact-corpus`, 227 точек. Генеративный endpoint в этом запуске не вызывался.

Через браузер проверено: поиск в «Лесе знаний» → 20 найденных фрагментов →
выбор документа → точный фрагмент с нужным утверждением → возврат к списку.
Техническая схема обновлена под BM25. Скриншоты и журналы хранятся локально,
личные источники не добавлены в репозиторий. Нативный WebView2 не проверялся.

Основной пользовательский индекс в ходе приёмки не изменялся. После обычного
перезапуска установленного Леса его первый гибридный поиск автоматически
пересчитает прежние веса в BM25. Исходники не перечитываются, модели не меняются.
Открытые пользовательские процессы принудительно не перезапускались.
Полный установщик и публичный выпуск этим локальным патчем не обновлены.

Остаются отдельными: независимые 100 случаев, технические короткие обозначения,
производительность на большом корпусе и качество ответа/отказа с моделью.
