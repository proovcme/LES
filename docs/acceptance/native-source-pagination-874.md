# 874 — непрерывное чтение источников

Изменения PR #7 проверяются на прежней копии корпуса. Рабочий LES,
назначения моделей и исходные документы не переключаются.

## Причина

`offset` относился к исходным единицам чтения, а `included_fragments`
считал также соседей, раскрытых упаковщиком. При размерах фрагментов
1 500, 1 500, 300 и 300 и бюджете 2 000 прежний путь выдавал `p0,p2`,
затем `p2,p3`: второй фрагмент терялся, третий повторялся. Ненулевой
offset также создавал продолжение после конца документа.

## Договор

Постраничные `read_source`, `read_excel_source` и явный `search_sources`
читают непрерывный префикс единой упорядоченной последовательности.
Материализованная PDF-страница считается одной единицей до применения
лимита и смещения. При недостатке бюджета нельзя перескочить через блок,
отрезать текст или подставить соседа. Первый невместившийся блок остаётся
следующим; если не помещается даже первый, возвращается явная ошибка.

`retrieval/pagination.rs` — единственный владелец курсора. Он вычисляет
продолжение после окончательного допуска целых блоков. В конце — `null`,
включая последнюю страницу с ненулевым смещением. Для продолжения должны
сохраняться запрос, фильтры и документ/редакция; смещение не является
универсальным курсором для другого запроса или изменённого корпуса.

`retrieval/envelope.rs` отвечает только за размер полного JSON-конверта,
целостность блоков и снятие признака полного документа при частичной выдаче.
Карточки навигации заполняют остаток бюджета. Он не вычисляет смещения.

Автоматический начальный поиск сохраняет dense + BM25 + RRF, разнообразие
источников и раскрытие родителей/целого документа. Явное чтение страницы
возвращает только её последовательные единицы; остальные разделы доступны
через продолжение. Дочитанные соседи не становятся скрытыми позициями курсора.
Оригиналы, SHA-256, физические страницы и исходные квитанции сохраняются.

## Приёмка

Форматирование Rust исправлено. Локальные `cargo test` дали 82 пройденных
проверки API и 122 проверки ядра. `make verify` собрала 2 212 тестов,
`make public-check` прошла. Полный локальный `make test` остановлен примерно
на 61% при смене приоритета на реальные запросы; он не считается пройденным.

Через настоящий API проверены `read_source` и `search_sources` на PDF с
четырьмя страницами разного размера. Ожидаемые идентификаторы независимо
прочитаны из индекса: все четыре выданы ровно один раз, окончания текста
сохранены, последнее продолжение — `null`. После окончательной правки
бюджета пять затронутых проверок чтения и смещений пройдены повторно.

### Что обнаружила реальная Qwen

На прежней копии корпуса выполнены семь запросов Qwen3.5:9b с окном 8 192.
Ни один файл не прикреплялся вручную. Два запроса были обычными справками
без инструкций о вызове инструментов; отдельные запросы проверяли курсор
и физическое чтение PDF. HTTP 200 не использован как оценка качества.

* Справка по составу томов непригодна: вместо связного обзора выданы строки
  содержания, подписи и пустые строки. Фактического дочитывания не было.
* По электроснабжению найден подходящий документ, но содержательное
  дочитывание не выполнено. Итог — отказ подтвердить сведения. Задача не решена.
* Pull с курсором прочитал первую порцию, но следующая не прошла бюджет;
  Hybrid закончил без явного чтения и потому курсор не проверил.
* Два положительных PDF-запроса действительно открыли нужные оригиналы
  и физические страницы. Это не приёмка обзорного синтеза.
* В отрицательном PDF-запросе получен отказ от подтверждения, однако модель
  открыла другой оригинал. Проверка конкретного повреждённого PDF не принята.

У 23 выданных источников сверены оригиналы и SHA-256, проверены 10 адресов
страниц и доступность всех ссылок. Ошибок адресации нет; соответствие ответа
вопросу этим не доказано. Частные тексты и пути остаются вне репозитория.

### Исправление по реальному отказу

`reader_capacity` уже переводил свободное окно из токенов в символы.
`bounded_read` повторно делил результат пополам; затем действовал ещё
фиксированный предел по умолчанию. При доступных примерно 5 300 символах
блоки более 4 200 не проходили ограничитель около 2 600.

Повторное деление удалено. Для отсутствующего `max_chars` используется
рассчитанный бюджет; явно заданный меньший предел сохраняется. Явный поиск
также получает этот бюджет. Окончательный packer, резерв идентификаторов,
целые блоки и защита чисел не отключаются.

После правки повторён тот же вопрос с Qwen в Pull. Выполнены поиск и два
`read_source`: offset 0 → 1 → 2, порции 2 059 и 4 275 символов. Два источника
сверены с одним оригиналом и двумя страницами; продолжение использовано,
повторённых единиц нет. Это модельный повтор, не детерминированное сравнение
её ответов: формулировки поисковых вызовов модель выбирает сама.

Чтение прошло, но итоговая справка снова содержит посторонние строки таблиц.
Полная пользовательская задача **не принята**. PR нельзя считать готовым
к мержу по числу технических проверок или успешному продолжению чтения.
Нужны исправление отбора сведений, содержательное дочитывание и полноценный
синтез с проверяемыми основаниями. Общий gate и пользовательская приёмка
должны завершиться перед мержем.

Тестовые серверы остановлены, Qwen выгружена, наблюдение копии восстановлено.
Рабочий LES, индекс и модели не переключались. Новый установщик и установленный
пользовательский сценарий этой сборки не проверены.
