# Кандидат 821: навыки, MCP и исполнитель инструментов

Статус: проверены исходники и изолированные компоненты Windows. Рабочая
установка, её модели и индекс не изменены. Полный Python-exit, установщик и
публичный выпуск не объявляются готовыми.

## Перенесённые владельцы

- `core/src/skills/`: библиотека, SHA-разрешения, входные строки, задания,
  атомарные результаты, контроль дочернего процесса и восстановление.
  Старый `tools/skill_compute_worker.py` удалён из исходников и списка упаковки.
- `core/src/mcp_registry.rs`, `api/src/mcp/`: настройки SQLite, HTTP/stdio,
  JSON-RPC/SSE, session/protocol headers, discovery и вызов выбранного чтения.
  Прежний Python SDK и SQL-реализация этого клиента удалены из его сервиса.
- `core/src/tool_execution/`: схемы, допуск, область, квитанции,
  идемпотентность, SQLite-журнал и полные ответы с курсорами.
- `core/src/document_source.rs`: единое разрешение внешних и загруженных
  оригиналов. Физическое чтение PDF теперь также работает для загрузок
  собственного хранилища; ID, страница и SHA остаются привязанными к каталогу.

Совместимые Python-сервисы этих модулей оставлены кодеками/адаптерами, их
потребители ещё не все перенесены. Это не замена полного координатора чата.

## Проверки

| Проверка | Результат |
| --- | --- |
| Rust core | 55 unit-тестов прошли |
| Rust API, обычная сборка | 10 unit-тестов прошли |
| Rust API с Edge | 10 unit-тестов прошли |
| Rust runtime | 7 unit-тестов прошли |
| `make verify` | 1758 тестов собраны; версии, карта и API-контракт совпадают |
| `make test` | 1755 прошли, 3 пропущены; 18 subtests прошли |
| Отдельные источники/навыки | 40 проверок прошли |
| Изолированный CPython без приложения | 4 проверки навыков прошли |
| `public-check` | прошёл |

Три пропуска общего прогона: POSIX TCP reuse, macOS lifetime supervisor и
отдельный тест локального эмбеддера без явно переданной offline-спецификации.
Новый прогон Qwen в этом кандидате не выполнялся.

В первом общем прогоне три проверки оригиналов обнаружили несовместимый
Windows-префикс `\\?\` в публичном пути. Исправлен именно код форматирования
на границе C ABI; прежние проверки пути сохранены. Повторный общий прогон зелёный.

Хеши аргументов сравнены с прежним Python JSON на 10 000 случайных double,
больших целых и Unicode. Исправлена обнаруженная разница кратчайшего округления
на точной середине. Подтверждения и старые ключи идемпотентности сохраняются.

## Автономные старые функции

Нативный exe запускался из отдельной папки. Проверены 70 строк, paging,
UTF-8/Unicode-пути, неизменность одобренного SHA, отсутствие переменных приложения,
тайм-аут, принудительное завершение владельца, гибель его дочернего процесса и
продолжение без повторения подтверждённой строки. NumPy и OpenPyXL выполнялись
в одобренной функции; `backend` и `proxy` нельзя импортировать.

Дополнительно собран отдельный тестовый CPython без каталога приложения и без
`import site`/`.pth` startup. Он содержит только стандартный интерпретатор и
замыкание зависимостей NumPy, Pandas и OpenPyXL из существующего lock:
NumPy 2.4.5, Pandas 3.0.3, OpenPyXL 3.1.5, et-xmlfile 2.0.0,
python-dateutil 2.9.0.post0, six 1.17.0, tzdata 2026.2.
Размер этого тестового каталога — 99 050 776 байт. В нём повторно прошли
четыре проверки нативного host, включая падение/восстановление.

Это самостоятельная проверка компонента, не приёмка всех пользовательских
скриптов и не проверка установщика на чистой Windows. Отдельная поставка и
обновление совместимого интерпретатора ещё должны войти в финальный пакет.
В прежнем общем embedded runtime строка `import site` в `._pth` переопределяет
`-S`; этот факт проверен отдельно и не скрывается заявлением об удалении Python.

## MCP и устойчивость исполнения

Проверены настоящий HTTP/stdio-сервер и stateful SSE: русский текст по частям,
Session ID, версия, ping, отказ в необъявленных roots, неверный ID ответа,
изменение схемы, внешние schema refs, отзыв сохранённого разрешения и DELETE
сессии. При отключённом Python-модуле `mcp` нативный клиент продолжает работать.

На реальной SQLite проверены параллельные повторы, привязка квитанции к actor,
инструменту, ревизии и точным аргументам, отзыв разрешения, потеря ответа после
эффекта, durable cursor/TTL и запрет автоматического повтора неоднозначного
изменения. Уменьшенный ответ сохраняет ссылку на полный, а не теряет данные.

## Что не закрыто

Полный список владельцев остаётся в [Python-exit](../modules/python-exit.md).
Нужно перенести `process_one` партии и её оставшиеся форматные ветви,
координатор общего разговора/динамические обработчики, остатки API,
bootstrap и classic UI. Нативный `AgentLoop` пока не заменяет весь основной чат.
После этого нужны чистая установка, реальный чат, CLI/MCP, восстановление и
обновление на копии корпуса. Только затем допустимы удаление общего окружения,
окончательная очистка и условно запрошенные push/merge.
