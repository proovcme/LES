# Build 785 — единая очередь индексации

Rust считает ожидающие документы и атомарно создаёт одну активную запись
очереди. Ручной и автоматический запуск используют один захват. Прерванное
задание сохраняет прогресс, а восстановление освобождает очередь. Выполнение
порций и HTTP остаются в Python. [Контракт](../modules/auto-parse-resume.md).

Кандидат и установленный Windows-патч проверены на двух синтетических файлах:
ручной дубль получил HTTP 409, единственное задание обработало оба файла,
поиск нашёл их. Тестовый набор удалён штатно, исходники сохранены. В рабочей
базе сохранены 337 исходных записей, 20 прежних заданий и назначения моделей.
Лес запущен стандартным ярлыком и открыл прежний диалог в новом чате.
Откат десяти файлов проверен на пробной замене.

Набор проверок: 1 589 основных тестов (два пропущены), 66 почтовых,
30 тестов ядра Rust, 33 теста frontend. Отдельно подтверждена гонка восьми
параллельных захватов с сохранением прогресса после восстановления.

Windows-установщик использует новый чат, если в пакете есть нативный запускатель
и Rust API. Этот локальный патч применён к существующей установке; чистая
установка не выполнялась. Сборка macOS preview теперь включает Rust-библиотеку
с квитанцией; сборка и запуск на реальном Mac здесь не проверялись.
