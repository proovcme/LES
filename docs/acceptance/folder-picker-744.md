# Выбор папки · build 744

Исправление после 0.1.0: кнопка выбора набора больше не открывает вложенный
браузер серверной файловой системы. В Windows используется IFileOpenDialog
с режимом выбора существующей папки, адресной строкой и поиском. PowerShell
и устаревшее дерево FolderBrowserDialog исключены из Windows-ветви.

Общая реализация используется также для папки в чате. Повторные нажатия
не создают окна поверх окон, отмена сохраняет путь и имя. Выбор сам по себе
не подключает набор и не индексирует документы. Исходники остаются read-only.

Проверено: тесты формы (выбор, отмена, отказ, повторный клик), реальная COM
конфигурация Unicode-пути, make verify и make test (1029 тестов и 18 subtests).
Нативное окно открыто установленным Python; папка с кириллицей, пробелами и №
выбрана через системную кнопку, возвращённый путь совпал с исходным.

Установлен локальный патч с сохранением отката. В отдельном профиле на
установленном коде пройден путь: Данные → Добавить набор → системный диалог →
Отмена (путь сохранён) → повторный выбор → подтверждение → подключение пустой
папки под наблюдение. В списке появился набор с честным статусом «Пусто».
Из чата также открыто системное окно; Escape вернул в форму без потери пути.
Также исправлено доступное имя кнопки подтверждения пустой папки: оно
совпадает с видимым текстом «Подключить под наблюдение».

Пользовательский профиль не изменялся, открытый экземпляр не перезапускался.
Локальная правка вступает в силу при следующем запуске. Публичный выпуск и
EXE-установщик остаются 0.1.0 build 743; build 744 ещё не опубликован.
