# Build 745: диалог, навыки и вычисления

## Изменения

- Одна строка истории принадлежит запросу от приёма до финального сохранения.
  Каждый отправляемый фрагмент потока сначала фиксируется в SQLite. После
  перезапуска незавершённый ответ виден как прерванный и не попадает в память
  модели как успешный. Повторный запуск восстановления не создаёт дубликаты.
- Автосводка начинается в простое; новый запрос отменяет фоновую сводку,
  освобождает слот модели и переносит её на следующий простой. Ручная сводка
  остаётся отдельным действием. CAS-защита забывания и редакций сохранена.
- Launcher проверяет свою API/UI instance identity и свой Qdrant. Шесть
  последовательных провалов приводят к восстановлению; ограничение трёх
  перезапусков за пять минут сохранено. Долгая генерация сама по себе не отказ.
- Установленные пакеты навыков находятся в постоянном storage/skills, читаются
  страницами без обрезания исходных файлов. Ссылки между навыками работают внутри
  библиотеки; выход через пути и ссылки за её границы запрещён.
- Выбранные расширения доступны через компактный каталог: список → точная схема
  → вызов. Проверки исходного инструмента выполняются при каждом вызове; профиль
  ограничивает доступный набор. Число вызовов и бюджет контекста остаются ограничены.
- Python-worker выполняет только явно проверенный SHA-256 и функцию из локального
  approved-compute.json. Проверка не является песочницей произвольного кода.
  В Windows: отдельный процесс, до 512 МиБ, один процесс в job, 15 CPU-секунд,
  20 секунд по часам; секреты подключений в среду ребёнка не передаются.
  До 100 JSON-позиций с уникальными ID; каждый результат фиксируется отдельно,
  возвращаются job_id, completed/succeeded и pending_ids. Изменение скрипта
  после разрешения блокирует исполнение. Исходные документы worker не получает.

## Приёмка

Целевые проверки: 12 прошли, включая реальный Python-worker на 70 синтетических
строках, ошибку отдельной строки, изменение хеша, Windows junction за границы
библиотеки, доступ через малый shortlist, обрыв SSE, отсутствие дублей истории,
приоритет запроса над автосводкой и восстановление счётчика health-проб.

`make verify` прошёл; `make test`: 1041 тест и 18 subtests прошли (24 предупреждения
зависимостей/жизненного цикла). Локально установлены 18 runtime-файлов с проверкой
baseline и SHA-256, резервной копией заменяемых файлов и квитанцией отката.
Публичный EXE не заменялся: это локальный патч 745 поверх установки 0.1.0.

На установленном embedded Python, в отдельном каталоге состояния:
- настоящий калькулятор установленного пользовательского навыка выполнил
  70 синтетических ресурсных строк, сохранил результаты; последняя проверена
  независимо (`70 × 10,25 = 717,50`);
- startup восстановил незавершённую строку, API истории вернул сохранённый текст
  и отметку «Ответ прерван», health API/UI/собственного Qdrant прошёл;
- источники и модели пользователя для тестового корпуса не использовались.

В пользовательское состояние перенесены 46 локальных навыков RU AEC, 133 файла
с проверкой хешей. Созданы отдельное подключение ФГИС с 26 инструментами чтения
и новая активная редакция профиля «Агент» для новых чатов. Реальный вызов каталога
ФГИС прошёл. Прежние чаты сохраняют свои закреплённые редакции профиля.

По отдельной просьбе пользователя модель ответов переключена на существующую
35B MLX на Mac через уже работающий SSH-туннель. ЛЕС получил настоящий потоковый
ответ и native tool call, затем исполнил вызванный моделью калькулятор:
`2 × 3,25 = 6,50`. Проверка выполнена установленными transport/harness/worker,
без замены результата модели. Контекст подключения ограничен 24 576 токенами;
параметр модели дополнительно прочитан через SSH. Поисковые embeddings сохранены.

Визуальная повторная приёмка не завершена: браузерный контроллер не вернул
доступных браузеров, Windows helper не смог активировать окно Chrome. API-проверка
не объявляется проверкой изображения/кликов; нативное окно и экранный диктор
в этом патче повторно не проверены.

## Границы

70 строк арифметики не доказывают готовность полной ЛСР. Внешний пользовательский
навык владеет методикой, а MCP — источниками. Специализированный сметный движок
в пакет не возвращён. Произвольный Python, возобновляемый реестр инженерных
решений, полный выпуск Excel и автоматическое продолжение цепочки MCP после
сбоя остаются в бэклоге. Контекст использует оценку токенов; автосводка не заменяет
построчную расчётную модель и доказательства.
