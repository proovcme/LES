# Семантика DOCX · кандидат 855

Продолжение [854](real-corpus-854.md) на том же отдельном состоянии и тех же
исходных документах. Этот файл описывает кандидат; рабочая установка,
назначения моделей и публичный выпуск не переключаются. Личные пути и
результаты извлечения остаются вне репозитория.

## Изменения

- Декодирование известных специальных символов с проверкой шрифта. В частности,
  минус, умножение, сигма, гамма и маркер Symbol не смешиваются с теми же кодами
  неизвестного шрифта. Метки списков используют `rFonts` уровня нумерации.
- Явные пропуски колонок `gridBefore`/`gridAfter` сохраняются пустыми ячейками;
  вертикальные объединения остаются привязаны к исходной колонке. `tblGrid`
  проверяет ширину. Отсутствующие без указания пропуска ячейки не додумываются.
- Ограниченное чтение Office Math: текст, дробь по умолчанию, верхние/нижние
  индексы с явной группировкой. Неизвестные операторы/свойства, неполные или
  переставленные аргументы вызывают отказ целого документа.
- Чтение чисто текстовых VML-textbox с абзацами/таблицами в месте вставки.
  Рисунки, объекты и неизвестные VML-элементы не маскируются текстом блока.
  Нумерованные textbox отклоняются до поддержки отдельных историй Word.
- Причина ошибки приходит из этапа чтения. Наличие списка больше не служит
  основанием обвинить нумерацию при ошибке таблицы. Проверяются дубликаты
  исходных имён OOXML, которые ZIP-reader скрывает при обычном перечислении.

## Ограничения

Полное чтение рисунков, WMF/EMF, DrawingML, OLE/MathType и всех конструкций
Office Math не заявляется. Содержимое этих элементов не пропускается ради
успешного статуса. Сохраняются пределы размера исходника, XML и результата;
новые зависимости и Python-маршруты не добавлялись.

## Реальный корпус

Повторно обработаны 42 отказавших DOCX через штатную Rust-очередь в прежнем
испытательном индексе. Четыре дополнительных файла опубликованы; остальные
596 документов не переиндексировались. Итог: **600 INDEXED / 38 ERROR** из
638 допущенных оригиналов. DOCX: 40 INDEXED / 38 ERROR. В каталоге 77 320
поисковых/навигационных узлов против 77 041 в 854. Все 638 исходников
сохранили SHA-256; INDEXED с нулём узлов не обнаружен.

Для четырёх новых документов отдельно проверены гибридный поиск с иерархией,
раскрытие родительского раздела и загрузка оригинала по ссылке, привязанной к
SHA-256. Все четыре ссылки вернули исходные байты. Сопоставление 7306 непустых
текстовых runs основной части `word/document.xml` с извлечённым текстом не
обнаружило пропусков, перестановок и недостаточного числа повторений
(с нормализацией пробелов и Markdown-экранирования). Это контроль сохранения
основного текста, а не аудит колонтитулов, всех частей OOXML и интерпретации
всех таблиц моделью.

В оставшихся файлах первая фактически встреченная причина: 34 рисунка/сложных
текстовых блока, два превышения лимита XML, один неизвестный шрифт символа,
одна неподдержанная нумерация. Это не полный перечень всех особенностей файла:
OLE и формулы могут находиться за первым отказавшим рисунком. Их поддержку
по смене первого кода ошибки не считаем реализованной.

Дополнительная сверка связей, а не просто списка файлов ZIP, обнаружила в
оставшихся документах встроенные Equation.3, MathType, PDF и XLSX. OLE-ссылки
есть в девяти файлах; некоторые документы содержат несколько объектов.
Два превышающих лимит XML имеют размер около 34 и 78 МиБ. Это отдельные
задачи структурного чтения и контролируемого извлечения объектов; переход на
картинку-превью не считается сохранением содержимого вложенного Excel/PDF.

## Регрессии

Целевой прогон DOCX/форматного конвейера: 90 passed. Включены специальные
символы и неизвестные шрифты, списки, формулы с группировкой и неправильными
аргументами, текстовые блоки с таблицами, запрет скрытой потери рисунка,
ограничение вложенности, XML-экранирование атрибутов, пропущенные ячейки,
дубликаты ZIP и последовательность успешный DOCX → ошибка → успешный DOCX
в отдельном Rust-процессе с отсутствующим Python в окружении.

Rust unit tests: 97 passed. `make verify` собрал 2108 тестов. Release-сборка
скомпилирована; целевые проверки в ней также дали 90 passed. После холодного
открытия того же испытательного индекса release API повторно прошёл поиск,
родительское чтение и ссылки четырёх новых файлов. Для всех 78 DOCX debug и
release дали одинаковые статусы, длины текста и причины отказа. Полный `make test`:
**2106 passed, 2 skipped, 44 warnings, 18 subtests passed за 814,70 с**;
отдельно сохранён код завершения 0. Первый прерванный общий прогон не засчитан.
Qwen, оценка фактической точности ответов и визуальная приёмка установленного
приложения в этом прогоне не повторялись. Новых измерений скорости на спокойной
машине нет: во время сверки параллельно выполнялись сборка и тесты.

Серверы проверки корпуса остановлены, оставшихся их дочерних процессов не
обнаружено. Автоматическая политика среды отклонила рекурсивное удаление
временных тестовых каталогов (`blocked by policy`). По итоговой сверке все три
каталога целевых и общих тестов пусты: 0 файлов / 0 байт. Пустые каталоги
остались; свободно около 35,4 ГиБ. Общий кеш сборок, модели, оригиналы и единственный
повторно используемый индекс корпуса не удалялись.

Соответствия Symbol сверены с [таблицей Unicode Consortium](https://www.unicode.org/Public/MAPPINGS/VENDORS/ADOBE/symbol.txt).
