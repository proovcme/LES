# Приёмка нативной проверки документов · 838

Проверены исходники и отдельный кандидат. Публичный чат, рабочее хранилище и
установленная версия не переключались. Модель/корпус пользователя не изменялись.

## Регрессии

Целевой набор включает прежние проверки журнала и новые проверки полного
Rust HTTP-чата: запись до передачи текста, точная цитата после передачи,
длинный Unicode-фрагмент с непрерывными курсорами, неполное покрытие,
перезапуск, изменение оригинала при прежних размере/mtime, изоляция владельцев,
совместимость с прежним владельцем, расширение инструмента через describe,
обрыв модели без зачёта чтения и сохранение результата инструмента в истории.
Проверяются также транзитивные зависимости, циклы, CAS, повторы request_id,
невыдуманные страницы PDF, вложения и автономный внешний Python-навык.

Итоговый расширенный целевой набор: **79 passed, 63,98 с**, без пропусков.
Rust core: **91 passed**; API с Edge и без Edge: **17 passed** в каждом варианте.
`make verify`: **2033 tests collected**. `make test`: **2031 passed, 2 skipped,
18 subtests passed, 613,99 с**. Проверки публикации и состава изменений пройдены.
В наборе проверяются также изменение PDF во время генерации и
чтение ещё не проиндексированного оригинала с явно известной редакцией.
Без SHA из каталога или явного запроса такое чтение останавливается до ответа.

## Реальные документы

Отдельная копия прежней принятой выборки: PDF и XLS, существующие векторы Edge.
Исходные оригиналы открываются только для чтения. Проверяются SHA, ссылка на
физическую страницу и отдельный журнал проверки выбранного раздела через Qwen.
В итоговом прогоне Qwen3.5:9b выполнила чтение физической страницы 2, затем
создала проверку одного явно выбранного родительского раздела, прочитала его
и сохранила наблюдение с выбранным точным отрывком. Проверены точный selector,
буквальные символы и смещения цитаты, запись в SQLite, SHA полученных оригиналов,
страницы ссылок и неизменность исходников. Одна переданная порция; одна единица;
accepted=false. Весь итоговый прогон двух обращений к чату — **57,941 с**; это не отдельный
замер скорости Rust или холодного старта модели.

До итогового прогона обнаружены и исправлены неправильный формат вложенного
вызова, повтор start после потери настоящей пары assistant/tool, неточная цитата
и пропуск служебного ключа записи. Неудачные попытки не засчитывались как проверка.
Короткие ссылки на отрывки сохраняют реальные символы источника; модель выбирает
отрывок и формулирует наблюдение. Повтор исходного решения с автоматически
полученным ключом не создаёт новую ревизию. Чужая/непереданная порция отвергается.

Перед сохранением финального ответа повторно проверяется физическая редакция
прочитанного PDF. Изменение оригинала во время генерации даёт ошибку
SOURCE_REVISION_CHANGED без события final; прочитанное и причина остаются в истории.
Ссылка содержит SHA реально прочитанного дескриптора, включая оригинал без
готового индекса. Отдельная регрессия меняет байты при прежних размере/mtime.

Независимая предметная оценка правильности ответа и весь большой корпус этим
прогоном не покрываются. Фоновое обновление/падение Edge в новом общем чате
остаётся отдельной незакрытой приёмкой.

## Очистка и публикация

Заменённая Python-реализация и неиспользуемый общий SQLite-класс удалены;
совместимые кодеки пока нужны прежнему чату. Успешные временные тесты очищаются
после teardown. Собственный испытательный индекс и копии оригиналов удалены после сохранения
компактных результатов; тестовая Qwen выгружена из памяти; модели и рабочие базы для очистки не удаляются.
Проверенный набор публикуется в main; это не обновление установленного приложения.
