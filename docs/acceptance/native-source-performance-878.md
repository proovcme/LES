# 878: скорость обзоров и изображения через MCP

Кандидат на отдельной копии реального корпуса. Рабочая установка, её MCP,
индекс и назначения моделей не переключались. Qwen не вызывалась. Это проверка
поиска, чтения и происхождения данных, а не качества сгенерированных справок.

## Что изменено

- Индексация и читатель Word используют одно полное преобразование. Законченные
  представления сохраняются; повторный запрос не начинает Docling/OCR заново.
- Снимки PDF-страниц и результаты распознавания отдельных картинок переживают
  перезапуск. Кэш ограничен, закреплён за оригиналом, обработчиками и настройками;
  повреждение означает повторное чтение. Порядок полей JSON не меняет ключ.
- В Windows один запрос может проверить большой PDF один раз и удерживать
  read-only handle на время чтения его страниц. Если защита от записи недоступна,
  сохраняются прежние проверки каждой страницы. Проверка по одному mtime не введена.
- MMR сохраняет прежнюю формулу, бюджеты и порядок; устранены повторный расчёт
  стоимости, построение временных словарей и сравнения уже рассмотренных пар.
- Edge обеспечивает также индекс `parent_id`; число векторов и редакции документов
  не изменяются. Добавление этого индекса само по себе не объявляется причиной
  общего ускорения: основная измеренная стоимость была в чтении оригиналов.
- MCP передаёт точный PNG выбранного объекта вместе с текстом и происхождением.
  Буквальные Unicode-подписи WMF читаются без OCR-догадки. Геометрия не интерпретируется.

[Владельцы и ограничения](../modules/source-derived-views.md).

## Измерения через настоящий MCP

Три одинаковых естественных запроса по двум подключённым наборам. В запросах
нет имени файла или ID документа. Дочитывание использует только найденные IDs.
Протокол: stdio `initialize → initialized → tools/call`; штатный MCP не используется.
Копия содержит 83 425 векторов; исходники открываются только для чтения.

| Запрос | Исходный 877, с | Первый проход 878, с | Повтор 878, с | После перезапуска 878, с |
|---|---:|---:|---:|---:|
| Состав томов | 75,274 | 79,323 | 9,209 | 16,775 |
| Электроснабжение | 90,844 | 67,784 | 12,251 | 13,402 |
| Внешние источники питания | 40,602 | 34,034 | 8,987 | 8,489 |

Исходные замеры выполнены на имевшемся состоянии кэшей 877. «Первый проход»
означает отсутствие производных записей для новой версии обработчика;
кэш файловой системы Windows не сбрасывался. Это не p95 и не универсальный
коэффициент ускорения. Первое чтение большого оригинала остаётся дорогим.

В первом проходе один Word достиг автоматического лимита 30 с и был явно
отмечен непрочитанным, без подстановки индексного текста как доказательства.
Подготовка полного представления при явном дочитывании заняла 73,021 с;
инструмент вернул ограниченную первую порцию, а не весь документ в контекст.
Последующие обзоры получили источник без отказа. Тексты, порядок документов
и SHA-256 в трёх контекстах совпали с прежним тёплым кандидатом: ускорение
не получено сокращением выданных материалов.

Два дополнительных запроса по инженерным разделам и резервированию не входили
в исходные три: первые проходы 24,017 и 57,486 с, после перезапуска — 7,850 и
12,568 с. Во всех повторных случаях тексты содержательны, отказы чтения отсутствуют;
`coverage=bounded` не означает полного обзора всех документов корпуса.

## Рисунки: что подтверждено

У естественно найденного Word проверены 392 объекта, включая 143 уникальных
изображения. Все исходные превью совпали с прежними SHA-256: новая обработка
не заменила оригинал и не изменила обрезку. Независимый разбор Windows GDI
обнаружил 52 WMF с текстовыми записями; у двух записи пустые. Для остальных
50 через MCP сверены буквальные подписи и SHA-256 полученного PNG. Две прежде
пустые OCR-проекции теперь возвращают исходные числовые подписи.

Число уникальных изображений без распознанных надписей изменилось с 68 до 66.
Это не оценка точности распознавания всех картинок. Мелкий символ и плотный
растровый график возвращаются изображениями; содержимое не объявляется пустым.
`evidence_admissible=false` и `visual_verification_required=true` сохранены:
подписи сами по себе не доказывают связи, геометрию или значение на графике.

Эксперимент с увеличением маленьких растров отклонён. На реальных формулах
OCR потерял знаки сравнения и части выражений, а буквы заменил похожими.
Эти три результата не засчитаны улучшением; код увеличения удалён до публикации.
Формулы остаются непрочитанными изображениями.

MCP и API интерфейса вернули одинаковые структурированные данные и байты
выбранного рисунка. Неверная редакция дала `SOURCE_REVISION_CHANGED`, несовместимые
имя объекта/ID — `SOURCE_PART_IDENTITY_MISMATCH`; в отказах нет ImageContent.
Частные исходники, изображения, вопросы и сырые протоколы в Git не включены.

## Регрессии и границы

Проверки Rust: core 137, API/Edge 96, runtime 8; проверки компонентов интерфейса
49. Отдельно пройдены 12 проверок Word/Edge, включая переиспользование полного
преобразования между индексацией и чтением после завершения процесса.
`make verify`, `make test`, `make public-check` пройдены: 2213 passed, 2 skipped,
18 subtests. В полном прогоне 55 предупреждений унаследованных адаптеров;
это не прогон без предупреждений. После окончательной правки списка объектов
повторены проверки интерфейса и 14 проверок его сборки/упаковки на текущем API.
Служебные XML-структуры не показываются в обычном списке рисунков; пустые
технические порции пропускаются ограниченным чтением.

Новый просмотр рисунков в окне источника использует общий API. Визуальная
приёмка не завершена: Computer Use остановлен из-за невозможности уверенно
определить URL тестового окна. После отказа действий в окне не было.

обзоров, параллельная нагрузка, установленное окно и полная приёмка продукта.
Установщик и публичный релиз не собраны; PR остаётся черновиком.
