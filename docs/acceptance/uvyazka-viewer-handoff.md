# Переход из источника LES во вьювер Увязки

Продолжение кандидата 880. Код LES и его версия не менялись: изменения
сделаны в отдельном репозитории Увязки. Рабочие процессы, модели и индексы
не переключены; установленная пара не принята.

В отдельном временном проекте синтетический DXF прочитан настоящим ezdxf.
В отдельном окне браузера ссылка с project/dataset/object/SHA открыла
свойства нужной надписи. Действие «Показать на чертеже» загрузило проверенный
оригинал, открыло CAD-вьювер и выделило надпись. Инспектор показал исходный
handle, TEXT и слой. Соседний контур не выбран. Это реальный экранный прогон,
а не подмена декодера; RAG-поиск в этом проекте не запускался.

Первый экранный прогон выявил отсутствие HEAD на сервере Увязки. CAD SDK
проверяет этим запросом доступность локальных workers и отказывал в чтении.
Сервер исправлен для статических ресурсов вьювера, с теми же заголовками,
что GET, без тела и без выполнения API. После исправления путь повторён.
Свойства при ошибке оставались доступны; ложного подтверждения выделения не было.

Оригинал выдаётся по зарегистрированному идентификатору, не произвольному пути.
Сервер проверяет SHA точной временной копии до ответа, браузер проверяет его
ещё раз до декодера. Изменение во время выдачи, неверный объект/редакция,
превышение 64 МиБ и неоднозначный handle проверены отдельно. Это не доказательство
чтения всех вариантов DWG. RVT/IFC-сцены выбираются только по SHA оригинала;
создание геометрии из одного снимка свойств и федеративные случаи не обещаются.

Исходники Увязки: тесты браузерных модулей — 259 passed, проверка типов и сборки
основного/CAD-вьювера прошли. Отдельная HTTP-регрессия проверяет точные байты,
смену редакции после предварительной проверки и HEAD без тела. Результаты
этих тестов не являются оценкой поиска или генерации на пользовательском корпусе.

Не завершены: поставка совместимого выпуска Увязки, установленный сценарий,
приёмка разных настоящих DWG/RVT и больших моделей, полный поиск → ответ → вьювер.
Ограничения импорта и единственный путь RAG кандидатов 879/880 сохраняются.
