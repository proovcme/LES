# Кандидат 773: импорт, восстановление и причины остановки

Отдельное состояние Windows, собственный native Qdrant, без пользовательского
корпуса и назначений моделей. Использован release EXE с SHA-256
`84ad98678aa6fbf6505c6eb20cb2db58b75e56a1e9b237aae90679f19182bdd0`.
Повторное применение патча и локальная установка описываются отдельно ниже.

## Подтверждённые изменения

Регистрация больше не читает содержимое PDF/таблиц в API. Тест со специально
заблокированным SQLite сохраняет отзывчивость event loop; parser не вызывается.
Повторная регистрация сохраняет ID и существующие фрагменты до публикации замены.
Нет второго сброса статуса после передачи файла уже работающему индексатору.
Фоновый импорт имеет долговечные счётчики и отличает завершение регистрации
от отдельного задания обработки. Ошибка обхода сохраняется как failed.

В настоящем собранном приложении зарегистрированы 324 авторских PDF-контейнера
без чтения/индексации их содержимого: 2,252 с до завершения; максимальный
наблюдавшийся ответ API во время регистрации — 0,127 с. Байты исходников совпали.
Это проверка регистрации и доступности API, не скорость парсинга или качество RAG.

Принудительно завершались только PID, подтверждённые как дочерние процессы
одноразового кандидата:

| Компонент | Восстановление до готового API | Проверка сохранности |
|---|---:|---|
| API | 8,98 с | Черновик, 324 записи каталога, точка Qdrant |
| Python launcher | 9,01 с | То же; окно осталось прежним |
| Native окно | 8,19 с | То же; внешний наблюдатель остался прежним |

Контрольная точка хранится в отдельной тестовой коллекции, а файлы остаются
PENDING: это не проверка смыслового поиска. После сбоя окна фактический WebView
восстановил тот же Unicode-черновик. Повторный запуск того же EXE с тем же
состоянием не создал второго владельца или новый instance API.

Первый прогон помощника остановился на его излишне строгой проверке рабочего
каталога native-процесса: он отказался завершать PID. После проверки пути EXE,
родителя и текущего ID окна проверка продолжена; отказ не был сбоем приложения.

Обычное закрытие выполнено кнопкой native окна. Получены `desktop_stop`,
`launcher_stopped` с кодом 0, внешний `desktop_exited` с `normal_exit` и кодом 0.
Оба статуса стали `stopped`, наблюдатель завершился; повторного открытия нет.
Свежие события отличают намеренную остановку служб от неожиданной смерти.

- make verify: 1409 тестов собраны.
- make test: 1405 passed, 4 skipped, 18 subtests; 98,72 с.
- Целевой gate импорт/журнал/launcher/health/datasets: 109 passed.
- Rust desktop: 7 passed; release EXE собран и проверен в живом процессе.
- Почтовый gate: полный повтор 66 passed после закрытия кандидата.
  Предыдущий параллельный прогон отказал в одном запросе из-за реальной

Код и границы: [runtime-recovery](../modules/runtime-recovery.md). Полного
установщика, проверки macOS и нового публичного релиза этот этап не содержит.

## Локальная установка

Установленный 770 был остановлен до применения. Подготовлены приватные резервные
копии SQLite и копии 33 заменяемых/добавляемых файлов приложения. Применение и
откат воспроизведены на одноразовой копии; контроль состояния пережил откат.
При установке проверяются отсутствие работающих процессов, launcher lease,
исходные SHA-256 и совпадение байтов кандидата. При сбое возвращаются только
изменённые файлы программы, состояние не откатывается.

Патч 773 установлен. Все 33 файла совпали с кандидатом; EXE соответствует SHA
выше. Окно достигло loaded, API подтвердил новый instance. Сохранены 324 записи
подключённого набора и настройки его наблюдения. Сравнение восьми назначений
моделей с резервной копией и SHA конфигурации подтвердило сохранность выбора.
Очередь продолжила обработку: на момент проверки 225 INDEXED, 34 PENDING и
65 прежних ошибок извлечения. Эти ошибки не объявлены исправленными.

Намеренные завершения процессов выполнялись только на отдельном кандидате;
пользовательское приложение после установки не прерывалось. Новый Svelte-чат
остаётся отдельным режимом, основной запуск сохраняет classic. Причина прежней
исторической остановки не установлена задним числом. Остаток изоляции парсера
и границы самого наблюдателя перечислены в контракте выше.
