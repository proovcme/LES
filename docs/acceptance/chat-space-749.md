# Build 749 — место для переписки

На окне 1280×720 переписке с выбранным набором оставалось 104,5 px:
декоративная шапка 99 px, заголовок чата 83 px, постоянно закреплённая строка
файлов, отдельная строка области поиска и ввод 186 px занимали остальную высоту.
Внизу сообщений сохранялся пустой отступ 120 px, уводивший ответ выше экрана.

Убрана дублирующая декоративная шапка. Выбор источников находится рядом с памятью
и файлами; список документов прокручивается вместе с перепиской. Ввод начинается
с одной строки и растёт до ограниченной высоты; загрузка перетаскиванием проявляет
слой только при переносе файла. Кнопка прикрепления остаётся доступной с клавиатуры.
На узком экране второстепенные кнопки имеют иконки и доступные названия.
Пустой нижний отступ убран. До ширины 1440 px источник открывается поверх чата;
на большом экране остаётся соседняя панель.

На 1280×720 область переписки после изменения — 416,6 px, ввод — 108 px.
Размер текста сообщений не уменьшен. Измерения сделаны по DOM настоящего
интерфейса; это высота области прокрутки, а не обещание числа видимых строк.

Локальный патч шести файлов установлен поверх 748 с резервными копиями.
Проверка идёт на установленном embedded Python, отдельном состоянии и копии
истории, без изменения пользовательского диалога. Проверены 1280×720,
1280×600 и 390×844, длинный ввод, источник → возврат и сохранение черновика.
На 390×844 область переписки — 476,6 px, ввод — 104 px, горизонтального
переполнения нет. На 1280×600 с 18 строками черновика ввод ограничен 120 px
по высоте текста, переписке остаётся 206,6 px. На 1280×720 открытие источника
сохраняет ширину чата 808 px; закрытие сохраняет введённый черновик.
Полные make verify / make test прошли: 1 092 теста и 18 subtests.
После последних правок CSS повторно прошли 98 целевых UI-тестов и public-check.
Настоящее перетаскивание из Проводника, нативный WebView и экранный диктор
этим браузерным прогоном не проверены. Полный установщик и публикация не обновлены.
