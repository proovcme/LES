# Build 751 — пространство чата

Постоянная колонка проектов заменена модальным списком по кнопке «Проекты и чаты».
Он закрывается после выбора диалога, через кнопку, Escape или фон. Используется
диалог NiceGUI/Quasar с именем, удержанием фокуса и возвратом на кнопку открытия.
Удалены старые правила скрытия списка только на мобильном экране.

По просьбе владельца удалена верхняя полоса с поисковой ссылкой. Поиск остаётся
на странице «Лес знаний». Назад и Главная перенесены в навигацию; на узком экране
они доступны в «Ещё» вместе с настройками и лесом знаний.

Кандидат основан на установленном 750: шесть файлов интерфейса и версии.
Табличный эксперимент 746 не включён. Основное состояние, индекс и модели не меняются.
Проверка использует отдельное состояние с копией истории.

На 1280×720 область чата выросла с 808 до 1032 px в ширину, область прокрутки
переписки — с 416,6 до 496,6 px в высоту. Размер шрифта сохранён.
Клавиатурный фокус удерживается в списке и возвращается на кнопку после Escape;
черновик с кириллицей, диакритикой и числами сохраняется при открытии и закрытии.

Установлен локальный патч шести файлов поверх 750 с проверкой хешей и резервной
копией. Проверка выполнена на установленном embedded Python и отдельном состоянии.
На 390×844 переписке доступно 540,6 px по высоте, горизонтального переполнения нет.
На 1600×900 при закрытых источниках у чата одна колонка шириной 1352 px.

Проверены создание нового чата, переход в существующий, возврат к собственному
черновику нового чата, отмена создания проекта, Escape, возврат из раздела данных
и мобильное меню. Проверка кликов выявила и закрыла дефект первой версии кандидата:
Quasar включал события указателя только у прямого div-потомка диалога. Панель теперь
использует div с семантической ролью navigation; клики действительно переключают чат.

make verify и make test прошли: 1 110 тестов, 18 subtests. После последнего исправления
контейнера прошли ещё 32 целевые проверки, карта кода обновлена. Public-check и
проверка пробелов прошли. Снимки обычного и узкого экрана сохранены в локальном отчёте.
Публичный выпуск и установщик не обновлены. Нативный WebView2 и экранный диктор
этим браузерным прогоном не проверены.
