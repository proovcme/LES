# Локальный установщик Edge · 849

Установщик Edge Preview требует отдельно перенесённый индекс в каталоге
`vector-edge` пользовательского состояния. Перед заменой приложения
он проверяет, что перенесённый индекс открывается. Пакет запускает Edge
через обычный настольный ярлык и оставляет серверное хранилище для отката.
Для Preview собираются только полный EXE и контрольная сумма.

В проверке использована свежая копия остановленной установки 847. Каталог
содержал две привязки моделей и ни одного документа. Для проверки поиска
в копию добавили один PDF и его 339 фрагментов, перенесённых из отдельного
Qdrant Server. Исходные данные рабочей установки использовались для чтения.

Транзакцию установки и отката запускает тот же PowerShell-обработчик, что
встроен в EXE. Внешний мастер NSIS и запись ярлыков в рабочий профиль в эту
проверку не входят.

После установки итогового пакета настольная сборка 849 открыла 339 точек
в Edge и вернула оригинал PDF с ожидаемым SHA-256. Поиск по установленному
индексу вернул шесть результатов. Каталог документов и привязки моделей
совпали с состоянием до установки.

В первой проверке отката сохранилось 19 из 339 свежезаписанных тестовых
точек Server. Для контрольного прогона создали снимок коллекции и до
перехода проверили, что 847 видит все 339 точек после перезапуска.
Повторную транзакцию отката проверили отдельно с теми же файлами приложений
и подготовленной резервной копией. Она вернула 847, все 339 точек, результаты
поиска и исходный PDF. Обратный перенос новых записей из Edge в Server
не проверялся.
