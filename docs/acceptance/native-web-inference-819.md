# Кандидат 819: проверка нативного транспорта и веб-инструментов

Дата: 07.11.2026. Проверены исходники и отдельные процессы со своим
состоянием. Работающее приложение, назначения моделей и индекс пользователя
не переключались. Полный установщик и публичный выпуск не выполнялись.

## Результат

- `make verify`: успешно, 1701 собранный тест; синхронизация версии,
  карта кода и контракт API совпадают.
- `make test`: 1692 passed, 9 skipped, 18 subtests; 238,07 с.
  Остались 27 предупреждений, в том числе прежние NiceGUI/lifespan.
- Rust: core — 51 passed, API — 9 passed, runtime — 7 passed.
  Форматирование проверено для всех трёх crates.
- Объединённая целевая проверка пресетов, транспорта, роли/ключа,
  веб-инструментов и stdio MCP: 70 passed. После последних уточнений
  ошибки MCP и валидации веб-выдачи повторены профильные проверки:
  8 passed через HTTP/stdio и 5 Rust-тестов HTML/RSS/кодировок.
- `git diff --check` на затронутых файлах веб-пути прошёл.

## Что действительно проверено

1. Python backend остановлен. Rust разрешает роль из SQLite, получает
   синтетический ключ, отправляет правильное тело на отдельный HTTP-провайдер
   и возвращает поток. Python-реализации секрета и провайдерного HTTP намеренно
   заменены отказом: обращений к ним нет.
2. Нативные OpenAI SSE/JSON и Ollama NDJSON сохраняют Unicode, потоковые
   инструменты, большие целые аргументы и позднюю статистику. Скрытые мысли
   не выводятся. Прерванный поток — ошибка. Закрытие клиента закрывает
   соответствующее соединение/системный TLS-процесс.
3. На 250 замороженных случаях совпали прежние лимиты/пресеты. Синтетические
   ключи меняются без потери параллельной записи другого ключа; чужие строки
   конфигурации и Unicode сохраняются. Реальные пользовательские ключи
   для проверки не читались.
4. После остановки backend инструмент чата получил выдачу отдельного
   SearXNG-сервера через Rust. Дубликаты/небезопасные ссылки исключены;
   точный URL, заголовок, выдержка и время остались в карте источников.
5. Живой DuckDuckGo потребовал капчу. Rust переключился на Bing RSS,
   вернул четыре источника за 0,86 с и явно указал фактический провайдер
   и причину переключения. Обход капчи не выполнялся.
6. Прочитана реальная публичная страница книги Rust: 944 символа,
   название и URL за 0,30 с. Это проверка HTTP/HTML, без Qwen.
7. Нативный stdio MCP проверен существующим MCP-клиентом. `web_search`
   и `web_read` доступны, имеют признаки чтения открытого интернета;
   ответ со статусом ошибки превращается в `isError`, сохраняя объяснение.
8. При режиме «только выбранные источники» запрещены и поиск, и чтение
   сайтов. Локальные/служебные адреса не читаются. Чужой Origin и запрос
   без приватного токена отвергаются до запуска веб-инструмента.

## Границы

Не проверен полный пользовательский диалог с Qwen и цитатой веб-страницы
в установленном окне. Поисковое ранжирование внешних систем и точность
генерации этим стендом не оцениваются. Сайты с JavaScript/авторизацией
могут требовать явно подключённый расширенный reader. Существующий путь
Crawl4AI пока остаётся в Python. MCP и чат вызывают нативный веб-путь
через оставшиеся фасады общего API.

Перенос Python целиком не завершён. Локальные модели/OCR, остатки
документной партии, общий цикл чата/инструментов, API/bootstrap и classic UI
ещё требуют переноса и приёмки. Автономная совместимость старых Python-навыков
остаётся отдельным явным требованием.
