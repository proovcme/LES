# Локальное обновление Windows 766

Кандидат 765 установлен поверх 757 с сохранением прежних файлов, контрольными
суммами и отдельной резервной копией SQLite. Откат заменённых и новых файлов
воспроизведён на одноразовой копии; контрольный файл состояния сохранился.
Это локальное обновление runtime, не новый публичный установщик.

По явному выбору пользователя роль ответов назначена локальной Qwen3.5:9b в
Ollama. Используется контекст 8192. Модель поиска BGE-M3 и её привязка сохранены;
повторная проверка возможностей восстановила просроченный допуск к embeddings.
Зависимости не менялись, новые модели/пакеты не скачивались.

Первый запуск с неограниченным сохранённым подключением Qwen использовал 32768
токенов; при нехватке RAM запрос завершился понятным CHAT_MEMORY_PRESSURE за
0,07 с. После ограничения контекста обычный потоковый чат завершился примерно
за 11 с. Порог 4 ГБ не снижался. Процесс llama-server принадлежал самой Ollama;
сторонние процессы не завершались.

На вымышленном контрольном документе поиск нашёл срок 14 дней и исключение,
модель воспроизвела обе точные цитаты. Ссылка на оригинал вернула исходные байты.
Один поиск занял около секунды; это малая контрольная выборка, не нагрузочный
или независимый тест качества RAG.

Живой тест продолжения document_review выявил HTTP 400 в native chat: канонический
assistant/tool передавал JSON-строку arguments, тогда как сервер ожидал объект.
Отдельный минимальный запрос воспроизвёл 400 со строкой и 200 с объектом.
В 766 добавлен отдельный адаптер native_tool_message_service: он преобразует
arguments и tool_name только на границе native-протокола, сохраняя исходную
историю и стандартный OpenAI запрос. Некорректный JSON или не-объект отклоняются
до отправки. Нативная проверка возможностей теперь передаёт заданный num_ctx,
чтобы не оставлять модель с контекстом серверного значения по умолчанию.

Целевые проверки транспорта, capability probe и очередей: 80 passed.
make verify: 1326 тестов собраны. Итог make test: 1322 passed, 4 skipped,
18 subtests passed, 108,42 с. Первый полный прогон получил временный WinError 5
в тесте переименования macOS-пакета на Windows; отдельный повтор 6/6 и полный
повтор прошли. public-check и git diff --check прошли.
Четыре файла исправления установлены поверх 765 с отдельной копией для отката.
Приёмка возобновления реальной моделью остаётся открытой: после сбоя в прежнем
диалоге модель объявила reviewed без записи в review_events. Также исследуется
расхождение каталога и native-точек контрольного документа после полного запуска;
простые native-проверки на новом хранилище и его копии сохраняют точки.
Итог установленного пользовательского пути дополняется после прогона.
Геометрия UI, экранный диктор и все клики этим отчётом не
подтверждаются; Computer Use не применялся.
