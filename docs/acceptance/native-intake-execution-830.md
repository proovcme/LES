# Приёмка фонового подключения 830

Область: исходники и отдельный кандидат, без обновления установленного LES.
Рабочие документы, индекс и назначения моделей не менялись.

Очистка: после проверки импортов, runtime manifest, тестов и строковых ссылок
удалены **7 неиспользуемых Python-модулей / 2766 строк** унаследованного
construction/resource-cost контура. Они не были доступны из действующего Light.
Из диагностики версий убраны 37 записей уже отсутствующих файлов, мёртвая
feature-ветка и версии удалённого расчётного компонента. Актуализировано начало
архитектурного документа, ранее ошибочно называвшее историческую сборку текущей.
Бэклог сокращён до актуальных незакрытых задач; повторяющиеся исторические
списки переноса убраны, отчёты и журнал выпусков сохранены.

Проверен холодный нативный API при отсутствующем Python upstream, с намеренно
нерабочими PYTHONHOME/PYTHONPATH/PATH. Одинаковые сценарии прошли на Qdrant Server
и Edge: ограничение корня → регистрация двух файлов → ожидание явной роли
модели → индексация → настоящие страницы PDF 1/2 и `#page=N` → изменение файла →
падение владельца во время inference → холодное восстановление того же задания.
Предыдущая партия сохраняет PID и `INDEX_BATCH_OWNER_LOST`; оригиналы не меняются.

Целевые проверки: **18 passed**. Включены четыре прежних embedding-профиля,
изменение модели/размерности/нарезки, повреждённый контракт, SHA токенизатора,
ограничение повторов по manifest/сроку/пути и фактические native HTTP-сценарии.
Эмбеддинги в регрессии — явно зарегистрированный контролируемый HTTP-стенд;
это проверка исполнения и целостности, не измерение качества модели.

На отдельной копии настоящего индекса проверен новый фоновый вход целиком:
реальные XLS и двухстраничный PDF, действующие локальные BGE-M3/ONNX и токенизатор,
без кеша эмбеддингов и без Python-сервера приложения. Результат: **2 файла,
35 фрагментов, 0 ошибок**, физические страницы 1/2 сохранены. Все **43 219**
прежних точек совпали до/после по SHA полных payload и векторов. Проверены SHA
оригиналов и тестовых копий. Изменение роли/manifest модели выполнялось только
в отдельном состоянии стенда; рабочие назначения не менялись.

Фоновый intake — **49,524 с**; весь driver с копированием и двойной полной
сверкой векторов — **315,025 с**. Это не сравнительный benchmark и не оценка
качества RAG. Сбой во время inference проверен отдельно в воспроизводимой
регрессии Server/Edge, без повторного изменения настоящего корпуса.

Rust core/API с Edge/runtime: **65/10/7 passed**. `make verify`: **1955 tests collected**.
Общий `make test`: **1953 passed, 2 skipped**, 18 subtests, **390,82 с**.
Он выполнен после удаления семи старых модулей и очистки диагностики.
Проверки документации/версий: 11 passed; форматирование Rust, runtime map,
native API contract, staged diff и publication audit прошли.

Для воспроизводимого source gate пути `LES_CORE_LIBRARY` и `LES_TEST_*` должны
указывать на соответствующий кандидат. `LES_NATIVE_MCP_WORKER` указывает на
проверяемый native API, `LES_SKILL_PYTHON` — на отдельный комплект внешних
навыков; отсутствие этих путей не подменяется интерпретатором приложения.

этим отчётом не объявляются. Незакрытые ветки указаны в
