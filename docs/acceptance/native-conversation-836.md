Изолированный контур. Рабочее приложение, его назначения моделей, источники
и индекс не переключались. Полный перенос основного чата/API ещё не завершён.

## Проверяемые границы

Нативный процесс запускается с отсутствующим Python upstream и недействительными
`PYTHONHOME`, `PYTHONPATH`, `PATH`. Проверяется реальный HTTP/SSE, SQLite и
контролируемый модельный транспорт, а не подмена функции суммаризации.

- Извлекательная сводка, Unicode, последовательное чтение длинной истории,
  сохранение последних сообщений, ручной CAS и отключённая память.
- Забывание памяти во время генерации: старая сводка не записывается.
- Новый запрос прерывает idle-модель, а задание возвращается в очередь.
- Жёсткое завершение процесса: очередь продолжается при следующем запуске,
  без нового запроса на суммаризацию; история сохраняется.
- Общий слот модели, совместимый classic-кодек и неизменность причин ошибок.
- Обычный завершённый запрос сам ставит задание памяти; отказ записи outbox
  откатывает успешную историю/квитанцию и сохраняет частичный текст с причиной.
- Палитра, справка и обе формы ответа на команду без модельной генерации.
- Прежние проверки источников/PDF, восстановление чата и автономный внешний
  Python-навык без импортов приложения.

## Реальная Qwen и копия источников

Отдельное хранилище: выборка из двух реальных документов, 35 фрагментов,
собственные SQLite и Edge. Основная модель — явно назначенная в копии Qwen3.5:9b.
Приложение Python не запущено. Шесть исходных реплик для проверки памяти созданы
как тестовые данные; затем выполнены три настоящих модельных запроса.

Первый запрос не прошёл полную приёмку: Qwen ограничилась результатом поиска,
хотя пользователь просил дочитать оригинал. После явного повторного указания
модель вызвала `read_pdf_source` через разрешённую обёртку дополнительных
инструментов. Rust прочитал физическую страницу 2; оригинал по ссылке и SHA-256
проверен, исходные файлы не изменились. Скрытого принудительного маршрута по
тексту вопроса не добавляли. **Исполнение всего задания с первого запроса не доказано.**

После остановки и повторного запуска отдельного API проверена нативная сводка:
граница — шестое сообщение, все выбранные записи дословно совпадают с исходными
репликами. Следующий настоящий модельный запрос получил эту сводку в контексте.
Точность сформулированных Qwen фактов независимым судьёй не оценивалась.
