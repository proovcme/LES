# Дочитывание и фактическое окно модели — кандидат 866

Продолжение [проверки обзорных задач](rag-synthesis-865.md). Рабочая установка,
индекс и назначения моделей не меняются. Проверка идёт на прежней копии.

## Две исправленные причины

В `retrieval::read` ранжированные по запросу фрагменты пересортировывались
по `chunk_ord` до допуска в ограниченный контекст. Теперь допуск сохраняет
релевантность; порядок документа применяется к уже отобранным фрагментам
для показа. Последовательное чтение без запроса сортируется до ограничения
числа исходных фрагментов. Поисковый индекс и формула ранжирования не меняются.

Допуск reader по предварительной оценке не гарантировал, что его фактический
результат поместится вместе с текущей парой вызова/ответа и схемами инструментов.
Координатор теперь проверяет собранное обязательное продолжение тем же packer.
Если мешают схемы в чисто документном чтении, `AgentLoop` один раз закрывает
инструментальную фазу ещё до отправки запроса провайдеру. В финальном окне
схем нет, целые доказательства остаются обязательными, полные квитанции сохранены.
Если и это окно не подходит, переполнение остаётся ошибкой. Контекст, срок
и бюджет действий не увеличиваются; активные табличные/обзорные задания
не переводятся таким способом в обычный ответ.

## Проверки

Ядро и API собраны в одном графе с Edge: 111 и 67 тестов прошли.
Интеграции: 9 passed, 21 deselected. В них проверяются поздний релевантный
PDF-фрагмент, обычный порядок чтения, реальное обязательное продолжение
с длинными аргументами, расширение окна, одна коррекция выбора и повторная
ошибка с сохранением причины. В модель не отправляется переполненный запрос.
Повторены четыре обзорные задачи с Qwen без выбора файла: одно исчерпание
вывода модели, два ограниченных отказа и одна подборка цитат. Готовых справок
по-прежнему нет. Прежнее переполнение при дочитывании электроснабжения
не повторилось. Полный gate 866: 2174 passed, 2 skipped,
18 subtests passed; `make verify` прошёл. Вместе с отдельным анализатором
проверены 112 тестов ядра и 67 API. Установка остаётся прежней.

Синтез справок остаётся открытым изменением: договор одного числового
`answerable` и рендер таблицы выдержек не объявляются исправленными этими
двумя изменениями. Отдельно исследуется связный ответ с дословными вставками
из доказательств; исследовательский формат не считается функцией приложения.
