# Приёмка нативного ядра 770

Исходники и отдельный собранный пакет, 31 октября 2026 года.
Реализация и откат: [контракт ядра](../modules/native-core.md).
Пользовательский экземпляр 769 остаётся открытым до согласованного перезапуска.
Это не полный публичный релиз и не новый EXE-установщик.

## Что перенесено

Rust-библиотека содержит выделение термов/прежний stem/частоты, чтение SHA-256
с проверкой стабильности источника, правила переходов заданий и решения при
восстановлении. Python сохраняет Unicode-нормализацию, OCR/модельные интеграции,
выполнение заданий и SQLite-транзакции. Отдельного процесса/хранилища не добавлено.
Язык выбирается внутри приложения; пользовательских настроек для этого не добавлено.

Автоматический BM25 использует кэшированный Python. Native-подготовка реализована
и проверена, но её автоматическое включение отложено по результату сравнения ниже.
Файлы и правила заданий в пакете используют Rust. Совместимый Python-откат сохранён.

## Измерения

Профиль исходного кода на 20 тысячах вымышленных фрагментов: 14,04 из 19,71 с
профилируемого построения — обработка окончаний; поисковый запрос преимущественно
проводит время внутри SQLite. Профайлер добавляет накладные расходы: эти числа
не используются как замер ускорения.

Последовательное сравнение без параллельных сборок/тестов: 100 тысяч фрагментов,
два повтора на режим, отдельные процессы, порядок во втором повторе развёрнут.
Медиана времени построения:

| Реализация | Время |
| --- | ---: |
| Исходный Python до 770 | 22,42 с |
| Python с ограниченным кэшем | 13,90 с |
| Rust с нормализованным текстом целой порции | 14,22 с |

Native быстрее исходного пути примерно в 1,58 раза, но преимущества перед кэшем
не показал. Разница с кэшем около 2,3% не доказывает выигрыша; auto оставлен на
кэшированном Python. Предварительные прогоны давали иной порядок близких результатов;
последовательный контроль не заменён самым удачным числом из них.
Начальный Rust-вариант со списком каждого слова был медленнее текущего.

Совпали SHA-256 всех логических postings, частот и метаданных, а также ID/оценок
60 запросов. Поисковая SQL-формула не менялась; ускорение самого запроса не заявлено.
Peak working set процессов был близким, устойчивого общего выигрыша RAM не показано.
Фикстуры синтетические; это не качество поиска на реальном корпусе и не полная
стоимость чтения PDF, OCR, эмбеддингов или ответа модели.

## Собранный пакет

Собран отдельный кандидат со встроенным Python и нативным Qdrant, повторно
использованы установленные зависимости без скачивания. Пользовательские состояние
и документы в него не копировались. Библиотека около 1,6 МиБ; Cargo.lock закреплён,
лицензии native-зависимостей включены. Абсолютные пути сборочной машины удалены
через remap-path-prefix; проверено отсутствие личного префикса в DLL.

Через фактические API кандидата на вымышленном документе выполнены: загрузка,
индексация локальной BGE-M3, поиск, чтение исходных байтов и повторный поиск после
полного перезапуска. ID доказательных фрагментов сохранились. В API-процессе
проверено присутствие DLL именно этого пакета. Генеративная модель не вызывалась.
Активное тестовое задание после перезапуска получило cancelled с причиной
прерывания и прежним processed=2. Тестовый набор удалён с обязательным recovery.
Два последних запуска служб: 7,17 и 6,55 с; ускорение старта не заявлено.

Первый тест восстановления записывал задание в meta.db, тогда как JobService
использует les_meta.db относительно каталога состояния. Исправлены база и cwd
стенда; подтверждение выше получено после этой поправки. История провала сохранена.

## Проверки и ограничения

Итоговый auto gate с поставленной библиотекой: make verify — 1370 тестов,
make test — 1366 passed, 4 skipped, 18 subtests passed, 100,66 с.
Полные дополнительные прогоны строгого native и Python-отката до последней
политики auto: 1365/4 и 1351/18, соответственно. В Python-прогоне дополнительные
14 пропусков относятся к проверкам, которым нужна скомпилированная библиотека;
в нативном/auto gate они выполнены. make test-core: формат и 8 Rust-тестов прошли.
Clippy не запускался: компонент отсутствует в установленном toolchain и не добавлялся.

Проверены Unicode/смешение алфавитов/нулевые значения, частоты, конкурентные вызовы
ABI, смена байтов при прежних размере/mtime, отклонение изменения при чтении,
конкурирующий прогресс/завершение, откат всей транзакции восстановления после
искусственного сбоя и явное закрытие SQLite-соединений.
Повреждённый native asset не загружается; кодовый откат подготовлен отдельно
и воспроизведён с сохранением контрольного файла состояния.

UI/WCAG и чистая Windows не проверялись; соответствие всем пользовательским кликам
не заявлено. Наблюдение за папками и исполнение задач ещё не перенесены в Rust.
Изменение не закрывает модельные дефекты 769: заявление Qwen о record без вызова
и обрыв ответа по длинной XLSX-ячейке. Полная перепись приложения не выполнялась.
