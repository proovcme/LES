# Приёмка индексации вложений · 841

Проверен отдельный Rust API с Edge и пустым каталогом, без адреса Python API.
Через `/api/rag/attach?mode=index` приняты два файла. Пока модель поиска
не назначена, задание показывает `EMBEDDING_MODEL_NOT_ASSIGNED` и сохраняет
оригинал. Повтор возвращает те же ID набора, документа и задания; с
изменённым содержимым тот же ключ даёт конфликт.

На копиях реальных PDF и XLS из проектного набора процесс принудительно
остановлен во время эмбеддинга. После запуска очередь продолжила задание,
оба документа опубликовались. В индексе проверена ссылка на страницу 2 PDF;
API оригиналов вернул байты с теми же SHA-256. Исходные образцы неизменны.
Тестовая папка, копии и индекс удалены. Для воспроизводимости использована
локальная тестовая модель эмбеддингов: это проверка конвейера и источников,
без оценки качества поиска на полном корпусе.

Обнаружение моделей проверено через локальный HTTP-стенд: список очищается
от дублей, редирект не выполняется, ключ не сохраняется. Отдельный Rust API
увидел 13 моделей запущенной Ollama и вернул тот же список при прямом выборе
адреса. Реестр и назначения не менялись. Целевые проверки: **4 passed**.
Ядро Rust: **91 passed**. `make verify`: **2042 tests collected**.
`make test`: **2040 passed, 2 skipped, 18 subtests passed**, 640,49 с.

Новый выбор режима в Svelte, полный мастер настройки моделей, почта и
проверка установленного приложения в этот прогон не входят.
