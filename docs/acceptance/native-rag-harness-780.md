# RAG/harness 780 — проверенный этап, поставлен в 781/782

Отдельно build 780 не устанавливался. Его изменения вошли в установленный
[782](auto-parse-resume-782.md). Ниже — замеры и проверки отдельного кандидата;
во время этих замеров рабочий экземпляр 779 и назначения моделей не менялись.
[Граница переноса](../modules/native-rag-harness.md).

Проверено на финальных core/API/runtime-v5: make verify — 1523 collected;
make test — 1521 passed, 2 skipped, 18 subtests; mail — 66 passed.
Rust: core 25, API 1, runtime 3. ABI-проверки покрывают таблицы/оценки/ранги,
области изменения, Unicode, старые scalar-метки, недопустимые структуры,
ошибку числа точек, лимит писателей, независимый снимок WAL и смерть процесса.
250 наборов контекста и 100 RRF-наборов сравнены с замороженным 779.

На 100 000 вымышленных фрагментов, две проходки в обратном порядке:

| Показатель | Python 779 с кэшем | Rust 780 |
| --- | ---: | ---: |
| Построение, с | 11,87 | 11,67 |
| Медиана запроса, мс | 87,49 | 82,77 |
| Память процесса после поиска, МиБ | 90,7 | 97,3 |

Индекс и выдача 60 вопросов совпали по хешам во всех четырёх процессах.
Заметного ускорения индексации нет: около 1,7% в этом синтетическом замере.
Это не измерение OCR, dense/embedding, полного ответа или качества рабочего корпуса.
Контекст через переходный JSON/FFI-мост медленнее: 20 объектов 0,43 → 1,96 мс;
100 объектов 1,94 → 6,38 мс. Следующие этапы должны сократить этот мост.

Реальная Qwen3.5:9b в отдельном состоянии через основной chat API сохранила
предпочтение инструментом, создала историю agent и вспомнила его в другом чате.
В браузере проверены русский заголовок/вопрос/ответ, точный USER.md, открытие
памяти и возврат с сохранением ответа. Это не замер Recall@k на рабочем корпусе.
Первый модельный прогон исключён из Unicode-приёмки: тестовый драйвер прочитал
UTF-8 в системной кодировке; повтор из оригинала с явной UTF-8 прошёл в новом
состоянии. Производственный код для ошибки драйвера не менялся.

Подготовлен патч из 11 файлов; before/after SHA и trial-откат проверены.

Новые библиотеки не добавлялись. Совместимый Python для прежних навыков
