# 876: RAG-источники без промежуточной модели через MCP

Статус: кандидат на копии, рабочее приложение и штатный MCP не переключены.
Это проверка передачи источников внешнему клиенту, а не приёмка всех ответов
Qwen и не публичный релиз.

## Исправленная причина

Нативный MCP вызывал отсутствующий в автономном API `/api/search` и не
публиковал общее чтение документа/PDF. Реальный запрос возвращал 501
`NATIVE_ROUTE_NOT_AVAILABLE`. CLI/MCP теперь вызывают общий Rust-читатель
чата через [источниковый API](../modules/native-source-mcp.md). Отдельная
урезанная проекция `hits` удалена: она теряла курсор и идентичность чтения.
Модель ответов не участвует в этом пути; эмбеддинги поиска остаются прежними.

## Что выполнено на документах

Использована существующая копия Edge/SQLite с двумя основными наборами
(638 зарегистрированных оригиналов); ещё один индекс для проверки не создан.
Настоящий `les-runtime --cli mcp` обменивался `initialize`,
`notifications/initialized`, `tools/list`, `tools/call` через stdio.
Проверялся отдельный `instance_id` копии, а не адрес рабочего окна.

1. Обычный вопрос о составе томов без имени файла нашёл документ состава.
   Последующее чтение дало все 15 индексированных единиц. Ссылки Word
   закреплены SHA-256; физические номера страниц не приписывались.
2. Тот же документ прочитан в 8 ограниченных порциях: список идентификаторов
   точно совпал с полным индексированным чтением, без повторов и пропусков.
   Перекрытия текста исходных чанков этим не объявляются отсутствующими.
3. Продолжение поисковой выдачи началось с первого непрочитанного смещения;
   идентификаторы двух порций не пересеклись. Поколение индекса осталось одним.
4. Поиск по электроснабжению вернул документы ПД и РД с разными ID/SHA-256.
   Установленная, расчётная активная и полная мощности найдены обычным
   запросом, затем подтверждены прямым чтением найденной физической PDF-
   страницы. Разные виды мощности не трактовались как конфликт редакций.
5. Длинная физическая PDF-страница прочитана двумя порциями. Их конкатенация
   побуквенно совпала с отдельным чтением всей страницы; последний курсор null.
   Ссылка с `#page=N` открыла оригинал с тем же SHA-256, без сохранения новой копии.
6. Неверный SHA оригинала, старое поколение индекса, продолжение без поколения,
   пустая/неизвестная область и запрос к приватному веб-адресу дали ошибки MCP.
   Код причины сохранён; отказ не превращался в пустое успешное доказательство.
7. Qwen не загружалась. Ответы внешнего клиента составлялись по тексту
   инструментов, без `les_chat` и локальной генерации между поиском и клиентом.
8. Поиск повторён в области только двух основных наборов. На запрос о
   фактическом электропотреблении за отдельный год нашлись проектные положения
   об учёте и расчётные расходы другого энергоносителя. Внешний клиент признал
   данные недостаточными и не подставил эти числа в ответ. Это оценка найденных
   доказательств, а не утверждение об отсутствии документа во всём корпусе.

Дополнительная проверка выявила обрыв продолжения после поиска фразы на
странице PDF. Исправлено: фраза выбирает начальное окно, курсор — следующую
порцию. На настоящей странице четыре вызова с неизменной фразой дали точный
суффикс исходного текста без повторного поиска и пропусков символов.
Граница между контрактом PDF и бюджетом координатора также исправлена:
координатор больше не подставляет лимит, нарушающий схему самого читателя.
Отказ страницы сохраняет настоящую причину и не вызывает уверенную генерацию.

Частные протоколы и оригиналы не включены в репозиторий. В наблюдённых
вызовах поиск занял около 5–9,5 с, прямое чтение выбранной PDF-страницы —
около 3 с, полное индексированное чтение документа состава — 0,17 с.
Это отдельные измерения, не p50/p95 и не обещание скорости на любом документе.

## Что не принято

- Два проверенных скана остановили физическое чтение с `PDF_OCR_REQUIRED`.
  Распознанный индексированный текст доступен отдельно; он не выдавался за
  новое OCR-чтение оригинала. Нужен общий путь OCR физической страницы.
- В старом индексе Word остаются перекрытия чанков, обрывки строк таблиц и
  колонтитулы. Получить все части теперь можно; это не исправление самой
  структурной нарезки и не гарантия удобного контекста для маленькой модели.
- Обзорные справки Qwen 9B не приняты. Контроль с полными проверенными
  выдержками также выявлял ошибки обозначений и неподтверждённые сравнения.
- Каталог и отдельное ограниченное окно не доказывают прочтение всего корпуса;
  совпадение содержимого не определяет актуальную редакцию документа.
- Обновление/падение Edge в этой проверке не запускались. Проверены отказы
  по неверным идентичностям и курсоры при неизменном поколении.
- Установка на рабочий LES, переключение штатного MCP и мерж пока не выполнены.

Общая приёмка RAG остаётся открытой. Содержание README и статусы выпуска
не следует повышать по числу тестов или успешному HTTP-ответу.
