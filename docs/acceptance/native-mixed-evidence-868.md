# Абзацы рядом с таблицами — кандидат 868

Проверка на копии. Рабочая установка, индекс и назначения моделей прежние.
Новый Rho SDK/Tantivy согласован отдельно; в приложение ещё не включён.

## Причина и исправление

Реестр проверяемого ответа добавлял целый текстовый фрагмент только при
отсутствии Markdown-таблицы. В смешанном фрагменте регистрировались только
табличные строки. Пояснения до и после таблицы модель могла видеть, но
не могла выбрать для проверяемого ответа.

Общая функция ядра выделяет точные абзацы смешанного текста. Разметка
модельного контекста и реестр ответа используют одну функцию. Адрес S…P…
указывает исходную строку начала абзаца; S…R… и S… сохраняют прежний смысл.
Метаданные конверта, OCR-предупреждения, разделители таблиц и невидимые
источники не получают адресов доказательств.

Нативный код копирует выбранный абзац и добавляет ссылку. Текст, страница,
документ и редакция сохраняются. Арифметика разрешена только для табличных
ячеек; целый числовой текстовый фрагмент не становится операндом.

Нарезка, векторы и оригинал не изменяются. Исправление не гарантирует
релевантность выбранного абзаца и не закрывает обзорные справки.

## Проверка

На прежнем API регрессия с одним смешанным документом закончилась HTTP 503.
После пересборки тот же сценарий прошёл: выбран нужный абзац, посторонняя
таблица и другое пояснение не скопированы, цитата совпадает с оригиналом.

118 тестов ядра, 68 API и пять целевых интеграций прошли. Проверены UTF-8,
CRLF, исходные строки, недоступные адреса, вложенные единицы доказательств,
запрет арифметики над абзацем, пагинация и переход окна.
make verify прошёл, собрано 2179 тестов. Полный gate и повтор Qwen ещё
не завершены; установки и выпуска нет.

Опыт переформулирования не включён: на старых 20 вопросах лексическое
покрытие известных источников среди первых пяти упало с 67,5% до 60%,
на новых 15 выросло с 60% до 70%. Это отдельный BM25, не качество всего RAG.
