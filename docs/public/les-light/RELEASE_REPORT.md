# LES RAG 0.1.0 · build 743

Первый выпуск для Windows x64. Полный EXE установлен и проверен; исходники
доступны в [proovcme/LES](https://github.com/proovcme/LES).
[Установщики и контрольные суммы](https://github.com/proovcme/LES/releases/tag/v0.1.0).

## Возможности

- Чат с потоком ответа, понятными этапами, источниками и точным оригиналом.
- Документы, файлы и папки в чате; наборы данных и наблюдение за изменениями.
- Проекты, память, контекст и сводка разговора с возможностью забыть контекст.
- Обнаружение локальных движков, явное назначение моделей, OpenAI-совместимый API.
- Собственный Qdrant и Python; исходные папки используются только для чтения.
- Локальный OCR Windows, письма/вложения, MCP, API и CLI.
- Полный и маленький сетевой установщик, проверка GitHub-обновлений и SHA-256.

## Исправления перед выпуском

Проверки возможностей моделей теперь соблюдают общую очередь и защиту памяти;
параллельные обращения не создают повторные пробы. PDF обрабатывается через
pdfplumber и PDFium с блокировкой native-рендеринга; MSG — через python-oxmsg.
Удалены прежние несовместимые с лицензией проекта зависимости. Лицензии
192 Python-пакетов и 248 Rust-пакетов собраны в THIRD_PARTY_NOTICES.
Сборка и тесты проверены в отдельном публичном дереве. Настройки открываются
на моделях; мобильное меню содержит почту. Устранены зависимости сборки
от старой оболочки и скрытого локального окружения разработчика.

## Установка

Маленький LES-RAG-Web-Setup.exe скачивает полный пакет. LES-RAG-Setup.exe
содержит Python и Qdrant. При отсутствии WebView2 нужен интернет для скачивания
подписанного компонента Microsoft. Модели подключаются отдельно.
Для CLI скачайте install-les.ps1 и запустите:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-les.ps1 -Silent
```

Полный EXE: 242001683 байт. SHA-256:

```text
6edaea09aeea8022ab552395eba38a7732cba56fc24db45f9f5e56c3bdfca175
```

## Открытые ограничения

EXE не подписан сертификатом издателя. Чистая Windows без WebView2 и нативный
WebView с экранным диктором требуют отдельной приёмки; полное соответствие
WCAG не заявляется. OAuth для IMAP отсутствует, New Outlook не поддерживается
классическим COM-сборщиком. Реальные почтовые аккаунты не проверялись.
После обрыва загрузка установщика начинается заново. Большие унаследованные
координаторы и расширение корпуса PDF остаются в [бэклоге](BACKLOG.md).
