# Проверка кода 743

- Проверки возможностей моделей соблюдают общую очередь и политику памяти.
  Отмена не освобождает чужой слот; параллельные запросы объединяют проверку.
- PDF-текст и таблицы читает pdfplumber, рендеринг выполняет PDFium под общим
  mutex. Изображения независимы от закрытых native-объектов. Ошибка OCR
  не индексируется вместо текста; смешанный PDF не выдаёт частичный текст за полный.
- MSG читает python-oxmsg. Ссылочные вложения не загружаются из внешних путей.
- Зависимость tabulate зафиксирована: таблицы работают в чистой среде.
- Исходная конфигурация сборки не требует старой оболочки полного ЛЕС.
- Публичная копия проверена отдельно от рабочей; тесты не зависят от её кэшей.
