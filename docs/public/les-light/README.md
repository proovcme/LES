## Установка

Есть два варианта: маленький **LES-RAG-Web-Setup.exe** скачает проверенный пакет сам;
полный **LES-RAG-Setup.exe** можно перенести на компьютер без интернета при уже установленном WebView2 Evergreen Runtime. Если WebView2 отсутствует, установщик скачает подписанный компонент Microsoft; для этого нужен интернет.
Python, Qdrant и компоненты приложения устанавливаются автоматически. Модели подключаются отдельно.

Для установки из CLI скачайте `install-les.ps1` из [официального выпуска](https://github.com/proovcme/LES/releases), затем:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-les.ps1 -Silent
```

Для загрузки без установки используйте `-DownloadOnly`. При обрыве повторите команду:
повреждённый пакет не запускается. Права администратора не нужны.
Контрольные суммы файлов находятся рядом с установщиками.

## Четыре шага

**Установите → подключите модель → добавьте документы → создайте проект.**

Python и Qdrant входят в установку. ЛЕС обнаруживает работающие локальные сервисы и помогает
подключить совместимый OpenAI API. Модели для чата и поиска выбираете вы.
Папки обновляются, пока приложение открыто. Технические подробности раскрываются отдельно.

## ЛЕС знает. ЛЕС показывает источник.

Ответ ведёт к **имени документа, странице или разделу**, полному фрагменту и оригиналу.
В build 755 поиск объединяет смысловую выдачу и полноценный BM25 через native RRF.
Необязательный реранкер уточняет порядок, затем Лес дочитывает индексированный раздел
и передаёт фрагменты в пределах контекста модели. [Контракт поиска](../../modules/rag-ranking.md).
Набор считается готовым после проверки индекса; регистрация файлов сама по себе готовностью не считается.

Исходные папки доступны только для чтения. База, индекс, распознанный текст и временные данные
хранятся отдельно, в каталоге Леса. Ошибка чтения или распознавания не должна становиться доказательством.

## ЛЕС помнит

Сохраняйте требования проекта и продолжайте разговор после перезапуска. Сводка старой части
беседы помогает сохранить ход работы, а последние сообщения дополняют её в пределах контекста.
Память можно посмотреть, исправить, отключить или забыть, сохранив исходную историю.
**Память помогает продолжить работу. Факты подтверждаются источниками.**

## Материалы для работы

| Материал | Как использовать |
|---|---|
| Документы и папки | Приложить к задаче или добавить в базу знаний с наблюдением |
| PDF и изображения | Текстовый слой; для сканов — локальный OCR Windows с установленными языками |
| Письма и вложения | Classic Outlook и IMAP, только чтение; без отправки и удаления |
| Проекты | Свои источники, чаты и записи памяти |

Для распознавания нужны языки OCR, установленные в Windows. Качество распознавания зависит
от скана; проверяйте важные числа по оригиналу. Подключение почты через OAuth пока не реализовано.

## Для интеграций

**MCP в обе стороны.** Подключайте выбранные внешние инструменты чтения. Другим приложениям
ЛЕС отдаёт поиск по своим документам — с фрагментами и ссылками.
**API и CLI работают с тем же запущенным приложением**, назначениями моделей и базой.

```powershell
.\les.cmd status
.\les.cmd search "Когда открывается объект?"
.\les.cmd ask "Помоги составить план работы"
.\les.cmd datasets
.\les.cmd projects
.\les.cmd mcp
```

Команды доступны в каталоге установки. Для MCP-клиента используйте встроенный `python/python.exe`
с аргументами `-m tools.light_mcp_server`. Адрес локального API ЛЕС определяет при запуске.

## Обновления

ЛЕС проверяет выпуски этого репозитория и сверяет размер и SHA-256 установщика.
Установка обновления выполняется по действию пользователя. Документы и состояние сохраняются,
предыдущая установленная сборка остаётся для отката.
