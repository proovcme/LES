# Интерфейс 0.1.0

- 1280×860: чат, данные, история; без горизонтального переполнения, ссылка перехода к содержимому присутствует.
- Черновик с кириллицей, японским текстом и пробелами сохраняется при переходе в данные, настройки, на главную и обратно.
- Подключение папки: короткая форма с наблюдением, закрывается Escape; Назад возвращает чат.
- Настройки открываются на моделях; мастер обнаруживает работающую Ollama без изменения назначений.
- API: адрес, ключ и назначение; пустой адрес даёт понятное сообщение; закрытие возвращает настройки.
- 574×803: мобильное меню содержит Состояние, Почту, Модели и Профили; переход в почту и Назад работают; переполнения по ширине нет.
- Главная открывает лес знаний; логотип возвращает чат и сохранённый черновик.
- Панель памяти показывает текущую область и явную кнопку закрытия; закрытие возвращает чат.
- История открывается, Назад возвращает чат без потери черновика.
- Скриншот установленного runtime сохранён; контрольный черновик очищен, вкладка закрыта, размер браузера восстановлен.

Проверен браузер установленного runtime. Нативный экранный диктор и полная
приёмка WCAG остаются в бэклоге. Масштаб ОС не менялся.
