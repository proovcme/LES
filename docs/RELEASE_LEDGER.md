# LES RAG — выпуски

## build 757 · инкрементальный BM25

Локально установленный патч обновляет только изменённые лексические записи; веса считаются при
запросе. Добавление точки на 100 тысячах: 0,062 с вместо 79,30 с. Первоначальная
миграция: 34,15 с. Исправлены склонения счётчиков леса.
1183 теста прошли; 14 файлов установлены с откатом и сверкой SHA-256.
На установленном Python повторена регрессия 40 запросов без моделей,
в браузере проверены счётчики на отдельном вымышленном профиле.
[Измерения и границы приёмки](acceptance/incremental-bm25-757.md).
Полный установщик и публичный выпуск остаются build 743.

## build 756 · короткие обозначения и видимый отказ

BM25 получает версию словаря v2: короткие обозначения ищутся и внутри обычного
текста. Миграция защищена журналом, TF-откат сохраняет старый словарь. В чате
отказ виден у поля ввода; переход к причине выполняется по кнопке, панель
источников самопроизвольно не открывается. [Приёмка и нагрузка](acceptance/model-free-756.md).
1173 теста прошли. Восемь файлов установлены локально с откатом и сверкой SHA-256;
поиск проверен встроенным Python, отказ и новый чат — через браузер установленного
runtime на отдельном вымышленном профиле. Вызовов генеративных моделей не было.
На 100 тысячах синтетических фрагментов выявлен пересчёт около 80 секунд;
это открытая задача производительности, не объявленное ускорение.
Полный установщик и публичный выпуск остаются build 743.

## build 755 · полноценный BM25 без Qwen

README обновлён под текущую цепочку RAG и компоновку чата. Все шесть снимков
заменены, добавлена схема архитектуры; [происхождение снимков](../assets/screenshots/README.md).
Это обновление документации; установщик остаётся прежним.

В основной поиск включён BM25 с точным IDF и средней длиной текущего корпуса,
миграцией прежних весов, восстановлением после прерывания и откатом в TF.
Native RRF, иерархия, отключаемый реранкер и дочитывание сохранены.
[Контракт](modules/bm25-index.md), [приёмка](acceptance/bm25-index-755.md).
12 файлов установлены локально с откатом; проверен поиск через установленный
runtime на копии состояния. Первый поиск после перезапуска применит BM25 к
основному индексу без моделей. Полный установщик и публичный выпуск не обновлены.

## build 754 · поиск, дочитывание и бюджет основного чата

Основной чат дочитывает индексированные разделы после поиска/реранкера,
сохраняет отдельные цитаты и передаёт фрагменты целиком через ContextGovernor.
Те же ограничения действуют при поиске инструментом модели и повторной генерации.
Фильтрация фактически видимых источников применяется также к UI и истории.
[Контракт](modules/chat-section-context.md), [приёмка](acceptance/chat-section-context-754.md).
Девять файлов установлены локально с откатом; индекс и назначения моделей
основного экземпляра сохранены. Испытательные веса BM25 не переносились.
Полный установщик и публичный выпуск не обновлены.

## build 753 · схема устройства Леса

В «Лесе знаний» — раскрываемая схема подготовки документов и ответа с источниками.
Краткое объяснение, отдельные технические подробности, адаптивная раскладка.
[Приёмка](acceptance/forest-architecture-753.md). Два статических файла и маркер
версии установлены локально с откатом; проверены через браузер на копии состояния.
Backend, модели и индексы не менялись. Кандидат RAG 752 остаётся отдельным.
Полный установщик и публичный выпуск не обновлены.

Основной индекс и установленный build 751 не менялись; публичный выпуск не обновлён.

## build 747 · индексация и открытие доказательств

Исправлены переполнение ответа embeddings при индексации PDF и пустой встроенный
просмотр PDF из цитаты. Обработка векторов идёт ограниченными пакетами; просмотр
использует собственный renderer и точный ID оригинала, без браузерного PDF-плагина.
Подписи страниц человекочитаемы. [Проверки и статус](acceptance/core-rag-747.md).
Установлен локальный патч семи runtime-файлов поверх 745, с резервной копией.
Пользовательский путь цитата → страница PDF → возврат проверен в браузере на
установленном embedded Python и отдельном состоянии.
Эксперимент заданий по таблицам 746 остаётся отдельной незавершённой приёмкой.
Публичный выпуск не изменён.

## build 746 · точные таблицы и устойчивые задания — кандидат

Новая самостоятельная реализация универсального чтения XLSX/XLSM/CSV и журнала
решений по строкам. Числовой ноль, пустая ячейка и формула без результата различаются.
В контексте находится текущий пакет; обработанные строки остаются в SQLite.
Состояние связано с диалогом, исходником, областью, моделью и профилем.
Повторная доставка идемпотентна, прерванный пакет выдаётся заново.
Код большого LES и сметные функции не переносились.
[Контракт и ограничения](modules/document-tasks.md),
[приёмка кандидата](acceptance/document-tasks-746.md). Установка и публичный EXE
этим изменением пока не обновлены; публичный выпуск остаётся build 743.

## build 745 · восстановление диалога и установленные навыки

Локальный патч: сохранение видимых фрагментов до доставки в чат, маркировка оборванных
ответов после запуска, фоновая сводка с приоритетом нового запроса, ограниченное
восстановление зависших служб. Библиотека навыков читается по запросу; выбранные
MCP-инструменты доступны через каталог без загрузки всех схем в контекст.
Проверенные Python-функции навыков выполняются отдельно, с сохранением результатов.
Установленная функциональная проверка прошла; повторная визуальная приёмка
ограничена недоступностью управления браузером/окном.
[Приёмка и ограничения](acceptance/reliability-skills-745.md).
Публичный релиз остаётся 0.1.0 build 743.
