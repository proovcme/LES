LES RAG — настольное приложение для поиска и разговора по своим документам. Подключите модель, выберите папку в Проводнике и задайте вопрос. Из ответа можно перейти к документу и нужной странице.

## Чат и источники

На учебной папке ЛЕС нашёл расход из таблицы. Под ответом видны фрагменты,
которые получила модель, и ссылка на лист «Вентиляция», строку 2.

![Ответ по учебной папке и список фрагментов, переданных модели](assets/screenshots/folder-chat-942.png)

В карточке источника можно открыть ту же строку исходной книги.

![Карточка источника с листом «Вентиляция» и содержимым строки 2](assets/screenshots/source-row-942.png)

## Как работает поиск

```mermaid
flowchart LR
    A["Внешние папки"] --> B["Разбор · OCR · фрагменты"]
    B --> C["SQLite BM25 + Qdrant"]
    Q["Вопрос и выбранный набор"] --> D["Гибридный поиск · RRF"]
    C --> D
    D --> E["Фрагменты и соседние строки из индекса"]
    E --> F["Один запрос к модели"]
    F --> G["Ответ"]
    E --> H["Цитаты и адреса оригиналов"]
    H --> I["Открытие по клику"]
```

Внешние папки остаются на месте. ЛЕС отслеживает изменения и обновляет индекс.
Обычный вопрос по набору использует готовые фрагменты. При необходимости ЛЕС
добирает соседние части страницы или строки таблицы, укладывает их в контекст
и передаёт модели. Рядом с ответом можно открыть фрагменты, которые она получила,
и перейти к исходной странице, листу или строке.

Для анализа явно выбранного документа предусмотрено отдельное чтение оригинала.
API, CLI и MCP используют общий поиск и позволяют получать источники без вызова
модели ответов.

## Установка и работа

- **Windows x64.** [Сетевой и полный установщики](https://github.com/proovcme/LES/releases), [установка и управление из терминала](docs/public/les-light/README.md#установка). Для установки WebView2, если его ещё нет, нужен интернет. Установщик без подписи издателя.
- **Модели.** Подключите локальную Ollama или совместимый OpenAI API. Модели ответа и поиска назначаются отдельно. Docker не нужен.
- **Приложение.** Чат Svelte, API и фоновые службы Rust. В Windows Python загружается при первом запуске одобренного скрипта внешнего навыка. В окне доступны проекты, память, профили чата, MCP и обновления.
- **Интеграции.** [MCP, API и CLI](docs/public/les-light/README.md#для-интеграций) · [macOS preview](docs/MACOS_PREVIEW.md) · [Ограничения и бэклог](docs/BACKLOG.md) · [Лицензия](LICENSE).
