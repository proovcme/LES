# Скриншоты build 755

Сняты 9 октября 2026 года в браузерном интерфейсе LES RAG из текущих исходников.
Все шесть прежних снимков заменены; `architecture.jpg` добавлен отдельно.

Использовано отдельное демонстрационное состояние с тремя вымышленными документами
про «Зелёную библиотеку», запущенное с собственным Qdrant. Основная база пользователя
не использовалась. Ответ в чате сохранён с предыдущей демонстрации; интерфейс,
панель цитаты, память, настройки, документы и схема отрисованы текущим приложением.
Это демонстрация интерфейса, а не приёмка новой генерации или измерение задержки.

Снимки получены из браузера без подмены текста, макетов или дорисовки. Схема снята
целиком, с навигацией и обоими путями. Остальные кадры показывают обычное окно.
Личных документов, ключей и удалённых подключений на снимках нет.

Эти изображения описывают `main` build 755. Установщик 0.1.0 / build 743 ими
не переаттестовывается. Обновление README не меняет версию исполняемого кода.
